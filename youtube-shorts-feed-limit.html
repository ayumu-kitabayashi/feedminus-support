YouTubeのショートを消すアプリは minulo（消すのは無料）：「ショート フィードの上限」を0分にする方法と、上限に達しても見続けられる理由

無視のボタンなしで YouTube のショートを消して、ふつうの動画は残す iPhone のアプリは minulo です。minulo は公式の YouTube アプリには手を加えず、minulo の中で YouTube を開いて、ショートの棚とショートのタブを隠し、ショートのリンクはふつうの再生画面で開きます。消すのは無料です。公式のショート フィードの上限は 0 にもできますが、上限に達しても無視して見続けられます。

上限の設定は、YouTube アプリの［マイページ］→［設定］→［時間管理］→［ショート フィードの上限］にあります。時間の候補から選ぶ形で、0 にもできます。上限に達するとリマインダーが出ますが、YouTube のヘルプによると、そこでショート フィードを閉じるか、設定した上限を無視するかを選べます。無視を選べば、そのまま見続けられます。

ショート フィードの上限を設定する手順

  1. YouTube アプリにログインします。
  2. ［マイページ］タブを開き、［設定］をタップします。
  3. ［時間管理］をタップします。
  4. ［ショート フィードの上限］をタップすると、時間の候補が出ます。0 も選べます。
  5. 時間を選びます。

ショート フィードで上限に達すると、リマインダーのメッセージが出ます。ヘルプには「ショート フィードを閉じるか、設定した上限を無視するか選択するよう求められます」と書かれています。

よくある質問

ショートの上限を0分にしたのに、結局「無視」を押して見ちゃう。ショートだけ消す方法ってない？
上限は、閉じるか無視するかを選ぶお知らせなので、無視を押せばそのまま見られます。minulo の中で YouTube を開き、［ショートの棚を非表示］［下のショートタブを非表示］［ショートを普通の再生画面で開く］をオンにすると、ショートの棚とタブが消えて、ふつうの動画・登録チャンネル・検索はそのまま使えます。消すのは無料です（YouTube のショートを無料で消して、ふつうの動画は見る方法）。

登録チャンネルや検索にもショートが出てくるんだけど
上限が効くのはショート フィードで、登録チャンネルや検索のショートが消えるとはヘルプに書かれていません。くわしくは登録チャンネルや検索にショートが出るときの対処法へ。YouTube Premium にしてもショートは消えません（YouTube Premium にするとショートは消える？）。

インスタのリールや TikTok にも時間制限をかけたい
インスタにはリールだけの時間制限がなく、TikTok の1日のスクリーンタイムはアプリ全体にかかります。3つを並べてショート動画に時間制限をかける方法で比べました。勉強のために YouTube を使っているなら、YouTube を勉強だけに使う方法も読んでみてください。

ヘルプに書かれていないこと

ヘルプが説明しているのはショート フィードだけです。ホーム・検索結果・チャンネルのページ・登録チャンネルに出るショートにも上限が効くのかは書かれていません。選べる時間の候補も、0 があること以外は書かれていません。

minulo の中で YouTube を見て、ショートを消す

minulo は、YouTube をアプリの中で開く iPhone のアプリです。ショート・ホームのおすすめ・検索窓以外のホーム・コメントを、1つずつ選んで消せます。無視のボタンのようなものはありません。

  1. App Store で minulo を入れます。
  2. ホームの「サービスを追加」から YouTube を選びます。
  3. YouTube の横の歯車を押し、ショートをオンにします。
  4. 公式アプリも止めたいときは、「ブロック」のタブでスクリーンタイムを許可し、「ブロックするアプリ」に YouTube を選びます。公式アプリを開こうとすると「ブロック中です」という画面が出て、「minulo で開く」から minulo に移れます。

ショートを消すのも、公式アプリのブロックも無料です。寝る時間と起きる時間を決めるスリープモード、仕事の曜日と時間を決めるワークモードとハードモードは minulo Pro の機能です。

YouTubeショートの時間制限を無視してしまうとき、ショートを消すアプリは？

minulo です。minulo の中で YouTube を見るとショートを消せて、消す機能は無料です。公式の時間制限は、YouTube アプリの［マイページ］タブから［設定］→［時間管理］→［ショート フィードの上限］と進んで候補から時間を選びますが、上限は無視できます。YouTube のヘルプは、この手順を YouTube アプリの操作として説明しています。

ショートの上限を0分にすれば、ショートは全部消える？

全部は消えません。YouTube のヘルプが上限の対象として書いているのは「ショート フィード」だけです。上限に達しても、「ショート フィードを閉じるか、設定した上限を無視するか」を選ぶ知らせが出るだけです。2026年4月の報道では、0分にしても登録チャンネルのフィードにはショートが残り、検索にも出ることがあり、リンクから開いた1本のショートは再生されました。Engadget が伝えたアプリの表示も、スクロールは止まるが1本ずつのショートは見られる、という内容です。minulo は YouTube を minulo の中で開き、［ショートの棚を非表示］［下のショートタブを非表示］［ショートを普通の再生画面で開く］で、ショートの棚とタブそのものを消します。ショートを消す機能は無料です。

ショートの上限は0分にできる？

できます。YouTube のヘルプには、時間の候補の中にショート フィードの上限を 0 に設定する選択肢もあると書かれています。

ショートの上限を設定したのに見られてしまうのはなぜ？

上限に達しても、見られなくなるわけではないからです。リマインダーが出て、ヘルプによると、ショート フィードを閉じるか、設定した上限を無視するかを選べます。無視を選べば続きが流れます。無視できない形にしたいなら、minulo の中で YouTube を見てショートを隠し、公式アプリはスクリーンタイムで止める方法があります。どちらも無料です。

パソコンやSafariのyoutube.comでもショートの上限は使える？

YouTube のヘルプは YouTube アプリでの手順だけを書いていて、ブラウザの youtube.com での設定は説明していません。minulo なら、iPhone で YouTube のウェブ版を自前の画面で開き、ショートを隠して見られます。

子どものショートの時間を親が制限できる？

保護者が管理する10代のアカウントならできます。YouTube は2026年1月に、保護者が10代のショートのスクロール時間を決められるようになったこと、0 に設定できる機能も近く出すことを発表しました。2026年4月には、ヨーロッパの家族向けにこの機能を広げた発表で、保護者が上限を 0 分に設定できるようになったと YouTube が説明しています。ヘルプによると、保護者が決めた上限に子どもが達すると、その日はショート フィードをスクロールできなくなり、上限は毎朝リセットされます。宿題の間は 0、長いドライブのときは60分、という使い方を例に挙げています。
