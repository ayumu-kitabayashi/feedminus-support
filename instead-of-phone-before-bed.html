寝る前のスマホの代わりにすること（SNS を開かない夜の設定・iPhone）

寝る前に SNS を開かないなら、代わりにすることを1つ決めておき、リールとショートは minulo で消しておけます（消す機能は無料）。

「寝る前 スマホ 代わり」「寝る前 スマホ以外何する」は Google の検索候補にも出てくる言い方です。スマホを置くと手が空き、気づくとまた手に取っている、という人は少なくありません。このページでは睡眠や体への効果には触れず、SNS の代わりにできることと、夜にリールやショートが出てこない設定だけを書きます。

2026-11-02

このページは minulo の開発者、北林 歩が書いています。比べている方法のひとつが自分のアプリなので、その点は割り引いて読んでください。睡眠や健康への効果は扱っていません。iPhone の設定は Apple の iPhone ユーザガイド（iOS 27 と iOS 26）を 2026-11-02 に確かめました。

SNS の代わりにできること

  • 紙の本や漫画を読む。1話や1章で終わるので、区切りをつけやすいです。
  • 明日の予定と持ち物を書く。手帳やメモ帳に3行だけ。スマホのカレンダーを開くと、そのまま SNS に行きがちな人は紙にします。
  • 日記を書く。その日のことを1行でも。
  • 明日の服やかばんを用意する。手を動かすことなら何でもかまいません。
  • 音だけのものを流す。ラジオや音楽なら画面を見ずに済みます。スマホで流すなら、再生したら画面を伏せておきます。

どれが合うかは人それぞれです。大事なのは、スマホを置く前に「代わりにこれをする」と決めておくことです。決めていないと、手が空いたときにスマホを取ってしまいます。

夜は SNS が開かないようにしておく

  1. 設定アプリで［スクリーンタイム］→［スクリーンタイムのスケジュール］を押し、［スケジュール］をオンにします（iOS 27）。
  2. ［スケジュールを追加］で、夜の時間枠を作ります。
  3. 目覚ましや家族の連絡など、夜も使うものは［常に許可］に入れます。

iOS 26 では「休止時間」の［スケジュール］で時間を決め、［休止時間中にブロック］をオンにします。Apple のガイドでは、これがオフだとリマインダーが出るだけで使い続けられます。

布団で SNS を開いてもリールが出ないようにする

LINE やインスタの DM だけは夜も返したい、という人は、アプリ全体を止めるより、リールとショートだけを消すほうが続けやすいです。

  1. App Store から minulo を入れます。
  2. minulo の中でインスタや YouTube、TikTok を開き、それぞれのログイン画面でログインします。minulo はパスワードを受け取りません。
  3. インスタの横の歯車で［リールと発見タブ］や［おすすめの投稿］を、YouTube の歯車で［ショートとおすすめを非表示］を、TikTok の歯車で［おすすめ］を選びます。消すのは無料です。
  4. 「ブロック」タブで公式のインスタや YouTube、TikTok を選んでブロックを始めます。アイコンを押すと「ブロック中です」の画面が出て、「minulo で開く」から移れます。無料では1回2時間までです。

無料のブロックは1回2時間までなので、寝る前に始めておけます。毎晩決まった時間に自動で始まるスリープモードは minulo Pro です（日本は月1,480円・年6,800円）。

minulo の弱いところも書いておきます。リールやショートが消えるのは minulo の中だけで、公式アプリは変わりません。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は使えません。minulo は iPhone のアプリで、Safari と Chrome で使える Mac 版もあります。Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

寝る前、スマホ以外に何をすればいい？

紙の本や漫画、明日の予定と持ち物を書く、日記、明日の服を用意する、ラジオや音楽を流すなどがあります。スマホを置く前に、代わりにすることを1つ決めておくのがこつです。

寝る何分前にスマホをやめればいい？

睡眠や健康への効果、医学的な目安はこのページでは扱っていません。

代わりのことを決めても、結局スマホを手に取ってしまう

夜の時間枠をスクリーンタイムのスケジュールで作るか、minulo のブロックで公式の SNS アプリを止めておけます。開いても minulo の中ならリールとショートは出ません。

夜も LINE や DM は使いたい

スクリーンタイムなら LINE を［常に許可］に入れておけます。インスタの DM は、minulo の中でインスタを開けばリールと発見を消したまま使えます。minulo が公式アプリを止めている間は、公式アプリの通知は届きません。
