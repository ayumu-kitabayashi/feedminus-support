minulo がリールやショート、おすすめの投稿を消せるのは、minulo の中でSNSを開いたときだけです。公式の Instagram・YouTube・TikTok アプリの中は変えられません。minulo が公式アプリを止めている間はそのアプリの通知が届かず、minulo 自身も通知を送りません。ストーリーズの投稿・ボイスメッセージ・通話は、各SNSのウェブ版に無いため使えません。使えるのは iPhone・Mac・Chrome・Safari で、Android 版はまだありません。無料のブロックは1回2時間までです。できないことを1つずつ、代わりにどうすればいいかと合わせて書きます。

できないこと理由・くわしく代わりの方法
公式アプリの中は変えられないiPhone では、ほかのアプリの表示を変えられるアプリはありません。リールやショートが消えるのは minulo の中だけです。公式の Instagram・YouTube・TikTok アプリをスクリーンタイムで止めます。アイコンを押すと「ブロック中です」の画面が出て、「minulo で開く」から minulo に移れます。公式アプリを削除する必要はありません。
止めている公式アプリの通知は届かないminulo がスクリーンタイムで公式アプリを止めている間は、そのアプリの通知が届きません。minulo 自体もプッシュ通知を送りません。通知が必要なSNSは、公式アプリを止めずにおきます。通知はいつもどおり届き、返信は minulo の中でもできます。
ストーリーズの投稿・ボイスメッセージ・通話各SNSのウェブ版に無いためです。写真つきの投稿、コメント、DM への返信はできます。「休憩する」を押すと、選んだ時間だけ公式アプリを開けます。
消していたものがしばらく出ることがあるSNS 側の画面の作りが変わると、それまで非表示にしていたものが出ることがあります。非表示のルールは毎週自動で点検しています。気づいたら workflowai.japan@gmail.com に知らせてください。確認できたものから直します。
Android 版がない使えるのは iPhone と Mac、Chrome と Safari の機能拡張です。Android 版はテスト中です。順番待ちに登録すると、公開のときに1通だけお知らせします。
無料のブロックは1回2時間まで曜日や時間帯の予定、2時間を超えるブロック、ハードモード、複数のブロックリストは Pro です（日本は月1,480円・年6,800円）。終わったらすぐ入れ直せます。リール・ショート・おすすめ投稿を消す機能は無料で、時間の制限もありません。
インスタの発見とリールは1つのスイッチ［リールと発見タブ］のスイッチで、発見とリールがいっしょに消えます。今のところ minulo の中で分ける方法はありません。発見を残したいなら、このスイッチはオフのままにして、おすすめの投稿だけを消します。
ハードモードはすぐには解除できないハードモード（Pro）の解除には、文を書き写す・暗算に答える・60秒待つ、の3つが必要で数分かかります。わざとそうしていて、抜け道はありません。本当に必要なときだけオンにします。minulo 自体はいつでも削除できます。
対応しているSNSは10だけInstagram、YouTube、TikTok、X、Threads、Facebook、Pinterest、Reddit、LinkedIn、Snapchat です。ほかのSNSの要望は workflowai.japan@gmail.com に送ってください。対応するSNSは順に増やしています。
まだ新しく、評価が少ない2026年9月に出たばかりで、評価の数はまだ少なめです。ログインする前に、minulo が送るもの・残すものと App Store の「アプリのプライバシー」を確かめてください。
13歳未満は対象外プライバシーポリシーで、13歳未満の人は対象にしていないとしています。代わりの方法はありません。13歳未満の人は使わないでください。

minulo が向いていない人

  • Android だけを使っている人。
  • インスタでストーリーズの投稿や通話を1日に何度もする人。そのたびに公式アプリを開くことになります。
  • SNS の通知をすぐに受け取りたいのに、そのアプリも止めたい人。

アプリ全体を止めるアプリも含めた比較は、リールを非表示にするアプリの比較にまとめています。

minulo の弱点は何ですか？

公式アプリの中は変えられないので、リールやショートが消えるのは minulo の中だけです。公式アプリを止めている間はそのアプリの通知が届かず、minulo 自身も通知を送りません。ストーリーズの投稿・ボイスメッセージ・通話は使えません。使えるのは iPhone・Mac・Chrome・Safari だけで、無料のブロックは1回2時間まで、まだ新しく評価も少なめです。

minulo で公式のインスタアプリからリールを消せますか？

消せません。iPhone では、ほかのアプリの表示を変えられるアプリはありません。minulo は、minulo の中でインスタを開いたときにリールを消します。公式アプリはスクリーンタイムで止めておけば、アイコンを押したときに minulo へ移れます。

minulo を使うと、インスタの通知は届かなくなりますか？

公式のインスタアプリを止めていなければ届きます。通知は公式アプリから届くので、minulo が公式アプリを止めている間は届きません。minulo 自体はプッシュ通知を送りません。

minulo は無料でどこまで使えますか？

10のSNSでリール・ショート・おすすめ投稿を消す機能と、公式アプリを1回2時間まで止める機能は無料です。Pro では、予定、2時間を超えるブロック、ハードモード、SNS を完全に止める機能、複数のブロックリストが使えます。料金は月額1,480円、年額6,800円（7日間の無料体験つき）、または買い切り23,800円です。

minulo は Android で使えますか？

まだ使えません。minulo は iPhone と Mac 向けで、Chrome と Safari の機能拡張もあります。Android 版はテスト中で、順番待ちに登録すると公開のときに1通だけお知らせします。
