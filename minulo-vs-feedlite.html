minulo と FeedLite の違い：リールを消して DM は残す、FeedLite の代わり（2026年）

リールとショートを消して DM は使いたいなら、どちらのアプリでもできます。FeedLite は Instagram と YouTube が対象で、App Store の説明には月9.99ドルか年39.99ドルのサブスクが書かれています。minulo は FeedLite の代わりに使えるアプリで、TikTok を含む10の SNS でリール・ショート・おすすめ投稿を消し、DM はそのまま使え、消すのは無料です。

FeedLite は App Store では「FeedLite - Block Reels&Shorts」という名前で、RCF LLC が作っています。自分のことを、ブロッカーではなく「デジタルフィルタ」と呼んでいます。Instagram や YouTube を使えなくするのではなく、リール・ストーリーズ・発見・ショートを取り除くので、Instagram はメッセージに、YouTube は検索に使えます。設定では、それぞれを別々にオンとオフにできます。

2026-11-04

このページは minulo の開発者・北林歩（Ayumu Kitabayashi）が書いています。自分のアプリと比べているので、その点は割り引いて読んでください。FeedLite については、米国とフランスの App Store のページ（2026-11-02 に更新された版 1.6）の説明・スクリーンショット・アプリ内課金の一覧・プライバシーの表示を、2026-11-04 に確かめました。機能や料金は変わることがあります。

minulo は FeedLite の代わりになる？

Instagram と YouTube のほかにも SNS を使うなら、なります。どちらのアプリもリールとショートを消して Instagram の DM は使えますが、minulo は TikTok・Threads・X・Reddit を含む10の SNS に対応していて、消すのは無料です。Instagram と YouTube だけでよく、Instagram のストーリーズや YouTube の登録チャンネルを隠すといった FeedLite のスイッチがほしいなら、FeedLite でできます。

FeedLite は無料？

ダウンロードは無料です。App Store の説明には、月9.99ドルと年39.99ドルのサブスク（3日間の無料体験つき）が書かれていて、アプリ内課金の一覧には、ほかにも「Feedlite Pro」が4.99ドルから29.99ドルで並んでいます。お金を払わずにどの機能が使えるかは書かれていません。minulo では、リール・ショート・おすすめ投稿を消すのは無料で、Pro は米国で月9.99ドル・年39.99ドル（日本は月1,480円・年6,800円）です。

FeedLite はどのアプリに使える？

Instagram と YouTube です。説明には Instagram のリールと YouTube のショートのことが書かれていて、設定のスクリーンショットには Instagram（Reels・Stories・Videos・Explore）と YouTube（Shorts・Subscriptions）のスイッチがあります。TikTok やほかの SNS には触れていません（2026-11-04 確認）。minulo は Instagram・YouTube・TikTok・X・Threads・Facebook・Pinterest・Reddit・LinkedIn・Snapchat に対応しています。
