仕事中にスマホでSNSを見てしまうときの対策

仕事中のスマホは、たいてい小さなすき間から始まります。ファイルの読み込み待ち、会議が始まる前、気が重い作業の前。スマホが机にあるので手に取ります。効くのは、連絡は切らずに、仕事の時間だけフィードを遠くすることです。iPhone なら、集中モードの「仕事」で SNS の通知を止めて SNS のないホーム画面に切り替え、スクリーンタイムの制限で SNS が開かないようにできます。仕事でインスタを使うなら、リール・発見・おすすめ投稿だけを消す方法があります。

よくある場面

報告書を送って返事を待つあいだに、スマホを手に取る。リールを2本見ているうちに返事が来ていて、気づかない。あるいは、気の重いメールが画面に開いたままで、それを書き始めるよりインスタを見るほうが楽に感じる。すき間は短く、リールやショートはその1〜2分を埋めるように作られています。

minulo の匿名の利用データにも、その気配があります。年齢を答えた韓国・日本の25〜34歳の利用者では、直近30日の平日に SNS を開いた回数の57%が8時〜16時で、学生の年齢の人よりずっと多くなっていました。ただしこの組は27人と少ないので、目安として見てください。minulo の中で SNS を開いた時刻（現地時間）で数えています。

集中モード「仕事」を設定する

Apple のガイドによると、集中モードでは、オンのあいだに通知を許可するアプリを選べて、気が散るのを減らすために、カスタマイズしたホーム画面のページに切り替えることもできます。

  1. 設定アプリで「集中モード」を開き、「仕事」を押します（なければ新しく追加します）。
  2. 「アプリ」で、通知を許可するアプリ（仕事のチャット・メール・カレンダーなど）を選びます。SNS は入れません。
  3. 仕事のアプリだけを置いたホーム画面のページを選びます。
  4. 勤務時間に自動でオンになるように設定します。

集中モードは通知を静かにするだけで、アプリを止めはしません。自分でインスタを開けば、開きます。

勤務時間だけ SNS をブロックする

スクリーンタイムなら、アプリが開かないようにできます。インスタ・TikTok・YouTube に「アプリ使用時間の制限」をかけて「制限終了時にブロック」をオンにするか、勤務時間に「休止時間」を設定して「休止時間中にブロック」をオンにします。パスコードを知っていれば押して外せる程度のものですが、その一手間で十分な人もいます。そのアプリの DM なども一緒に止まります。手順はiPhone でインスタをブロックする方法にあります。

スマホを離す

いちばんお金のかからない方法は距離です。集中したい作業のあいだは、スマホをかばんや引き出しに入れて手の届かないところに置き、仕事の連絡はパソコンで見ます。手に取るのに立ち上がる必要があれば、ちょっとした確認はそれだけ減ります。

仕事でインスタを使う人は

SNS 運用の担当者、お店の人、採用の担当者は、インスタをブロックするわけにいきません。minulo は、リール・ショート・発見・おすすめ投稿を消した状態で Instagram・LinkedIn・YouTube などをアプリの中で開け、投稿・コメント・DM はそのまま使えます。消すのは無料です。

限界もあります。ストーリーズの投稿、ボイスメッセージ、通話は、各サービスの Web 版にない機能なので minulo の中では使えません。「休憩する」を押すと、選んだ時間だけ公式アプリを開けます。minulo が公式アプリを止めている間は公式アプリの通知が届かないので、仕事でインスタの通知が必要なら、公式アプリはブロックせず、見るときだけ minulo を使ってください。iPhone だけです。

仕事の日の組み立て方

  1. 朝。仕事を始めると集中モード「仕事」がオンになり、スマホはかばんへ。
  2. 休憩。昼と午後の休憩に、決めて連絡を見ます。
  3. 仕事の SNS。投稿や返信は minulo で。フィードが出てきません。
  4. 夜。集中モードがオフに。夜に時間が溶けるなら、minulo の無料ブロック（1回2時間まで）か休止時間で夜も守ります。

仕事中にスマホを見てしまうのをやめるには？

勤務時間だけフィードを遠くします。SNS の通知を止めて SNS のないホーム画面に切り替える集中モード「仕事」を使い、SNS にスクリーンタイムの制限をかけ、スマホは手の届かないところに置きます。仕事でインスタを使うなら、アプリごと止めるのではなく、リールと発見だけを消します。

集中モードの「仕事」でアプリは止まりますか？

止まりません。集中モードは通知を許可するアプリとホーム画面のページを切り替えるだけで、アプリは開けます。開かないようにするなら、スクリーンタイムの「アプリ使用時間の制限」か「休止時間」でブロックをオンにします。

仕事中についスマホを触ってしまうのはなぜですか？

多くは短いすき間のせいです。返事待ち、読み込み待ち、始めたくない作業の前。スマホが手の届くところにあり、リールやショートは1〜2分を埋めるように作られています。スマホを離し、SNS の通知を止めると、きっかけの多くがなくなります。

仕事でインスタを使うけど、リールを見てしまうときは？

フィードのない形で使います。iPhone の minulo なら、リール・発見・おすすめ投稿を消した状態でインスタを開け、投稿・コメント・DM はそのまま使えます。消すのは無料です。ストーリーズの投稿や通話は公式アプリが必要です。

勤務時間だけ SNS をブロックできますか？

できます。勤務時間にスクリーンタイムの「休止時間」や「アプリ使用時間の制限」を設定するか、minulo のブロック（1回2時間まで無料）を使います。曜日と時間で自動で切り替わる予定は minulo Pro の機能です。
