Facebook アプリからマーケットプレイスを消す方法（iPhone・2026年）

マーケットプレイスを画面から消したいなら、minulo の中で Facebook を開けば無料で消せて、お知らせとメッセージはそのまま使えます。公式のアプリでも、下のタブバーからマーケットプレイスを外せます。［設定とプライバシー］→［設定］からタブバーの設定（英語表示では Tab bar → Customize the bar）を開き、マーケットプレイスを隠す設定（英語表示では Hide）にします。

変わるのはタブバーだけです。Facebook のヘルプには、マーケットプレイスそのものをオフにする設定は見つかりませんでした。画面から消したいなら、minulo の中で Facebook を開けばマーケットプレイスを無料で消せて、お知らせとメッセージはそのまま使えます。

  2. タブバーのカスタマイズ（英語表示では Customize the bar）を開き、マーケットプレイスの横のプルダウンで隠す設定（英語表示では Hide）を選びます。

タブバーからマーケットプレイスのショートカットを隠す

Facebook のヘルプでは、iPhone と Android のアプリでタブバーを自分で変えられると説明されています。タブバーのメニューから［設定とプライバシー］→［設定］と進み、英語表示では Tab bar → Customize the bar と進みます。ショートカットごとのプルダウンに Pin・Auto・Hide（英語表示）があり、マーケットプレイスで Hide を選びます。

ヘルプによると、お知らせと Facebook のホームはタブバーから外せません。気になるのが赤い点なら、ショートカットを長押しして通知の点をオフにできる（英語表示では Turn off notification dots）とも書かれています。

ショートカットを隠しても変わらないこと

このヘルプはタブバーについての説明だけで、アプリのほかの場所からマーケットプレイスが消えるとは書かれていません。マーケットプレイスをアカウントごとオフにする設定も、ヘルプには見つかりませんでした。マーケットプレイスの通知をオン・オフする記事はヘルプの一覧にありますが、本文を読めなかったので、ここでは手順を書いていません。

minulo でマーケットプレイスを消す

minulo は Facebook の公式サイトをアプリの中で開き、オンにしたものを消します。「マーケットプレイス」はその1つで、ほかに「リール・Watch・マーケットプレイスを非表示」、［「おすすめ」の投稿を非表示］、「ホームのフィード」、［「アプリを開く」の帯］があります。お知らせ・メッセージ・友達・フィードは minulo のホームからすぐ開けます。消す機能は無料で、時間の制限もありません。

つい公式アプリを開いてしまうなら、minulo の「ブロック」タブで止められます。アイコンを押すとブロック画面が出て、「minulo で開く」から minulo に移れます。ブロックは1回2時間まで無料で、寝る時間と起きる時間を決めるスリープモードやハードモードは minulo Pro の機能です。

minulo の弱いところも書いておきます。消えるのは minulo の中だけで、公式アプリは変わりません。minulo が公式アプリをブロックしている間は、そのアプリの通知は届かず、minulo からも通知は送りません。minulo は iPhone のアプリで、Safari と Chrome で使える Mac 版もあります。Android 版はまだありません。出たばかりで、評価もまだ少ないです。くわしくは minulo にできないことをご覧ください。

Facebook アプリからマーケットプレイスは消せる？

タブバーのショートカットなら隠せます。画面から消したいなら、minulo の中で Facebook を開けば消えて、お知らせとメッセージはそのまま使えます（消す機能は無料）。［設定とプライバシー］→［設定］のあと、英語表示では Tab bar → Customize the bar と進み、Hide を選びます。マーケットプレイス自体をオフにする設定は、ヘルプには見つかりませんでした。

お知らせやホームのタブも外せる？

Facebook のヘルプによると、お知らせと Facebook のホームはタブバーから外せません。ほかのショートカットは、Pin・Auto・Hide（英語表示）から選べます。

マーケットプレイスの赤い点を消すには？

ヘルプでは、ショートカットを長押しして通知の点をオフにする（英語表示では Turn off notification dots）と説明されています。

隠すと出品やメッセージは消える？

タブバーで隠すと変わるのはタブバーだけ、minulo で隠すと変わるのは minulo の中の見た目だけです。どちらも何かを削除するとは書かれていません。

マーケットプレイスとリールを一緒に消せる？

minulo ならできます。マーケットプレイス、リール・Watch、おすすめの投稿、ホームのフィードは同じメニューの別々のスイッチで、どれも無料です。
