  • スリープモードやハードモード（Pro）を使いたい

noShorts は無料？

止める機能は無料です。説明には、短い動画を止める機能はずっと無料とあります。noShorts Pro（米国で4.99ドル・1回払い・サブスクなし）では、1日の上限・夜の休止時間・白黒表示・過去の記録・設定をゆるめる前の Face ID かコード・1つの SNS で複数アカウント・最初に開くページの指定が使えます。minulo では、リール・ショート・おすすめ投稿を消すのは無料で、サブスクも時間の制限もなく、DM もそのまま使えます。スリープモード・ハードモード・1日の上限・2時間を超えるブロックは Pro の機能で、日本の App Store では月額1,480円・年額6,800円です。minulo Pro は月額か年額だけで、買い切りはありません。

noShorts が対応している SNS は？

Instagram・YouTube・TikTok・Snapchat・Facebook・X で、Reddit・Bluesky・Tumblr は追加すると使えます。LinkedIn は版 1.5 で加わりました。Threads と Pinterest は App Store のページに書かれていません。minulo は Instagram・YouTube・TikTok・X・Threads・Facebook・Pinterest・Reddit・LinkedIn・Snapchat に対応しています。

DM はそのまま使える？

minulo では使えます。DM は残り、Instagram と TikTok には DM 以外をぜんぶ消す無料の設定もあります。noShorts の App Store のページには、短い動画のフィードを除いてふだんどおり使えるとありますが、DM についてははっきり書かれていません。
