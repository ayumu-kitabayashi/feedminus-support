パソコンでインスタの DM を使う

  1. パソコンのブラウザで instagram.com を開き、ログインします。
  2. 左の［メッセージ］をクリックします。
  3. 新しく送るときは、左上の［作成］をクリックし、相手を選んで［チャット］をクリックします。
  4. メッセージを入れて［送信］をクリックします。

このクリックの手順は、インスタの公式サイト（About Instagram）にあるものです。相手のプロフィールで［メッセージ］をクリックしても送れます。フォローされていない相手へのメッセージは、メッセージリクエストとして届きます。2026-10-26 はインスタのヘルプの本文を読み込めなかったので、パソコンのウェブ版でどのメッセージ機能が使えるかまでは確かめられませんでした。

パソコンのウェブ版にもリールは出る？

出ます。インスタのウェブ版にもリールと発見のタブがあり、だからこそ minulo のようにウェブ版を開くアプリには、それを隠すスイッチがあります。パソコンに移ればスマホからは離れられますが、メッセージの画面からフィードやリールまではワンクリックです。

minulo には Mac 版もあり、Safari と Chrome で使えます。プライバシーポリシーによると、Mac 版はブラウザで開いているページの URL だけを読み、そこがフィードやショート動画の入口なら、自分で選んだ場所へ振り替えます。macOS の「オートメーション」の許可が必要で、ページの中身は読みません。Mac 版と各機能拡張がinstagram.com では、リールと発見のタブ、ストーリーの列を隠し、メッセージへの入口は残します（2026年9月に Chrome で確かめました）。

iPhone でアプリを開かずに DM を読む

  1. ［設定］を開き、［通知］をタップします。
  2. ［通知スタイル］の下でインスタをタップします。
  3. ［プレビューを表示］をタップし（表示されている場合）、［常に］か［ロックされていない時］を選びます。

Apple によると、プレビューにはメッセージの本文などが入ることがあり、プレビューに対応していないアプリもあります。インスタが DM の通知に本文を入れるかは、インスタのヘルプで確かめられませんでした。通知をタップすると、インスタのアプリでそのチャットが開き、フィードやリールもそこにあります。

ほかの近道は インスタを開いたらすぐ DM に行く方法 にまとめています（通知の長押しと、アイコンの長押しのメニュー）。届く通知を DM だけにしたいなら、インスタの中でほかの種類をオフにします。手順は インスタの通知を DM だけにする方法 へ。

minulo で iPhone のインスタを DM だけにする

  1. minulo を入れ、その中でインスタを開き、インスタ自身のログイン画面でログインします。minulo がパスワードを受け取ったり保存したりすることはありません。
  2. インスタの横の歯車をタップし、「DM以外のタブ」をオンにします。リール・発見・ホームのフィード・おすすめ投稿が消え、DM とお知らせのタブが残ります。
  3. 必要なら「ブロック」タブで、公式のインスタをスクリーンタイムで止めます。1回2時間まで無料で、ブロック画面の「minulo で開く」から DM に移れます。

グループの DM も使えます。インスタの DM の一部だからです。通知は公式のインスタアプリから届くので、止めずにおけばいつもどおり届き、minulo の中で返信できます。minulo Pro では、寝る時間と起きる時間を決めるスリープモード、長いブロック、ハードモード、1日の上限が使えます。

minulo の弱いところも書いておきます。リールが消えるのは minulo の中だけで、公式アプリは変わりません。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は使えません。インスタでは、リールと発見のタブが1つのスイッチです。使えるのは iPhone と Mac（Mac 版は Safari と Chrome で使える）で、Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。
