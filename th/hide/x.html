วิธีซ่อนหน้าสำหรับคุณใน X โดยยังใช้ข้อความได้ (iPhone)

ด้วย minulo คุณยังใช้ X ได้ตามปกติ และซ่อนเฉพาะส่วนที่กินเวลา เช่น หน้าสำหรับคุณ หน้านี้อธิบายว่าซ่อนอะไรได้บ้างและตั้งค่าอย่างไร

อัปเดต 2026-11-05

ซ่อนอะไรใน X ได้บ้าง

เมื่อเปิด X ใน minulo คุณซ่อนรายการต่อไปนี้ได้ทีละรายการ และเปลี่ยนได้ทุกเมื่อ

  • สำหรับคุณ

ซ่อนแล้วอะไรยังใช้ได้อยู่

ข้อความ, การแจ้งเตือน และกำลังติดตาม เปิดได้ทันทีจากหน้าแรกของ minulo ส่วนที่คุณไม่ได้ซ่อนจะใช้งานได้เหมือนเว็บไซต์ X

ตั้งค่าอย่างไร

  1. ติดตั้ง minulo จาก App Store
  2. ที่หน้าแรก แตะ "เพิ่มบริการ" แล้วเลือก X
  3. แตะไอคอนฟันเฟืองข้าง X แล้วเปิดรายการที่ต้องการซ่อน
  4. ถ้าต้องการหยุดแอปทางการด้วย ให้เปิดแท็บ "บล็อก" อนุญาตเวลาหน้าจอ แล้วเลือก X ใน "แอปที่จะบล็อก"

แอป X ทางการจะเป็นอย่างไร

minulo ใช้เวลาหน้าจอ (Screen Time) ของ iPhone เพื่อไม่ให้แอป X ทางการเปิดได้ เมื่อคุณพยายามเปิด จะมีหน้าจอ "ถูกบล็อกอยู่" ขึ้นมา และปุ่ม "เปิดใน minulo" จะพาคุณไปที่ minulo การบล็อกใช้ได้ฟรี

ใช้ฟรีไหม

การซ่อนเนื้อหาใน X และการบล็อกแอปทางการใช้ได้ฟรี ส่วนโหมดนอนหลับที่ตั้งเวลานอนและเวลาตื่น โหมดเข้มงวด และขีดจำกัดรายวัน อยู่ใน minulo Pro

วิธีสลับไปที่กำลังติดตามและให้อยู่ที่นั่นต่อไป

  1. เปิด X แล้วไปที่หน้าแรก
  2. แตะ กำลังติดตาม ที่ด้านบน หรือปัดไปทางซ้ายจาก สำหรับคุณ
  3. ปิด X ตอนที่ยังอยู่ที่กำลังติดตาม

หน้าความช่วยเหลือของ X บอกว่า เมื่อคุณปิด X ขณะอยู่ที่แท็บสำหรับคุณหรือกำลังติดตาม แอปจะเปิดกลับมาที่ไทม์ไลน์ที่คุณเปิดไว้ล่าสุด ถ้าคุณแวะดูแท็บสำหรับคุณแม้แค่ครั้งเดียวแล้วปิดแอป ครั้งหน้าก็จะกลับไปที่สำหรับคุณ จึงควรสลับกลับมาก่อนปิดแอป

ปิดเสียงหัวข้อที่ดึงคุณเข้าไป

ถ้ามีหัวข้อหนึ่งที่คอยดึงคุณเข้าไปในสำหรับคุณ ให้ปิดเสียงหัวข้อนั้น ไปที่ การตั้งค่าและความเป็นส่วนตัว › ความเป็นส่วนตัวและความปลอดภัย › ปิดเสียงและปิดกั้น › คำที่ปิดเสียง (เข้าจากแท็บการแจ้งเตือนก็ได้) เพิ่มคำ แฮชแท็ก หรือ @ชื่อ แล้วเลือก ไทม์ไลน์หน้าแรก การแจ้งเตือน หรือทั้งสองอย่าง จากนั้นเลือกระยะเวลา ได้แก่ ตลอดไป 24 ชั่วโมง 7 วัน หรือ 30 วัน

หน้าความช่วยเหลือของ X ระบุว่าคำที่ปิดเสียงยังขึ้นในผลการค้นหา และการแจ้งเตือนที่คุณเปิดไว้สำหรับบัญชีใดบัญชีหนึ่งจะไม่ถูกปิดเสียง
