スマホ封印ボックスの代わりになる iPhone の設定とアプリ（2026年）

minulo なら、スマホを箱に入れなくても、リールとショートだけを消して、LINE や DM、地図は使えます（消す機能は無料）。

スマホ封印ボックスは、タイマーが切れるまでスマホを取り出せなくする箱です。勉強や仕事の間に手が伸びるのを止めるには確実ですが、閉じている間は電話も連絡も調べものもできません。部活やバイトの連絡が来る日、辞書や地図を使う日は使いにくくなります。箱を使わずに iPhone の中で止める方法を、止める強さの順に並べます。

2026-11-06

このページは minulo の開発者、北林 歩が書いています。比べている方法のひとつが自分のアプリなので、その点は割り引いて読んでください。個別の封印ボックスの商品は確かめていません。iPhone の設定は Apple の iPhone ユーザガイド（iOS 27 と iOS 26）を、minulo の機能は minulo のサイトの記載を 2026-11-02 に確かめました。

方法止まるもの使えるもの途中でやめるには
スマホ封印ボックススマホ全体箱に入っている間は使えないタイマーが切れるのを待つ（箱の作りによる）
iPhone のスクリーンタイムのスケジュール（iOS 26 は休止時間）［常に許可］に入れていないアプリ［常に許可］のアプリと連絡先スクリーンタイムのパスコードを入れる
minulo のブロック選んだ公式アプリほかのアプリと、minulo の中の SNS（リールやショートは消えたまま）無料は1回2時間まで。ハードモード（Pro）は解除に数分かかる
minulo で消すリール・発見・おすすめの投稿・ショート・TikTok のおすすめDM・検索・フォロー中自分でオフにするまで続く

箱の代わりに iPhone の設定で止める

  1. 設定アプリで［スクリーンタイム］→［スクリーンタイムのスケジュール］を押し、［スケジュール］をオンにします（iOS 27）。
  2. ［スケジュールを追加］から曜日を選び、勉強や仕事の時間枠を作ります。
  3. ［スクリーンタイム］の画面に戻って［常に許可］を押し、電話・LINE・地図など止めたくないアプリと連絡先を入れます。
  4. ［パスコードと管理］→［スクリーンタイム設定をロック］でパスコードを決めます。家族や友だちに入れてもらえば、自分では外しにくくなります。

iOS 26 では「休止時間」の［スケジュール］で時間を決め、［休止時間中にブロック］をオンにします。Apple のガイドでは、これがオフだとリマインダーが出るだけで使い続けられます。

止めたいのが SNS だけなら minulo

封印ボックスを使う理由が「勉強中にインスタや YouTube を開いてしまう」なら、止めるのは SNS だけで足ります。

  1. App Store から minulo を入れます。
  2. minulo の中でインスタや YouTube、TikTok を開き、それぞれのログイン画面でログインします。minulo はパスワードを受け取りません。
  3. インスタの横の歯車で［リールと発見タブ］や［おすすめの投稿］を、YouTube の歯車で［ショートとおすすめを非表示］を、TikTok の歯車で［おすすめ］を選びます。消すのは無料です。
  4. 「ブロック」タブで公式のインスタや YouTube、TikTok を選んでブロックを始めます。アイコンを押すと「ブロック中です」の画面が出て、「minulo で開く」から移れます。無料では1回2時間までです。

無料のブロックは1回2時間までで、終わったらすぐ次を始められます。寝る時間と起きる時間を決めるスリープモード、仕事の曜日と時間を決めるワークモード、2時間より長いブロック、解除にわざと数分かかるハードモード（文を書き写す・暗算に答える・60秒待つ）は minulo Pro です（日本は月1,480円・年6,800円）。

minulo の弱いところも書いておきます。リールやショートが消えるのは minulo の中だけで、公式アプリは変わりません。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は使えません。minulo は iPhone のアプリで、Safari と Chrome で使える Mac 版もあります。Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

箱のほうが合う人

スマホに触ること自体をやめたい人、通知を見るだけで集中が切れる人は、箱のほうが合います。minulo もスクリーンタイムも、スマホを手に取れる状態のまま止める方法だからです。両方を使い分けて、試験前の数時間は箱、ふだんの勉強や夜は iPhone の設定、という分け方もできます。

スマホ封印ボックスとアプリはどちらがいい？

何を止めたいかで変わります。スマホ全体を手放したいなら箱、連絡や地図は使いたくて SNS だけ止めたいならアプリです。minulo ならリールやショートだけ消して DM は使えます（消すのは無料）。

スマホを箱に入れている間、連絡はどうなる？

箱に入っている間は、スマホを操作できないので電話にも LINE にも出られません。連絡を受けたいなら、iPhone のスクリーンタイムのスケジュールで［常に許可］に入れたアプリだけ使えるようにする方法があります。

アプリでも自分で解除できない仕組みはある？

自分用のスクリーンタイムは、パスコードを知っていれば外せます。minulo のハードモード（Pro）は、解除に文を書き写す・暗算に答える・60秒待つの3つが必要で、わざと数分かかるようにしています。

受験勉強中だけ SNS を止めたい

勉強の時間だけ止めるなら、minulo のブロック（無料は1回2時間まで）か、スクリーンタイムのスケジュールが使えます。テスト期間の止め方は「テスト期間・受験前にインスタをやめる方法」にまとめています。
