minulo と Spool の違い：Spool の代わりになる？リールを消すか、開く前に AI に理由を話すか（2026年）

Spool の代わりになるのが minulo で、TikTok を含む10の SNS でリール・ショート・おすすめ投稿を消し、DM はそのまま使えます（消すのは無料）。Spool はブロックしたアプリを開く前に AI に理由を話す仕組みで、Full Access は日本で週800円から、年7,000円です。

Spool（Spooli Inc）は、やり方が違います。ブロックしたアプリを開く前に「なぜ開きたいのか」を AI に話す必要があり、同じ言い訳を何度も使うと自動でロックされます。ほかに、Spool の中のブラウザ「Focus Web」で、Instagram・YouTube・X・Snapchat・Facebook のリールやショートなどを隠せます。フルアクセスは、日本の App Store で週800円か1,280円、または年7,000円です。

2026-11-04

このページは minulo の開発者・北林歩（Ayumu Kitabayashi）が書いています。自分のアプリと比べているので、その点は割り引いて読んでください。Spool については、米国・日本・韓国の App Store のページ（2026-11-02 に出た版 5.5）と公式サイト（thespoolapp.com の Focus Web のページと「Spool vs SocialLite」の記事）をもとに、2026-11-04 に確かめました。Spool の機能名は英語のまま書いています。機能や料金は変わることがあります。

minulo が見せるのは公式アプリではなく各 SNS のウェブ版なので、画面は公式アプリと少し違います。公式アプリを minulo で止めている間は、その通知も届きません。

Spool の代わりに minulo は使える？

リールとショートを消して DM は使えるようにしたいなら、使えます。minulo は TikTok を含む10の SNS で消せて、消すのは無料です。アプリを開く前に理由を話したり、AI の分析や友だちの見守りで、スマホをつい手に取る癖そのものを見直したりしたいなら、それは Spool が得意なことで、minulo にはその機能はありません。

Spool は無料？

ダウンロードは無料です。日本の App Store の説明では、フルアクセスは週800円か1,280円（購入前に出るプランによる）、または年7,000円で、7日間無料の年額プランが出ることもあると書いてあります。米国では週4.99ドルか年44.99ドルで、公式サイトには通常のプランに無料体験はないとあります。サブスクなしでどこまで使えるかは、App Store の説明には書いてありません。minulo では、リール・ショート・おすすめ投稿を消すのは無料です。

Spool で公式の Instagram アプリのリールは消える？

消えません。公式サイトによると、Focus Web は Spool の中で Instagram のウェブ版を絞り込むもので、公式アプリは変えません。送られてきたリールのリンクは開いてしまうこともあると書いてあります。minulo も公式アプリには手を加えず、Instagram のウェブ版を minulo の中で開いてリールを隠します。公式アプリはスクリーンタイムでロックできます。

Spool は TikTok に使える？

公式サイトの Focus Web の一覧に TikTok はありません（2026-11-04 確認）。App Store の説明にはアプリのブロックと、ブロックしたアプリを開く前に理由を話す仕組みがありますが、TikTok の「おすすめ」だけを消せるかは確かめられませんでした。minulo では TikTok の「おすすめ」を消してメッセージは使え、TikTok を DM だけにする設定もあります。

Spool の「Spool vs SocialLite」の記事には何が書いてある？

Spool の創業者 Prafull Sharma さんが書いた記事で、最終更新は 2026-10-17 です。SocialLite は主に SNS をすっきり見るためのものだとし、Spool は Focus Web での絞り込みに、公式アプリを開く前に声で理由を話す仕組み、話した理由の AI 分析、友だちの見守りを組み合わせたものだと説明しています。SocialLite のほうが対応する SNS が多く保護者向けの機能もあること、Spool はいまのところ iPhone だけであることも書いています。

実績があるのはどっち？

米国では Spool です。2025年10月から App Store にあり、米国の評価は175件・平均4.4です（2026-11-04）。minulo は2026年9月に出たばかりで、米国の評価はまだ1件です。日本では Spool が2件、minulo が4件、韓国では Spool が2件、minulo が14件です。
