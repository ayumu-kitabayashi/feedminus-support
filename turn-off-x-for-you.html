  1. X を開き、ホームにします。
  2. 上の［フォロー中］を押すか、［おすすめ］から左にスワイプします。

おすすめタブは消せる？

2026年10月の時点で、X のヘルプには消す方法が見つかりませんでした。ホームには必ず2つのタブがあります。X は、おすすめのポストやアカウント、人気のあるコンテンツをタイムラインに足すことがあり、プッシュ通知や通知タブでもおすすめを送ると説明しています。そのため［フォロー中］にしていても、フォローしていない人のポストが目に入ることはあります。

つい見てしまう話題をミュートする

決まった話題でいつも［おすすめ］に引き込まれるなら、その言葉をミュートします。［設定とプライバシー］→［プライバシーとセキュリティ］→［ミュートとブロック］→［ミュートするキーワード］を開き（通知タブからも行けます）、言葉・ハッシュタグ・@ユーザー名を入れて、ホームタイムライン・通知のどちらか、または両方を選びます。期間は無期限・24時間・7日・30日から選べます。

X のヘルプによると、ミュートしたキーワードも検索には出ます。また、特定のアカウントの通知をオンにしている場合、その通知はミュートされません。

minulo は、アプリの中で X の公式のウェブ版を開きます。［フォロー中を先に開く］がオンだと、［おすすめ］タブが消えて、ホームが［フォロー中］に切り替わります。［検索を非表示］［動画とGrokを非表示］もあります。どれも最初からオンで、X の横の歯車から1つずつ切れます。メッセージ・通知・フォロー中は、minulo のホーム画面からすぐ開けます。

X のおすすめタブは消せる？

2026年10月の時点で、X のヘルプには消す設定が見つかりませんでした。［フォロー中］に切り替えることはでき、閉じたときに選んでいたタイムラインが次も表示されます。毎回おすすめタブのない状態で開きたいなら、おすすめタブを消して X を開けるアプリを使います。minulo なら無料です。

X を開いたときに［フォロー中］から始めるには？

ホームの上で［フォロー中］に切り替え、そのまま X を閉じます。X のヘルプによると、閉じたときに選んでいたタイムラインが次に開いたときも表示されます。閉じる前に［おすすめ］を見ると、次は［おすすめ］から始まります。

X がすぐ［おすすめ］に戻るのはなぜ？

X は、閉じたときに見ていたタブを覚えています。少しでも［おすすめ］にスワイプしてから閉じると、次はそのタブで開きます。おすすめのポストが通知で届くこともあり、そこからおすすめに入ってしまうこともあります。

キーワードをミュートすると［おすすめ］からも消える？

ミュートするキーワードはホームタイムラインと通知に効くので、その言葉を含むポストはホームに出なくなります。検索には出ます。特定のアカウントの通知をオンにしている場合は、その通知はミュートされません。1つずつ登録し、無期限・24時間・7日・30日から期間を選べます。

X にはその設定がありません。スクリーンタイムで止めるとアプリごと止まり、DM も使えなくなります。minulo なら、X はメッセージから開き、［おすすめ］タブは消えています。検索・動画・Grok も消せます。消すのは無料です。
