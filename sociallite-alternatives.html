SocialLite（Block Reels & Shorts）の代わりになるアプリ（iPhone）：リールとショートを消して DM は使える（2026年）

SocialLite の代わりになる iPhone アプリなら、いちばん近いのは minulo です。リールとショートを消す機能は無料で、SocialLite と同じく DM は残せます。

このページで扱うのは、App Store の iPhone アプリ「SocialLite-Block Reels&Shorts」です。名前の似た SNS のリーダーアプリのことではありません。

公式アプリはスクリーンタイムで止められ、TikTok を含む10のSNSに対応しています。SocialLite は、ショート動画のフィード・おすすめ・発見ページを消して DM は残すアプリで、公式アプリを止めて SocialLite に案内することもできます。同じ仕組みのアプリには、minulo・UNDOOMED・Awhile・LoomWeb があります。どれも自前の画面で SNS を開き、その部分を消します。ScrollGuard と Nope は Safari の機能拡張です。minulo には Safari と Chrome で使える Mac 版もあります。SocialLite は評価の数がずっと多く、Instagram と Snapchat のプッシュ通知にも対応しています。

  1. App Store から minulo を入れ、その中でインスタを開きます。
  2. インスタの横の歯車をタップし、リールと発見のタブを隠すスイッチをオンにします。DM だけにしたいなら「DM以外のタブ」をオンにします。DM は使えて、消すのは無料です。
  3. YouTube と TikTok も「サービスを追加」から足し、ショートと「おすすめ」を消します。
  4. SocialLite と同じく、公式アプリも止められます。「ブロック」タブでスクリーンタイムで止めると（1回2時間まで無料）、アイコンを押したときにブロック画面が出て、「minulo で開く」から minulo に移れます。

SocialLite の代わりになるアプリは？

いちばん近いのは minulo です。SocialLite と同じくリールとショートを消して DM は使え、消す機能は無料です。ほかは何を求めるかで変わります。SocialLite と同じく、リールとショートを消した画面で SNS を開き、DM は使えるアプリなら、minulo・UNDOOMED・Awhile・LoomWeb があります。この中で対応SNSがいちばん多いのは minulo（TikTok・Threads・Pinterest・LinkedIn を含む10）で、公式アプリを止めることもできます。Awhile は Instagram だけです。Safari だけで見るなら、機能拡張の ScrollGuard と Nope があります。

SocialLite から乗り換えるなら、どのアプリがいい？

いちばん近いのは minulo です。リールとショートを消して DM は使え、公式アプリをスクリーンタイムで止めて自分の画面に案内でき、消す機能は無料です。TikTok・Threads・Pinterest・LinkedIn にも対応し、Safari と Chrome で使える Mac 版もあります。SocialLite は評価の数がずっと多く（米国の App Store で17,763件・平均4.7、2026-11-11 確認）、minulo に無い Instagram と Snapchat のプッシュ通知があります。SocialLite は無料でダウンロードできますが、新しく始める人は有料のプランに入らないと使えません（公式 FAQ）。料金ページにある米国の標準の値段は月9.99ドルか年29.99ドルで、App Store にはほかに月6.99〜17.99ドル・年19.99〜47.90ドル、ファミリープラン月12.99ドルも並んでいます（2026-11-11 確認）。minulo の Pro は米国で月9.99ドルか年39.99ドルです。インスタの通知が欠かせないなら、SocialLite のままが合っています。

minulo と SocialLite の違いは？

無料で使える SocialLite の代わりは？

StillTabs はアプリ内課金なしの無料アプリで、YouTube・Instagram・Facebook・X・Reddit のショートとリールを消せますが、TikTok には対応していません。Nope はアプリ内課金も無く完全に無料ですが、Safari の instagram.com と youtube.com でしか効きません。minulo は、リール・ショート・おすすめ投稿を消す機能が無料で、スリープモード、ワークモードやハードモードなどが Pro です。SocialLite はダウンロードは無料ですが、新しく始める人は有料のプランに入らないと使えません（公式 FAQ・2026-11-11 確認）。

SocialLite から乗り換えるときに迷いやすいところ

SocialLite を消せば、購読も止まると思っていた
アプリを削除しても、App Store の購読は続きます。止めるときは、iPhone の「設定」で自分の名前から「サブスクリプション」を開き、SocialLite を選んで解約します。

minulo に移ったら、インスタの通知が来なくなった
minulo には自分で通知を出す仕組みがありません。公式アプリをブロックしている間は、公式アプリの通知も止まります。通知を受けたいなら、ブロックは使わずに、リールを消す機能だけを使う手もあります。Instagram と Snapchat の通知を SocialLite で受けるのが欠かせないなら、乗り換えないほうが合っています。

ログインはやり直しになる？
SocialLite でログインしていても、minulo では別にログインします。minulo の中で開いた各SNSの公式のログイン画面に入れるので、minulo は ID もパスワードも受け取りません。

minulo でできないこと
ストーリーズを載せる、音声メッセージを送る、通話するといった操作は SNS のウェブ版に無く、minulo の中ではできません。そのときは公式アプリを開くことになります。iPad 版と Android 版もありません。
