在電腦上隱藏 YouTube Shorts 的瀏覽器擴充功能（2026）

在 Mac 上，可以用 minulo 的 Mac App（Safari、Chrome）隱藏 YouTube Shorts。在 Chrome、Firefox 或 Edge 上，也可以用有隱藏開關的 Unhook 擴充功能。如果要在 Chrome 用 minulo，先安裝 Mac App，再從 Mac App 裡加入 Chrome 擴充功能。

YouTube 本身沒有在 youtube.com 首頁拿掉 Shorts 的設定。在 Shorts 區塊選「不感興趣」只是對推薦內容的意見回饋，區塊可能會回來，所以想用設定的方式隱藏 Shorts，就需要擴充功能。Unhook 官網有 Chrome、Firefox 和 Edge 的安裝按鈕，沒有 Safari 的。

  1. 在 Mac 上打開 minulo.app 首頁，用 macOS 的下載按鈕安裝 minulo 的 Mac App。Mac App 目前只有日文介面。
  2. 在 Safari 打開 youtube.com。
  3. 要用 Chrome 的話，從 Mac App 裡加入 Chrome 擴充功能，再在 Chrome 打開 youtube.com。
  4. 在 iPhone 上，在 minulo 裡打開 YouTube，點齒輪，開啟「Shorts」。隱藏免費。

用 Unhook 隱藏 Shorts（Chrome、Firefox、Edge）

Unhook 官網把它介紹成不受干擾地看 YouTube 的工具，可以擋掉推薦動態、留言等內容，並提供 Chrome、Firefox 和 Edge 的安裝按鈕。它在 Chrome 線上應用程式商店的頁面有大約 30 個開關，包括「Hide YouTube Shorts」、首頁動態、側邊推薦影片、片尾推薦、留言，以及探索和發燒影片。我們在 2026-11-02 查看時，商店頁面顯示 1,000,000 位使用者、4.6K 則評分平均 4.9、2026 年 3 月 22 日更新（1.6.9 版）、沒有標示價格，並請求捐款。

官網和商店頁面都沒有提到 Safari。唯一提到的手機用法，是在 Android 的 Firefox 上使用行動版 YouTube（m.youtube.com）。Chrome 線上應用程式商店上也有其他擴充功能表示能隱藏 Shorts，但本頁只列出我們查看過官網和商店頁面的 Unhook。我們沒有實際測試 Unhook。

Mac 上的 Safari 和 Chrome：minulo 的 Mac App

minulo 有可在 Safari 和 Chrome 使用的 Mac 版。要先裝 Mac App：從 minulo.app 首頁安裝，想用 Chrome 的話，再從 Mac App 裡加入 Chrome 擴充功能。Mac App 目前只有日文介面。

minulo 的隱私權政策（日文）寫著，Mac App 只讀取瀏覽器中開啟頁面的網址，當那個頁面是進入動態或短影音的入口時，會把你帶到你選擇的地方。Mac App 以及 Chrome 和 Safari 擴充功能都不含分析工具，擴充功能也沒有和外部伺服器通訊的程式碼。本頁不介紹 Mac App 會隱藏 YouTube 的哪些部分。minulo 支援 iPhone 和 Mac，沒有 Windows 版，也沒有 Android 版。

電腦上 YouTube 本身的設定能做什麼

在 youtube.com 上，可以按一下首頁某個區塊（包括 Shorts 區塊）標題旁的「更多」，選擇「不感興趣」。YouTube 說明把它描述為調整推薦內容的意見回饋，沒有說區塊會消失多久。另一個方法是觀看記錄：YouTube 表示，如果關閉觀看記錄，而且近期沒有記錄，首頁的推薦內容就會被移除。詳見怎麼拿掉 YouTube 網站首頁的 Shorts 區塊。

在 iPhone 上

minulo 會在 App 裡打開 YouTube 自己的網站，隱藏你開啟的項目，例如「Shorts」和「首頁推薦」。訂閱內容、稍後觀看和搜尋照常能用，隱藏免費，沒有時間限制。官方 YouTube App 不會改變，但可以在「封鎖」分頁鎖定它（免費，每次封鎖最多 2 小時），封鎖畫面上有「在 minulo 中開啟」按鈕。

minulo 鎖定官方 App 期間，收不到那個 App 的通知，minulo 也不會代替它傳送通知。minulo 是新 App，評分還很少。請看minulo 做不到的事。

哪個擴充功能能隱藏 YouTube Shorts？

在 Chrome、Firefox 和 Edge 上有 Unhook，它在 Chrome 線上應用程式商店的頁面有「Hide YouTube Shorts」開關。在 Mac 的 Safari 和 Chrome 上，可以用 minulo 的 Mac App。先安裝 Mac App，再從 Mac App 裡加入 Chrome 擴充功能。

Unhook 能在 Safari 上用嗎？

Unhook 官網只有 Chrome、Firefox 和 Edge 的按鈕，Chrome 線上應用程式商店頁面也沒有提到 Safari。在 Mac 的 Safari 上，可以用 minulo 的 Mac App。

怎麼在 Chrome 上用 minulo？

先從 minulo.app 首頁安裝 Mac App，再從 Mac App 裡加入 Chrome 擴充功能。可以在 Mac 上的 Chrome 使用，Mac App 目前只有日文介面。

不用擴充功能，能在 youtube.com 隱藏 Shorts 嗎？

YouTube 沒有能拿掉 Shorts 的設定。在 Shorts 區塊選「不感興趣」可以讓它變少，但 YouTube 說明把它描述為意見回饋，區塊可能會回來。

怎麼在 iPhone 上隱藏 YouTube Shorts？

在 minulo 裡打開 YouTube，點齒輪，開啟「Shorts」。隱藏免費，訂閱內容和搜尋照常能用。
