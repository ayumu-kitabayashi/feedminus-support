怎麼隱藏 X 的推薦、保留訊息（iPhone）

用 minulo，你可以照常使用 X，只隱藏推薦這類佔用時間的部分。以下說明可以隱藏哪些內容，以及怎麼設定。

2026-10-27

X 上可以隱藏什麼？

在 minulo 裡打開 X 時，可以逐項隱藏以下內容，隨時都能更改。

  • 推薦

隱藏之後，還能用哪些功能？

訊息、通知、追蹤中可以直接從 minulo 的主畫面打開。沒有隱藏的部分，用起來和 X 網站一樣。

怎麼設定？

  1. 從 App Store 安裝 minulo。
  2. 在主畫面點「新增服務」，選擇 X。
  3. 點 X 旁邊的齒輪，開啟想隱藏的項目。
  4. 如果也想擋住官方 App，打開「封鎖」分頁，允許「螢幕使用時間」，然後在「要封鎖的 App」選擇 X。

官方 X App 會怎樣？

minulo 會透過 iPhone 的「螢幕使用時間」讓官方 X App 打不開。想打開時會出現「封鎖中」畫面，點「在 minulo 中開啟」按鈕就會回到 minulo。封鎖是免費的。

要錢嗎？

在 X 隱藏內容和封鎖官方 App 都是免費的。依星期和時段自動切換的排程、嚴格模式和多份封鎖清單屬於 minulo Pro。
