iPhone 上怎麼關掉 Pinterest 的推薦（2026）

minulo 在 iPhone 上免費隱藏 Pinterest 的首頁動態：在 minulo 裡打開 Pinterest，「推薦」開關會隱藏為你挑選的 Pin 動態，已儲存的 Pin 和訊息都還在。

Pinterest 自己的工具只能讓推薦變少，不能讓它消失：在 Pin 上選 See fewer like this（英文介面的名稱）、取消追蹤那個 Pin 來自的圖版或帳號，以及「縮小建議範圍」，在那裡可以關掉根據你看過的 Pin 所提供的推薦。我們在 Pinterest 說明中找不到關掉首頁動態的設定。

  1. 安裝 minulo，點「新增服務」，選擇 Pinterest。
  2. 點 Pinterest 旁的齒輪。「推薦」會隱藏首頁動態，以及今日、影片和靈感。「影片 Pin」也能用同樣的方式隱藏。
  3. 從 minulo 的主畫面打開已儲存和訊息。
  4. 在「封鎖」分頁選擇官方 Pinterest App，免費，每次最多 2 小時。

Pinterest 的推薦從哪裡來

Pinterest 把首頁動態稱為「為你挑選的 Pin 所組成的動態」。說明表示，挑選的依據是你追蹤的人、你建立的圖版、你互動過的 Pin，以及你的搜尋。所以每一次儲存和搜尋，都會影響首頁動態顯示的內容。

Pinterest 能讓你做的事

See fewer like this：點首頁動態中 Pin 上的省略符號圖示，選擇 See less（或 See fewer like this）。Pinterest 也建議取消追蹤那個 Pin 來自的圖版、主題或帳號。

縮小建議範圍：在 App 裡點右下角的個人檔案照片，點右上角的更多選項圖示，選擇「縮小建議範圍」。「活動」分頁可以關掉根據你看過的 Pin 所提供的推薦。「AI 內容」分頁有「顯示 AI 內容」開關，也可以依主題設定 AI 生成的 Pin。Pinterest 表示，這些設定不會改變你看到的廣告。

這些都沒有被說明能關掉首頁動態。你還是會看到為你挑選的 Pin，只是某一類變少了。

用 minulo 隱藏首頁動態

minulo 會在 App 裡打開 Pinterest 自己的網站，隱藏你開啟的項目。「推薦」會隱藏首頁動態，以及今日、影片和靈感，預設是開啟的。你也可以隱藏「影片 Pin」和 Pin 下方的相關推薦，如果只想看自己的圖版，也可以隱藏搜尋框。已儲存和訊息可以直接從 minulo 的主畫面打開。隱藏功能免費，沒有時間限制。

你可以在「封鎖」分頁用「螢幕使用時間」鎖定官方 Pinterest App，免費，每次最多 2 小時。睡眠模式、工作時間和嚴格模式屬於 minulo Pro。

先把限制說清楚，方便你判斷：隱藏的部分只有在 minulo 裡才會隱藏，官方 App 不會改變。minulo 封鎖官方 App 期間，收不到那個 App 的通知，minulo 自己也不會傳通知。minulo 是 iPhone App，另有可在 Safari 和 Chrome 使用的 Mac 版，目前還沒有 Android 版，而且是新 App，評分還很少。請看 minulo 做不到的事。

可以關掉 Pinterest 的推薦嗎？

從 2026 年 11 月的 Pinterest 說明來看，無法完全關掉。你可以在「縮小建議範圍」關掉根據你看過的 Pin 所提供的推薦，也可以少看類似某個 Pin 的內容。在 minulo 裡，「推薦」開關會免費隱藏首頁動態。

在「縮小建議範圍」關掉「活動」會怎樣？

Pinterest 說明它會關掉根據你看過的 Pin 所提供的推薦。根據你的儲存、圖版和搜尋的推薦，並沒有被說明會停止。

怎麼在 Pinterest 少看類似某個 Pin 的內容？

點首頁動態中那個 Pin 上的省略符號圖示，選擇 See less（網頁版是 See fewer like this）。

可以只用 Pinterest 看已儲存的 Pin 嗎？

在 minulo 裡可以。保持「推薦」開啟，從 minulo 的主畫面打開已儲存和訊息。搜尋框也可以隱藏。

minulo 會改變官方 Pinterest App 嗎？

不會。首頁動態只在 minulo 裡隱藏。不想打開官方 App，可以在「封鎖」分頁鎖定它，免費，每次最多 2 小時。
