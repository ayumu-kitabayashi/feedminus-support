minulo と Intent の違い：リールを消して DM は無料で使える、Intent の代わりのアプリ（2026年）

Intent と minulo は、どちらも SNS のサイトを自分のアプリの中で開き、リールとショートを消します。Intent は SNS を開く前に目的を選ばせるアプリで、小紅書（Xiaohongshu）や NAVER を含む12の SNS に対応していますが、メッセージの機能には Intent Pro が必要です。先に目的を選ぶやり方が好きな人や、その2つの SNS を使う人は Intent です。フィードなしで DM を使いたいのが一番の目的で、そのためにお金を払いたくない人は minulo です。

Intent（App Store での名前は「Intent: Block Reels & Shorts」、開発は Evergoods Holdings LLC）は、なぜ SNS を開くのか（メッセージ・検索・時間を決めた閲覧）を選ぶところから始まるアプリです。対応しているリール・ショートと、おすすめへの導線を隠し、説明には、知らないうちに制限のないフィードに入ってしまうことはないとあります。各 SNS の公式サイトに、アプリの中でログインして使います。App Store には Intent という名前のアプリがほかにもいくつかあり、習慣の記録アプリや、開く前にひと呼吸おかせるアプリなどがあります。このページで比べているのは、リールとショートをブロックするものです。

Intent が合う人

  • 小紅書（Xiaohongshu）や NAVER を使う人
  • 開くたびに目的（メッセージ・検索・時間を決めた閲覧）を選ぶやり方が好きな人
  • セッションのタイマー、集中と睡眠のルーティン、キャプションの下書きがほしい人
  • 安い Pro（月2.99ドル・年19.99ドル）がいい人、iPad を使う人

minulo が合う人

  • Instagram や TikTok の DM を、フィードなしで無料で使いたい人
  • 公式アプリはロックして minulo から開くようにしたい人
  • Mac を使っている人
  • 開いた SNS のリール・ショート・おすすめ投稿をただ消してくれる、シンプルなアプリがいい人

minulo が見せるのは公式アプリではなく各 SNS のウェブ版なので、画面は公式アプリと少し違います。公式アプリを minulo でロックしている間は、その通知も届きません。ただし 1.0.19 からは、Pro の方はベータ機能の DM の通知をオンにすると、Instagram を止めている間も Instagram の DM の通知だけは届きます（スリープモード・ワークモードの間と、1日の上限に達した後は届きません）。minulo は出たばかりで、評価はまだ少ないです。

Intent の代わりに minulo は使える？

リールなしで DM を使うのが一番の目的なら使えます。Intent ではメッセージは Intent Pro の機能ですが、minulo では DM はお金を払わずにそのまま使え、Instagram と TikTok を DM だけにする無料の設定もあります。Intent は小紅書（Xiaohongshu）や NAVER を含むより多くの SNS に対応し、Pro も安く、開くたびに目的を選ばせます。そのやり方が合う人もいます。

Intent は無料？

一部は無料です。米国の App Store の説明には、検索と時間を決めた閲覧は無料で、メッセージ・通知・投稿・プロフィールと細かいカスタマイズには Intent Pro が必要とあり、Pro は月2.99ドル・年19.99ドルです（2026-11-04 確認）。minulo ではリール・ショート・おすすめ投稿を消す機能は無料で、DM もお金を払わずに使えます。Pro は米国で月9.99ドル・年39.99ドル（日本は月1,480円・年6,800円）です。

Intent はどの SNS に対応している？

説明には Instagram・YouTube・TikTok・Threads・Facebook・Xiaohongshu・Reddit・X・Pinterest・NAVER・Snapchat・LinkedIn が挙がっていて、ウェブの機能は SNS・地域・アカウントによって違うとあります（2026-11-04 確認）。minulo は Instagram・YouTube・TikTok・X・Threads・Facebook・Pinterest・Reddit・LinkedIn・Snapchat に対応しています。
