旅行中に SNS を休んで、地図と連絡は使う方法（iPhone・2026年）

minulo なら、リール・ショートなどのフィードを無料で消したまま DM は使え、公式のインスタ・TikTok・YouTube アプリも無料で止められる（1回2時間まで）ので、旅行中もフィードを見ずに友だちと連絡が取れます。iPhone の機能では、マップのオフラインマップを入れておく、アプリごとにモバイルデータ通信を切って Wi-Fi のときだけ使えるようにする、［休止時間］で LINE と地図を［常に許可］に入れる、の3つが使えます。minulo は各 SNS のウェブ版を開くので、ウェブ版と同じように Wi-Fi かモバイルデータ通信が要ります。

2026-10-27

このページは minulo の開発者、北林 歩が書いています。手順は Apple の iPhone ユーザガイドで 2026-10-27 に確かめました。メニューの名前は、更新で変わることがあります。

方法できること気をつけること
マップのオフラインマップApple によると、Wi-Fi やモバイルデータ通信が無くても経路や場所の情報が見られる一部の国や地域では使えない
アプリごとにモバイルデータ通信をオフそのアプリは Wi-Fi のときだけ使えるホテルやカフェの Wi-Fi では開ける
データローミングをオフApple によると、ローミングの請求を避けられる海外では、どのアプリもモバイルデータ通信が使えなくなる
休止時間＋［常に許可］許可した通話・メッセージ・アプリだけ使える手動でオンにすると明日まで。［休止時間中にブロック］にはパスコードが要る
minuloフィードを消して DM は使える（無料）。公式アプリを1回2時間まで止める（無料）通信が要る。止めたアプリの通知は届かない

出かける前に：オフラインマップを入れる

  1. マップアプリを開きます。
  2. 検索フィールドの横の写真かイニシャルをタップし、［オフラインマップ］→［オフラインマップを追加］の順にタップして、場所を入れるか［現在地］をタップします。
  3. 範囲を調整して［ダウンロード］をタップします。

Apple によると、オフラインマップがあれば、Wi-Fi やモバイルデータ通信が使えないときも、場所の営業時間や評価、徒歩や交通機関の経路、到着予定時刻が見られます。一部の国や地域では使えないので、旅行の前に確かめておきます。

フィードは Wi-Fi のときだけにする

  1. ［設定］→［モバイル通信］をタップします。
  2. 下のアプリの一覧で、インスタ・TikTok・YouTube をオフにします。

Apple によると、特定のアプリでモバイルデータ通信がオフなら、iPhone はそのアプリに Wi-Fi だけを使います。外を歩いている間はフィードが読み込まれず、マップと LINE は使えます。Apple は、旅行中は［モバイルデータ通信のオプション］の［データローミング］をオフにすればローミングの請求を避けられるとも書いていますが、海外ではすべてのアプリでモバイルデータ通信が使えなくなるので、Wi-Fi・海外用のプラン・旅行用 eSIM のどれかを用意します。

旅行中の休止時間

  1. ［設定］→［スクリーンタイム］→［常に許可］で、マップ・LINE などのメッセージアプリ・チケットのアプリを足します。
  2. ［休止時間］をタップし、毎朝［明日まで“休止時間”をオンにする］をタップするか、［スケジュール］をオンにして旅行中の時間帯を決めます。
  3. ほかのアプリを完全に止めたいなら、スクリーンタイムパスコードを設定して［休止時間中にブロック］をオンにします。

Apple によると、休止時間中は許可した通話・メッセージ・アプリだけが使えます。旅行のあとも続けたいなら オフラインにならずに1週間デジタルデトックスする方法へ。

連絡は残して、フィードは minulo で消す

  1. minulo にインスタ・TikTok・YouTube を足し、リールと発見タブ、ショート、TikTok のおすすめなど、消すものをオンにします。
  2. 家の友だちとの連絡は、minulo の中の DM で取ります。
  3. 公式アプリは「ブロック」タブで止めます。1回2時間まで無料で、minulo Pro なら曜日と時間帯の予定と長いブロックが使えます。

消すのは無料で、時間の制限もありません。minulo は各 SNS のウェブ版をアプリの中で開くので、ウェブ版と同じく通信が要ります。

minulo の弱いところも書いておきます。リールやショートが消えるのは minulo の中だけで、公式アプリは変わりません。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は使えません。minulo は iPhone のアプリで、Safari と Chrome で使える Mac 版もあります。Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

旅行中に SNS を休んで、連絡だけは取るには？

minulo でフィードを消せば無料で DM は使え、公式アプリも1回2時間まで無料で止められます。iPhone の機能なら、休止時間で LINE と地図のアプリを［常に許可］に入れれば、それだけが使えます。

旅行中、通信なしで地図を使える？

マップならオフラインマップを出かける前にダウンロードしておけば使えます。Apple によると、一部の国や地域では使えません。

海外でインスタにデータを使わせないには？

［設定］→［モバイル通信］で、アプリの一覧のインスタをオフにします。Apple によると、そのアプリは Wi-Fi だけを使うようになります。

データローミングはオフにしたほうがいい？

Apple は、旅行中はデータローミングをオフにすればローミングの請求を避けられると書いています。海外ではすべてのアプリでモバイルデータ通信が使えなくなるので、Wi-Fi・海外用のプラン・旅行用 eSIM を用意します。

休止時間中もメッセージは届く？

Apple によると、休止時間中は許可した通話・メッセージ・アプリだけが使えます。使うメッセージアプリを［常に許可］に入れておきます。

minulo はオフラインで使える？

使えません。minulo は各 SNS のウェブ版をアプリの中で開くので、ウェブ版と同じく Wi-Fi かモバイルデータ通信が要ります。
