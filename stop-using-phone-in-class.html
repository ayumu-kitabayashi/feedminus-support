授業中にインスタや TikTok を見てしまうときの設定（iPhone・2026年）

minulo なら、公式のインスタ・TikTok・YouTube アプリをスクリーンタイムで無料で止められ（1回2時間まで、授業1コマ分ほど）、minulo Pro なら選んだ曜日と時間帯にひとりでにブロックが始まります。iPhone の機能では、集中モードを決まった時刻や場所で自動でオンにして、それらのアプリが無いホーム画面のページに切り替えられます。ただ Apple は集中モードを通知を減らす機能と説明していて、アプリが開けなくなるとは書いていません。授業のあいだアプリを開けなくしたいなら、［休止時間］と［休止時間中にブロック］か、ブロックアプリを使います。

2026-10-27

このページは minulo の開発者、北林 歩が書いています。手順は Apple の iPhone ユーザガイドで 2026-10-27 に確かめました。メニューの名前は、更新で変わることがあります。

方法授業の時間に自動で始まるアプリが開けなくなる気をつけること
集中モード＋スケジュールはい（時刻・場所・特定のアプリ）Apple のガイドには書かれていない通知を減らし、ホーム画面のページを切り替えられる
休止時間（曜日別に設定）はい（曜日ごとに時刻を変えられる）［休止時間中にブロック］なら、［常に許可］以外は開けない授業で使うアプリ（LINE やノートなど）は［常に許可］に入れる
アプリ使用時間の制限いいえ（1日の合計）Apple によると、デフォルトでは制限に達しても無視できる時間割とは合わない
minuloPro なら、決めた曜日と時間帯公式アプリをスクリーンタイムで止める無料は自分で始める1回2時間まで。グループ DM は minulo の中で使える

授業の時間に集中モードを入れる

  1. ［設定］→［集中モード］で、［仕事］などの集中モードをタップするか、自分用のものを作ります。
  2. ［アプリ］で、通知を許可するアプリを選びます。インスタと TikTok は入れません。
  3. 集中モードがオンのときに切り替えるホーム画面のページを選び、それらのアプリが無いページにします。
  4. ［スケジュールを追加］をタップします。Apple によると、設定した時間・場所・特定のアプリの使用中に自動でオンにできます。

場所で設定すれば、大学に着いたときにオンにできます。ただ、集中モードでアプリが開けなくなるとは Apple のガイドに書かれていないので、インスタは静かに見えなくなるだけで、検索すれば開けます。メッセージだけ届く集中モードも参考に。

時間割に合わせた休止時間

  1. ［設定］→［スクリーンタイム］→［常に許可］で、授業で使うアプリを足します。
  2. ［休止時間］をタップし、［スケジュール］をオンにして［曜日別に設定］を選び、授業のある曜日ごとに時刻を決めます。
  3. スクリーンタイムパスコードを設定して、［休止時間中にブロック］をオンにします。

Apple によると、休止時間中は許可した通話・メッセージ・アプリだけが使え、［休止時間中にブロック］がオンならほかのアプリは開けません。SNS だけでなく［常に許可］に無いアプリが全部止まるので、最初の授業の前に一覧を確かめておきます。

minulo で授業1コマ分だけ止める

  1. minulo を入れ、「ブロック」タブを開いて、スクリーンタイムを許可します。
  2. 公式のインスタ・TikTok・YouTube を選び、授業が始まるときにブロックを始めます。無料では1回2時間までです。
  3. クラスのグループ DM は、minulo の中でインスタを開き、「DM以外のタブ」をオンにして使います。メッセージはそこで使えます。
  4. minulo Pro のワークモードなら、決めた曜日と時間帯に選んだアプリが自動で止まり、終わると戻ります。

消すのは無料で、時間の制限もありません。止めるのは自分で始める1回2時間まで無料で、終わったらすぐ次を始められます。グループ DM のためにインスタを残している人は リールなしでクラスのグループ DM を使う方法へ。

minulo の弱いところも書いておきます。リールやショートが消えるのは minulo の中だけで、公式アプリは変わりません。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は使えません。minulo は iPhone のアプリで、Safari と Chrome で使える Mac 版もあります。Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

授業中にインスタを見ないようにするには？

minulo で公式のインスタアプリを無料で止めれば（1回2時間まで）、授業のあいだ開きません。minulo Pro なら授業のある曜日に自動で始まり、iPhone の機能なら休止時間と［休止時間中にブロック］で同じことをスケジュールでできます。

集中モードで授業中のアプリは止まる？

Apple は集中モードを、通知をオフにしたり一部だけ許可したりする機能と説明しています。アプリが開けなくなるとは書かれていませんが、それらのアプリが無いホーム画面のページには切り替えられます。

大学に着いたら集中モードを自動でオンにできる？

できます。Apple によると、集中モードは設定した時間・場所・特定のアプリの使用中に自動でオンにできます。その集中モードで［スケジュールを追加］をタップします。

授業中はインスタを止めて、クラスのグループ DM だけ使える？

使えます。minulo の中でインスタを開いて「DM以外のタブ」をオンにすれば、グループ DM はそこで使えます。休止時間なら、ほかのアプリのグループは、そのアプリを［常に許可］に入れれば使えます。

曜日ごとに止める時間を変えられる？

休止時間なら［曜日別に設定］で曜日ごとの時刻を決められます。minulo の曜日と時間帯の予定は minulo Pro の機能です。

授業中の通知はどうなる？

minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo からも通知は送りません。集中モードなら、許可した人とアプリからの通知は届きます。
