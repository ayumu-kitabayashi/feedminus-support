minulo と FeedOff の違い：iPhone でショートとリールを消す無料のアプリはどっち？（2026年）

TikTok・Threads・Facebook・Pinterest・Snapchat を使う人や、Mac でも同じようにしたい人は minulo です。10の SNS でリール・ショート・おすすめを消し、DM とふつうの動画はそのまま使えます。消すのは無料です（Pro は有料）。使うのが Instagram・YouTube・X・Reddit・LinkedIn だけなら、FeedOff も同じことを無料で、アプリ内課金もなしでできます。

FeedOff: Block Reels & Shorts は、Peter Khalil さんが作った iPhone のアプリで、2026-10-01 に App Store に出ました。Instagram・YouTube・X・Reddit・LinkedIn を FeedOff の中のブラウザで開き、リール・ショート・発見・おすすめ・おすすめ投稿・広告・自動再生を隠します。Shield という機能では、TikTok を含む公式アプリをスクリーンタイムでブロックできます。minulo も各 SNS のウェブ版をアプリの中で見せるところは同じですが、対応は10の SNS で、TikTok もアプリごとブロックするのではなく、フィードを消して使えます。

2026-11-04

このページは minulo の開発者・北林歩（Ayumu Kitabayashi）が書いています。自分のアプリと比べているので、その点は割り引いて読んでください。FeedOff については、米国の App Store のページ（2026-10-28 に出た版 1.0.4）と公式サイト（feedoff.app）をもとに、2026-11-04 に確かめました。機能や料金は変わることがあります。

FeedOff が合う人

  • Instagram・YouTube・X・Reddit・LinkedIn だけ使えればいい人
  • サブスクなしで、すべての機能を無料で使いたい人
  • 公式アプリのアイコンの代わりにウィジェットを置きたい人や、アプリごとにグレイスケールにしたい人
  • ブロックしたアプリの通知は届いてほしい人
  • フィルタのルールを GitHub で自分で読みたい人

minulo が合う人

  • TikTok・Threads・Facebook・Pinterest・Snapchat を使っていて、アプリごとブロックするのではなくフィードだけ消したい人
  • Instagram や TikTok を DM だけにする設定がほしい人
  • Mac を使っている人
  • アプリを日本語や韓国語など、英語以外で使いたい人

どちらのアプリも見せるのは公式アプリではなく各 SNS のウェブ版なので、画面は公式アプリと少し違います。公式アプリを minulo でロックしている間は、その通知も届きません。

FeedOff は無料？

はい。App Store の説明には、FeedOff にはサブスクもアプリ内課金も広告もないと書いてあり、米国の App Store でも無料になっています（2026-11-04 確認）。minulo でも、リール・ショート・おすすめ投稿を消すのは無料です。予定、2時間より長いブロック、ハードモード、複数のブロックリストは Pro の機能で、米国では月9.99ドル・年39.99ドルです。

FeedOff や minulo で、YouTube のショートを消してふつうの動画は見られる？

どちらもできます。FeedOff は YouTube を登録チャンネルの画面で開き、ショートの棚・ショートのタブ・ホームのおすすめ・自動再生を隠します。検索も、どの動画を見ることもできます。minulo は YouTube のサイトをショートを隠してアプリの中で見せ、ふつうの動画と検索はそのまま使えます。どちらのアプリも公式の YouTube アプリは変えませんが、代わりにスクリーンタイムでブロックできます。

TikTok・Threads・Facebook を使うならどっち？

minulo です。FeedOff のブラウザが対応するのは Instagram・YouTube・X・Reddit・LinkedIn で、TikTok は Shield でアプリごとブロックすることしかできません。minulo は TikTok・Threads・Facebook・Pinterest・Snapchat をフィードを消して見せ、TikTok のメッセージも使えます。FeedOff の5つの SNS だけ使うなら、FeedOff で無料で足ります。
