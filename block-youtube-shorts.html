iPhoneでYouTubeのショートだけを非表示にして、ふつうの動画は見る方法（すべての方法・2026年）

方法は2つです。YouTube のショートのフィードの上限を 0 にする方法（大人は閉じられます）と、minulo の中で YouTube を開く方法です。minulo ならショートは無料で消え、ふつうの動画はそのまま見られます。公式の方法では、YouTube アプリの設定にある、ショートのフィードの上限を 0 にします（英語の画面では You → Settings → Time management → Shorts feed limit。日本語の表示名は確かめていません）。ただし大人のアカウントでは上限の表示を閉じられ、登録チャンネルや送られてきたリンクからはショートが出ます。閉じるだけでは戻れない止め方がほしいなら、minulo で公式の YouTube アプリをスクリーンタイムで止めることもできます（無料のブロックは1回2時間まで）。

YouTubeのショートを完全に非表示にできる？

大人のアカウントでは、YouTube アプリの中だけで完全には非表示にできません。minulo の中で YouTube を開けば、ショートは無料で消え、ふつうの動画は見られます。YouTube アプリでショートのフィードの上限を 0 にすると、上限のあとはショートのフィードが止まりますが、大人は上限の表示を閉じられます。登録チャンネルや送られてきたリンクのショートも残ります。

ショートの上限は、Safari の youtube.com でも効く？

YouTube のヘルプでは、ショートのフィードの上限は YouTube アプリの機能として説明されています。youtube.com でショートを消したい場合は、Safari や自前のブラウザで動く Nope や minulo のようなアプリが使えます。

つい YouTube アプリを開いてしまうのを止めるには？

iPhone のスクリーンタイムで YouTube アプリ全体を止められます。minulo も同じスクリーンタイムの仕組みを使いますが、YouTube を開こうとすると minulo に案内し、そこではショートが消えたまま、ふつうの動画は見られます。

ショートのフィードの上限を 0 分にする手順

1. YouTube アプリでプロフィール（英語の画面では You）を開き、設定に入ります。
2. 時間の管理の項目（英語では Time management）にある、ショートのフィードの上限（Shorts feed limit）を開きます。
3. 0 分を選びます。2026年4月から、大人のアカウントでも 0 分を選べるようになりました。
日本語の画面での項目名は確かめていないので、見つからないときは英語表示の名前を手がかりにしてください。上限のあとに出る案内は、大人のアカウントでは閉じて続きを見られます。

どのアプリも、公式の YouTube アプリからショートを消せないのはなぜ？

iPhone では、あるアプリがほかのアプリの画面を書き換えることはできません。公式の YouTube アプリの中からショートを消せるのは YouTube 自身だけです。ショートを消すアプリにできるのは、YouTube のウェブ版を自前の画面や Safari で開いてショートの入口を隠すことと、スクリーンタイムで公式アプリを止めることの2つです。minulo はこの2つを組み合わせて、YouTube のアイコンを押すと、ショートのない画面に移れるようにしています。

勉強中に、講義の動画だけ見てショートは見ないようにするには？

授業や受験勉強で YouTube の動画を使う人は、YouTube アプリ全体を止めると勉強の動画まで見られなくなります。ショートのフィードの上限を 0 にするか、ショートを消すアプリでふつうの動画と検索だけを使うと、講義の動画は見ながらショートには流れにくくなります。勉強の時間だけ公式アプリを止めたい場合は、スクリーンタイムの休止時間や、集中モードと組み合わせます。

minulo でショートを消す手順

1. App Store から minulo を入れます。
2. minulo で YouTube を開き、必要なら YouTube（Google）の公式のログイン画面でログインします。minulo はパスワードを受け取りません。
3. minulo の YouTube の設定で、ショートを隠す項目をオンにします。ふつうの動画・検索・登録チャンネルはそのまま使えます。
4. 必要なら、スクリーンタイムで公式の YouTube アプリを止めます。アイコンを押すとブロック画面が出て、「minulo で開く」からショートのない画面に移れます。ショートを消す機能は無料です。

子どもの YouTube のショートを止めたいときは？

保護者が見守りの設定をした10代のアカウントなら、保護者がショートを見る時間に上限をかけられ、0 にもできます。見守りの設定をしていないアカウントでは、上の方法のどれかを使います。

再生履歴をオフにすれば、ショートは消える？

再生履歴をオフにすると、最近の履歴がない場合にホームのおすすめが表示されなくなります。ただ、ショートのタブまで消えるとは YouTube のヘルプに書かれていません。ショートを確実に止めたいなら、上限 0 分かショートを消すアプリのほうが向いています。
