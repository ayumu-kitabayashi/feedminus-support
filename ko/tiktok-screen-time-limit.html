틱톡 시간제한(하루 사용 시간) 설정·해제 방법과 안 먹힐 때 해결법 (2026)

틱톡 시간 제한은 프로필 › 메뉴 › Settings and privacy › Time and well-being › Screen time의 Daily screen time에서 정해요. 정한 시간이 되면 알림이 뜨지만, 앱을 닫거나 화면에 나오는 암호를 입력해서 계속 볼 수 있어서 막는 기능은 아니에요. 만 13~17세는 처음부터 1시간으로 켜져 있어요. 시간이 되면 정말 막고 싶다면 다른 사람이 정한 암호로 아이폰 스크린 타임을 써요. 추천 피드가 문제라면 minulo로 추천을 숨기고 메시지는 남길 수 있어요. 무료예요.

2026-10-24

이 페이지는 minulo 개발자 Ayumu Kitabayashi가 썼어요. 틱톡과 아이폰 설정은 아래 출처를 바탕으로 2026-10-24에 확인했어요. 메뉴 이름은 앱 업데이트에 따라 바뀔 수 있어요.

방법할 수 있는 것한계

틱톡 하루 시간 제한 설정하는 방법

  1. 틱톡을 열고 아래쪽의 프로필을 눌러요.
  2. 위쪽의 메뉴(☰)를 누르고 Settings and privacy를 눌러요.
  3. Time and well-being(시간관리 및 웰빙)을 눌러요.
  4. Screen time을 누르고 Daily screen time을 켜요.
  5. 보기 중에서 시간을 고르거나 직접 정해요.

틱톡 한국어 고객센터의 이 글은 영어로만 나와 있어서, 메뉴 이름을 영어로 적었어요. ‘시간관리 및 웰빙’은 틱톡 한국 뉴스룸에서 쓰는 이름이에요. 한국어 화면에서 메뉴가 정확히 어떻게 표시되는지는 확인하지 못했어요.

웹에서는 프로필 사진, Settings, Screen time, Daily screen time 순서로 들어가요. 웹에서는 요일마다 다른 시간도 정할 수 있어요. 틱톡에 따르면 사용 시간 설정은 앱과 웹 모두에 적용돼요.

정한 시간이 되면 어떻게 되나요?

틱톡 고객센터에는 시간이 되면 알림이 뜨고, "틱톡을 닫거나 화면에 나오는 암호를 입력해 다시 볼 수 있다"고 나와 있어요. 입력할 암호가 같은 화면에 나오니까 몇 초면 계속 볼 수 있어요.

‘틱톡 시간제한 안 됨’ 같은 검색이 많은 것도 이 때문이에요. 고장이 아니라, 시간을 알아차리게 하는 기능이고 계속 볼지는 내가 정하게 되어 있어요.

틱톡의 다른 시간 관리 설정

Sleep hours(같은 Screen time 화면): 잘 시간이 되면 푸시 알림을 끄고, 앱 안에서 쉬어 가라는 알림을 보여 줘요. 끝나는 시간은 나이에 맞춰 자동으로 정해지고, 만 18세 이상은 최소 7시간 수면을 기준으로 해요.

Weekly screen time updates는 한 주 동안의 사용 시간과 지난주와의 비교를 알려 줘요. 사용 시간 대시보드(메뉴 ☰ › Activity center)에서는 이번 주 하루하루의 사용 시간을 보고, 최대 3주 전까지 거슬러 볼 수 있어요.

시간이 되면 정말 막으려면 (아이폰 스크린 타임)

시간이 됐을 때 틱톡이 정말 닫히게 하려면 틱톡이 아니라 아이폰에서 막아야 해요.

  1. 설정 앱에서 스크린 타임 › 앱 시간 제한 › 시간 제한 추가를 탭해요(iOS 26).
  2. 틱톡을 고르고 다음을 탭한 뒤 시간을 정해요.
  3. 스크린 타임 설정 잠그기로 스크린 타임 암호를 설정해요.
  4. 틱톡 제한을 다시 열고 제한 종료 시 차단을 켜요.

iOS 27에서는 앱 시간 제한 대신 허용 시간으로 소셜 미디어 같은 카테고리에 시간을 정해요. 앱에 연결되었다고 명시된 웹사이트에도 적용돼요. iOS 26에서는 Safari의 tiktok.com을 콘텐츠 및 개인정보 보호 제한의 ‘허용 안 함’에 따로 넣어야 해요. 암호를 직접 정하면 스스로 풀 수 있으니 가족이나 친구에게 정해 달라고 하세요. 어떤 방법이든 틱톡 메시지까지 막혀요. 자세한 순서는 아이폰에서 틱톡 차단하는 방법에 있어요.

시간을 재기보다 추천 피드를 숨기기 (minulo)

시간 제한은 친구에게 답장하는 시간까지 포함해 틱톡에서 보낸 시간을 모두 세요. 시간을 잡아먹는 게 추천 피드라면 그 부분만 숨기는 방법도 있어요. minulo는 틱톡 웹사이트를 앱 안에서 여는 아이폰 앱이에요. 추천이나 DM 외의 모든 탭을 숨길 수 있어요. 메시지와 팔로우 중은 minulo 홈 화면에서 바로 열려요.

숨기기는 무료이고, 직접 끌 때까지 계속 숨겨져 있어요. 공식 틱톡 앱은 스크린 타임으로 잠글 수 있고 한 번에 최대 2시간까지 무료예요. 잠가 둔 동안에는 틱톡 알림이 오지 않고, minulo도 알림을 보내지 않아요. 요일과 시간대별 일정, 2시간보다 긴 차단, 하드 모드, 여러 차단 목록은 minulo Pro 기능이에요. 안드로이드 버전은 없어요.

틱톡 시간 제한은 어디서 설정하나요?

틱톡 앱에서 프로필을 누르고 위쪽의 메뉴(☰), Settings and privacy, Time and well-being, Screen time 순서로 들어가 Daily screen time을 켜요. 웹에서는 프로필 사진, Settings, Screen time, Daily screen time 순서예요. 틱톡은 이 설정이 앱과 웹 모두에 적용된다고 설명해요.

틱톡 시간 제한이 안 먹히는 이유는요?

틱톡이 설명한 대로 작동하고 있는 거예요. 정한 시간에 도달하면 알림이 뜨고, 앱을 닫거나 화면에 나오는 암호를 입력해서 계속 볼 수 있어요. 암호가 화면에 그대로 나오니까 막는 기능이 아니라 시간을 알려 주는 기능이에요.

틱톡 시간 제한 알림이 자꾸 뜨는 이유는요?

만 13~17세 계정은 하루 사용 시간이 처음부터 1시간으로 켜져 있어요. 직접 한도를 정했다면 그 시간에 도달하는 날마다 떠요. Screen time 화면에서 끌 수 있어요. 보호자가 세이프티 페어링으로 설정할 수도 있어요.

틱톡 시간 제한을 해제하려면요?

프로필, 메뉴(☰), Settings and privacy, Time and well-being, Screen time으로 가서 Daily screen time을 열고 시간 제한을 꺼요. 웹에서는 프로필 사진, Settings, Screen time, Daily screen time에서 꺼요.

시간이 되면 틱톡이 아예 안 열리게 할 수 있나요?

틱톡 고객센터에서는 그런 기능을 찾지 못했어요. 틱톡의 시간 제한은 화면의 암호를 넣으면 계속 볼 수 있어요. 정말 막고 싶다면 아이폰 스크린 타임을 써요. iOS 26에서는 앱 시간 제한으로 틱톡에 제한을 추가하고, 스크린 타임 암호를 설정한 뒤 제한 종료 시 차단을 켜요. 암호를 다른 사람이 정해야 스스로 풀 수 없어요. 틱톡 메시지도 같이 막혀요.
