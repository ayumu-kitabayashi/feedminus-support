인스타·페이스북 동영상 자동 재생 끄는 방법 (아이폰·2026)

Facebook에는 자동 재생 설정이 있어요. 메뉴 › 설정 및 개인정보 › 설정 › 미디어에서 동영상 자동 재생 사용 안 함이나 Wi-Fi에서만을 고르면 돼요. 인스타에는 없어요. 고객 센터에 나오는 건 모바일 데이터에서 동영상을 미리 불러오지 않게 하는 데이터 절약 설정(Use less cellular data)뿐이에요. 불러오는 게 느려질 수 있고 Wi-Fi에서는 달라지지 않아요. 어느 설정으로도 릴스는 사라지지 않아요. 릴스가 문제라면 minulo에서 숨길 수 있어요. 무료이고 DM도 그대로 쓸 수 있어요.

2026-10-25

이 페이지는 minulo 개발자 Ayumu Kitabayashi가 썼어요. 인스타, Facebook, iPhone 설정에 관한 내용은 아래 출처를 바탕으로 2026-10-25에 확인했어요. 메뉴 이름은 앱 업데이트에 따라 바뀔 수 있어요.

설정바뀌는 것바뀌지 않는 것
인스타: Use less cellular data (프로필 › 메뉴 › Media quality)모바일 데이터에서는 동영상을 미리 불러오지 않아요. 그래서 불러오는 데 시간이 더 걸릴 수 있어요.Wi-Fi에서는 달라지는 게 없어요. 자동 재생을 끄는 설정은 인스타 고객 센터에서 찾지 못했어요.
Facebook: 자동 재생 (메뉴 › 설정 및 개인정보 › 설정 › 미디어)피드의 동영상과 애니메이션 자동 재생을 모바일 데이터 및 Wi-Fi 연결 시, Wi-Fi에서만, 동영상 자동 재생 사용 안 함 중에서 골라요.동영상과 릴스는 앱에 그대로 있어요. 누르면 재생돼요.
iPhone: 비디오 미리보기 자동 재생 (설정 › 손쉬운 사용 › 동작)Apple에 따르면 App Store 같은 앱이 비디오 미리보기를 자동으로 재생하게 하는 설정이에요. 끄면 멈춰요.인스타나 Facebook에도 적용된다는 말은 없고, 적용되는지 확인하지 못했어요.
minulo (무료)인스타의 릴스 탭, 피드의 릴스, 탐색 탭과 Facebook의 릴스, Watch를 숨겨요.minulo에는 자동 재생 설정이 없어요. 공식 앱 자체는 바뀌지 않아요.

인스타: 모바일 데이터 줄이기

  1. 오른쪽 아래의 프로필 또는 프로필 사진을 눌러 프로필로 가요.
  2. 오른쪽 위의 메뉴를 눌러요.
  3. 아래로 내려서 Media quality를 눌러요.
  4. Use less cellular data를 켜요.

인스타 고객 센터에 따르면, 인스타는 동영상이 빨리 시작되도록 기본적으로 동영상을 미리 불러와요. 이 설정을 켜면 모바일 데이터에서는 미리 불러오지 않아서, 동영상을 불러오는 데 시간이 더 걸릴 수 있어요. Wi-Fi에서는 달라지지 않아요.

이건 데이터 설정이지 자동 재생을 끄는 스위치가 아니에요. 다 불러오고 나면 화면에 나온 동영상은 그대로 재생돼요. 2026년 10월 기준으로 인스타 고객 센터에서 자동 재생을 끄는 설정은 찾지 못했어요. 메뉴 이름은 한국어 화면을 확인하지 못해서 영어로 적었어요.

Facebook: 동영상 자동 재생 끄기

  1. 메뉴를 눌러요. Facebook 고객 센터에는 화면 왼쪽 위에 있다고 나와 있어요.
  2. 아래로 내려서 설정 및 개인정보를 누르고 설정을 눌러요.
  3. 기본 설정까지 내려서 미디어를 눌러요.
  4. 자동 재생에서 모바일 데이터 및 Wi-Fi 연결 시, Wi-Fi에서만, 동영상 자동 재생 사용 안 함 중 하나를 골라요.

동영상 자동 재생 사용 안 함을 고르면 피드의 동영상과 애니메이션이 자동으로 재생되지 않아요. Wi-Fi에서만을 고르면 Wi-Fi에 연결됐을 때만 자동 재생돼요. 미디어가 보이지 않으면 Facebook 앱을 업데이트해 보라고 고객 센터에 나와 있어요.

iPhone의 비디오 미리보기 자동 재생

설정 › 손쉬운 사용 › 동작에서 비디오 미리보기 자동 재생을 끌 수 있어요. Apple은 App Store 같은 앱이 비디오 미리보기를 자동으로 재생하도록 허용하는 설정이라고 설명해요. Apple 페이지에는 인스타나 Facebook 이야기가 없고, 두 앱에도 적용되는지는 확인하지 못했어요. 인스타와 Facebook은 위의 앱 안 설정을 쓰세요.

자동 재생을 꺼도 바뀌지 않는 것

자동 재생 설정이 바꾸는 건 동영상이 저절로 시작되느냐뿐이에요. 사라지는 건 없어요. Facebook에서는 릴스와 동영상이 그대로 있고 누르면 재생돼요. 인스타에서는 릴스 탭도 피드의 릴스도 그대로이고, 고객 센터에는 자동 재생 설정 자체가 없어요. 한 편을 보면 다음 영상으로 넘어가 버리는 문제는 자동 재생 설정으로는 막을 수 없어요.

minulo에서 릴스 숨기기

minulo는 앱 안에서 인스타와 Facebook의 공식 웹사이트를 열어요. 인스타에서는 릴스 탭, 피드의 릴스, 탐색 탭이 숨겨지고 DM과 팔로우하는 사람의 게시물은 그대로 쓸 수 있어요. Facebook에서는 릴스, Watch, 마켓플레이스를 숨길 수 있어요. 숨기는 건 무료예요. minulo에는 자동 재생 설정이 없어요. 대신 릴스가 나오는 곳 자체를 숨겨요.

공식 앱을 스크린 타임으로 막을 수도 있고, 한 번에 2시간까지는 무료예요. 막아 둔 동안에는 공식 앱의 알림이 오지 않고, minulo가 알림을 보내지도 않아요. minulo Pro에서는 요일과 시간에 따라 바뀌는 일정, 더 긴 차단, 하드 모드, 여러 차단 목록을 쓸 수 있어요. minulo는 iPhone 전용이고, 이 페이지를 쓴 사람이 만들었어요.

인스타 동영상 자동 재생을 끌 수 있나요?

2026년 10월 기준으로 인스타 고객 센터에서 자동 재생을 끄는 설정은 찾지 못했어요. 가장 가까운 건 프로필, 메뉴, Media quality에 있는 Use less cellular data예요. 모바일 데이터에서 동영상을 미리 불러오지 않게 해 주지만, 그만큼 불러오는 게 느려질 수 있고 Wi-Fi에서는 달라지지 않아요.

Facebook 동영상이 저절로 재생되지 않게 하려면?

메뉴, 설정 및 개인정보, 설정, 기본 설정 아래의 미디어로 가서 자동 재생에서 동영상 자동 재생 사용 안 함을 골라요. Wi-Fi에서만을 고르면 모바일 데이터에서만 자동 재생이 멈춰요.

Use less cellular data를 켜면 인스타 동영상이 재생되지 않나요?

아니요. 인스타 고객 센터에 따르면 모바일 데이터에서 동영상을 미리 불러오지 않게 하는 설정이라 불러오는 데 시간이 더 걸릴 수 있어요. 재생을 멈춘다는 말은 없고, Wi-Fi에서는 달라지지 않아요.

iPhone의 비디오 미리보기 자동 재생은 인스타에도 적용되나요?

Apple은 App Store 같은 앱이 비디오 미리보기를 자동으로 재생하게 하는 설정이라고 설명해요. 인스타나 Facebook 이야기는 없고, 적용되는지는 확인하지 못했어요.

자동 재생을 끄면 릴스가 사라지나요?

아니요. 자동 재생 설정은 동영상이 저절로 시작되느냐만 바꿔요. 릴스 탭과 피드의 릴스를 숨기고 싶다면 minulo에서 인스타를 열면 돼요. 숨기는 건 무료이고 DM도 그대로 쓸 수 있어요.
