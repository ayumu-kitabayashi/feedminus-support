Configurer un mode de concentration sur iPhone qui n’autorise que les apps de messagerie (et ce qui arrive aux messages Instagram)

Un mode de concentration sur iPhone filtre les notifications par personne et par app. Pour ne laisser passer que les messages, allez dans Réglages › Concentration, choisissez ou créez un mode, touchez Apps › Autoriser les notifications de et ajoutez Messages et les apps de discussion que vous utilisez. Pour un mode de concentration, Instagram est une seule app : si vous l’ajoutez, tous les types de notifications Instagram passent, pas seulement les messages, et si vous ne l’ajoutez pas, les notifications de messages sont masquées aussi. Pour n’avoir que les messages, autorisez Instagram dans le mode de concentration, puis désactivez les autres types de notifications dans Instagram. Un mode de concentration filtre les notifications. Il ne vous empêche pas d’ouvrir Instagram.

Configurer un mode de concentration pour les messages

  1. Ouvrez l’app Réglages et touchez Concentration.
  2. Touchez un mode existant comme « Temps pour soi » ou Travail, ou touchez + puis Personnalisé pour en créer un. Donnez-lui un nom, une couleur et une icône, touchez Suivant, puis Personnaliser le mode de concentration.
  3. Touchez Apps (ou Choisir des apps), touchez Autoriser les notifications de, touchez + et choisissez Messages et les apps de discussion dont vous avez besoin, par exemple WhatsApp ou LINE. N’ajoutez Instagram que si vous voulez ses messages (voir plus bas).
  4. Sur le même écran, désactivez Notifications urgentes si vous ne voulez pas que d’autres apps passent.
  5. Touchez Personnes (ou Choisir des personnes) et ajoutez les personnes dont les appels et les messages doivent toujours vous parvenir.
  6. En option : choisissez une page d’écran d’accueil sans réseaux sociaux, ou touchez Ajouter un programme pour que le mode s’active à une heure ou dans un lieu donnés, ou quand vous utilisez une certaine app.

Apple précise que si vous activez « Partager le statut Concentration », les personnes qui essaient de vous joindre, dans Messages par exemple, peuvent voir que vos notifications sont désactivées. Vous pouvez changer cela dans Réglages › Concentration › Statut Concentration.

Ce que fait un mode « messages seulement » aux messages Instagram

Un mode de concentration décide app par app. Le guide d’Apple permet d’autoriser ou de masquer une app, et ne décrit aucun moyen d’autoriser seulement une partie des notifications d’une app. Cela donne deux cas :

  • Instagram n’est pas dans la liste des apps autorisées : les messages Instagram sont masqués avec les mentions J’aime, les commentaires et tout le reste d’Instagram tant que le mode est activé.
  • Instagram est dans la liste des apps autorisées : les messages passent, et toutes les autres notifications d’Instagram aussi.

Pour vous rapprocher des messages seulement, autorisez Instagram dans le mode, puis désactivez dans Instagram les types de notifications qui ne concernent pas les messages, dans votre profil › Menu › Notifications. Notre guide des notifications Instagram pour les messages seulement détaille les étapes. Ces réglages Instagram s’appliquent tout le temps, pas seulement pendant le mode de concentration.

Les filtres de concentration permettent aux apps de changer ce qu’elles affichent pendant un mode, par exemple le compte de messagerie utilisé. Nous n’avons pas pu confirmer qu’Instagram propose un filtre de concentration.

Un mode de concentration ne bloque pas les apps

Apple présente les modes de concentration comme un moyen de masquer ou d’autoriser des notifications et de faire savoir que vous êtes occupé. Rien dans leurs réglages n’empêche une app de s’ouvrir, donc vous pouvez toujours ouvrir Instagram et finir dans les Reels. L’option d’écran d’accueil aide en sortant de votre vue l’icône que vous touchez par habitude. Pour vraiment bloquer une app, utilisez Temps d’écran, ou le blocage de minulo ci-dessous.

Où minulo a sa place, et où il ne l’a pas

minulo est une app pour iPhone qui ouvre le site officiel d’Instagram dans l’app avec les onglets Reels et Explorer et les publications suggérées masqués, pour que vous puissiez lire et répondre aux messages sans tomber dans les Reels. Avec Tous les onglets sauf les messages, il ne reste que les messages et les notifications. Le masquage est gratuit.

minulo n’envoie aucune notification, donc ajouter minulo à un mode de concentration ne vous donne pas d’alertes de messages. Si vous voulez les alertes des messages Instagram, laissez l’app officielle Instagram déverrouillée et autorisée dans le mode. Si minulo verrouille l’app officielle avec Temps d’écran, ses notifications n’arrivent pas tant qu’elle est verrouillée, et un mode de concentration n’y change rien. Le verrouillage est gratuit jusqu’à 2 heures par blocage. minulo Pro ajoute les programmes par jour et par heure, les blocages plus longs, le mode strict et plusieurs listes de blocage. minulo existe seulement sur iPhone, et l’app officielle Instagram elle-même ne change pas.

Un mode de concentration sur iPhone peut-il n’autoriser que les apps de messagerie ?

Oui. Dans Réglages › Concentration, choisissez un mode, touchez Apps, touchez « Autoriser les notifications de » et ajoutez seulement Messages et vos apps de discussion. Désactivez « Notifications urgentes » si vous ne voulez pas que d’autres apps passent.

Les messages Instagram passent-ils avec un mode « messages seulement » ?

Seulement si Instagram fait partie des apps autorisées du mode. Un mode de concentration autorise ou masque une app dans son ensemble, donc autoriser Instagram laisse passer toutes ses notifications. Pour ne garder que les messages, désactivez aussi les autres types de notifications dans Instagram.

Un mode de concentration bloque-t-il Instagram ?

Non. Un mode de concentration filtre les notifications. Vous pouvez toujours ouvrir Instagram quand il est activé. Vous pouvez associer au mode une page d’écran d’accueil sans Instagram, et utiliser Temps d’écran ou une app de blocage si vous voulez bloquer l’app elle-même.

À quoi sert « Notifications urgentes » dans un mode de concentration ?

D’après Apple, cette option autorise toutes les apps à envoyer immédiatement les notifications urgentes. Si vous ne voulez recevoir que les apps choisies, désactivez-la dans l’écran Apps de ce mode.

minulo envoie-t-il les notifications des messages Instagram pendant un mode de concentration ?

Non. minulo n’envoie aucune notification. Tant que minulo verrouille l’app officielle Instagram, les notifications de cette app n’arrivent pas non plus. Pour les alertes de messages, laissez l’app officielle déverrouillée et autorisée dans votre mode de concentration.
