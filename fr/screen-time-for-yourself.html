Utiliser Temps d’écran pour soi-même et le rendre plus dur à désactiver (iPhone, iOS 27)

Si ce que vous voulez arrêter, ce sont les Reels et les Shorts, minulo masque seulement ceux-ci et garde vos messages (masquer est gratuit). Le Temps d’écran que vous configurez pour vous-même, lui, ne tient que par un code que vous avez choisi.

Pour un enfant, un parent configure Temps d’écran via le partage familial et garde le code. Pour vous-même, c’est vous qui le configurez et qui choisissez le code, donc vous pouvez toujours le retirer. Les réglages de l’iPhone ne peuvent pas, à eux seuls, vous empêcher de défaire votre propre Temps d’écran. Voici les étapes d’Apple pour le configurer pour vous-même, puis les moyens de le rendre plus dur à défaire et les points où ils ne suffisent plus.

Configurer Temps d’écran pour vous-même (iOS 27)

  1. Ouvrez l’app Réglages et touchez Temps d’écran.
  2. Touchez Gérer le temps d’écran, puis Activer Activité dans les apps et sur les sites web.
  3. Touchez Temps autorisés et définissez combien de temps vous pouvez utiliser chaque jour une catégorie comme Réseaux sociaux.
  4. Touchez Programme de temps d’écran, activez Programme, puis ajoutez des jours et des plages horaires.
  5. Touchez Code et gestion, puis Verrouiller les réglages « Temps d’écran », et saisissez deux fois un code à quatre chiffres.

D’après le guide d’Apple, une fois le code créé, il faut le saisir avant de pouvoir modifier les réglages de Temps d’écran que vous avez choisis pour vous-même. Sous iOS 26, faites défiler l’écran Temps d’écran vers le bas et touchez Verrouiller les réglages Temps d’écran. Dans le guide d’iOS 26, la fonction qui bloque les apps à certaines heures s’appelle Temps d’arrêt, et celle qui fixe un temps par jour s’appelle Limites d’app.

Les moyens de le rendre plus dur à défaire, et leurs limites

  • Ne choisissez pas le code vous-même. Si un proche ou un ami le saisit, vous ne pouvez pas retirer les réglages seul. Le guide d’Apple précise toutefois que si le code de secours pour Temps d’écran est configuré, le code peut être réinitialisé avec un compte Apple en cas d’oubli.
  • Sous iOS 26, activez Bloquer l’appareil. D’après Apple, avec un code Temps d’écran défini et cette option activée, les apps soumises à restriction ne peuvent pas être ouvertes pendant le temps d’arrêt. Si elle est désactivée, vous voyez seulement un rappel et pouvez continuer à utiliser les apps.
  • Par défaut, les limites peuvent être ignorées. Le guide d’iOS 26 indique que les limites de Temps d’écran peuvent être ignorées une fois atteintes. Plus de détails sur le bouton Ignorer la limite ici.

Quiconque connaît le code peut tout de même défaire tout cela. Pour votre propre Temps d’écran, il est réaliste de le voir comme une étape de plus avant de pouvoir le désactiver. Pour chaque manière de contourner vos propres limites et comment la fermer, voir comment arrêter de contourner vos propres limites Temps d’écran.

Si vous voulez seulement arrêter les Reels et les Shorts

Temps d’écran bloque des apps entières, donc bloquer Instagram bloque aussi vos messages. Si ce sont seulement les Reels ou les Shorts que vous voulez voir disparaître, ouvrez les apps dans minulo et masquez seulement ceux-ci.

  1. Installez minulo depuis l’App Store.
  2. Ouvrez Instagram, YouTube ou TikTok dans minulo et connectez-vous sur l’écran de connexion de chaque service. minulo ne reçoit jamais votre mot de passe.
  3. Touchez la roue dentée à côté du réseau et activez ce que vous voulez faire disparaître, comme les Reels et Explorer sur Instagram ou les Shorts sur YouTube. Masquer est gratuit.
  4. Dans l’onglet Blocage, choisissez les apps officielles Instagram, YouTube ou TikTok et lancez un blocage. Quand vous touchez leur icône, un écran de blocage s’affiche avec un bouton Ouvrir dans minulo. Un blocage gratuit dure jusqu’à 2 heures.

Si vous voulez des blocages sur les apps officielles que vous ne pouvez pas lever tout de suite, le mode strict oblige volontairement à passer quelques minutes pour en sortir (recopier une phrase, faire un peu de calcul mental, attendre 60 secondes). Il fait partie de minulo Pro (9,99 $ par mois ou 39,99 $ par an aux États-Unis).

minulo a aussi ses points faibles : les Reels et les Shorts ne sont masqués que dans minulo, et les apps officielles ne changent pas. Tant que minulo bloque une app officielle, ses notifications n’arrivent pas, et minulo n’en envoie aucune. Publier des Stories, les messages vocaux et les appels ne sont pas disponibles. minulo est une app pour iPhone, avec une version Mac qui fonctionne dans Safari et Chrome, et il n’existe pas encore de version Android. C’est une app récente, avec peu de notes. Voir ce que minulo ne sait pas faire.

Puis-je désactiver le Temps d’écran que j’ai configuré pour moi-même ?

Oui. Si vous avez choisi le code, vous pouvez le saisir et modifier ou désactiver les réglages. Pour rendre cela plus difficile, demandez à un proche ou à un ami de saisir le code à votre place.

Quelle différence entre Temps d’écran pour soi-même et pour un enfant ?

Vous configurez votre propre Temps d’écran sur votre propre iPhone et choisissez le code vous-même. Le Temps d’écran d’un enfant est configuré par un parent via le partage familial, et c’est le parent qui garde le code.

Que faire si j’oublie mon code Temps d’écran ?

D’après Apple, si vous avez configuré le code de secours pour Temps d’écran, vous pouvez utiliser votre compte Apple pour réinitialiser le code. Voir Vous avez oublié votre code Temps d’écran ? pour les détails.

Où est passé le Temps d’arrêt dans iOS 27 ?

Dans le guide d’utilisation d’iOS 27, le réglage qui bloque les apps à certaines heures s’appelle Programme de temps d’écran, et le réglage du temps par jour s’appelle Temps autorisés. Dans le guide d’iOS 26, ce sont Temps d’arrêt et Limites d’app.

Puis-je arrêter les Reels mais garder les messages Instagram ?

Pas avec Temps d’écran. Si vous ouvrez Instagram dans minulo, les Reels et Explorer sont masqués et les messages continuent de fonctionner (masquer est gratuit).
