Regarder les Shorts YouTube comme une vidéo normale, sans le fil à faire défiler (iPhone, 2026)

Le réglage gratuit « Ouvrir les liens Shorts dans le lecteur normal » de minulo lit les Shorts dans le lecteur vidéo habituel de YouTube sur iPhone : un Short se lit comme n’importe quelle autre vidéo, et non dans le flux Shorts qu’on fait défiler vers le haut.

Nous n’avons trouvé aucun réglage YouTube qui ouvre les Shorts dans le lecteur habituel. La limite du flux Shorts peut être réglée sur 0, mais l’aide YouTube indique que vous pouvez ignorer le rappel ou la limite. Les réglages de minulo ne fonctionnent que dans minulo, donc l’app YouTube officielle ouvre toujours les Shorts dans le flux Shorts.

  1. Installez minulo, touchez « Ajouter un service » et choisissez YouTube.
  2. Touchez la roue dentée à côté de YouTube et activez « Ouvrir les liens Shorts dans le lecteur normal ». « Masquer la section Shorts » et « Masquer l’onglet Shorts » se trouvent dans le même menu.
  3. Les vidéos normales, la recherche et les abonnements fonctionnent comme d’habitude dans minulo.
  4. Dans l’onglet « Blocage », choisissez l’app YouTube officielle, gratuit jusqu’à 2 heures par blocage.

Mis à jour le 2026-11-02

Cette page est rédigée par Ayumu Kitabayashi, le développeur de minulo. Les informations sur la limite du flux Shorts et la lecture automatique viennent de l’aide YouTube, vérifiée le 2026-11-02. Les noms des menus peuvent changer avec les mises à jour.

Ce que font les réglages de YouTube

La page de l’aide YouTube sur la limite du flux Shorts indique qu’un rappel s’affiche quand vous atteignez votre limite dans le flux Shorts, et que vous pouvez régler la limite sur 0. La même page précise que vous pouvez ignorer le rappel ou la limite : c’est donc un coup de pouce, pas un verrou.

Pour les vidéos normales, vous pouvez empêcher la vidéo suivante de démarrer toute seule : touchez votre photo de profil, puis Paramètres, et désactivez Lecture automatique. D’après l’aide YouTube, la lecture automatique peut être réglée différemment sur chaque appareil. Nous n’avons trouvé dans l’aide YouTube aucun réglage qui lit les Shorts dans le lecteur habituel.

Comment minulo lit les Shorts

minulo ouvre le site de YouTube dans l’app et ne change que ce que vous activez. Avec « Ouvrir les liens Shorts dans le lecteur normal » activé, un Short s’ouvre dans le même lecteur que n’importe quelle autre vidéo. « Masquer la section Shorts » et « Masquer l’onglet Shorts » retirent les endroits par lesquels les Shorts vous entraînent d’habitude dans le flux. Les vidéos normales, la recherche et les abonnements fonctionnent toujours, et tout cela est gratuit et sans limite de temps.

C’est utile quand vous voulez quand même voir le Short qu’un ami ou une chaîne que vous suivez a publié, mais pas les cinquante suivants.

Si vous voulez aussi rester hors de l’app

Dans l’onglet « Blocage » de minulo, autorisez Temps d’écran et choisissez l’app YouTube officielle. Son icône affiche alors un écran de blocage avec « Ouvrir dans minulo », qui vous emmène sur YouTube sans le flux Shorts. Le blocage est gratuit jusqu’à 2 heures par blocage. Le Mode sommeil, le Mode strict, la Limite quotidienne et les blocages de plus de 2 heures font partie de minulo Pro.

Existe-t-il un réglage YouTube pour regarder les Shorts dans le lecteur normal ?

Nous n’en avons trouvé aucun dans l’aide YouTube. Le réglage gratuit « Ouvrir les liens Shorts dans le lecteur normal » de minulo lit les Shorts dans le lecteur habituel sur iPhone.

Régler la limite du flux Shorts sur 0 arrête-t-il les Shorts ?

Pas complètement. D’après l’aide YouTube, vous pouvez ignorer le rappel ou la limite.

Puis-je encore regarder un Short quand je le veux ?

Oui. Avec le réglage activé, un Short s’ouvre dans le lecteur normal dans minulo, et vous regardez cette seule vidéo.

Est-ce que cela modifie l’app YouTube officielle ?

Non. minulo ne peut pas modifier l’app officielle. Vous pouvez la bloquer dans l’onglet « Blocage », gratuit jusqu’à 2 heures par blocage.

Puis-je plutôt masquer complètement les Shorts ?

Oui. « Masquer la section Shorts » et « Masquer l’onglet Shorts » se trouvent dans le même menu, et leur masquage est gratuit aussi.

Est-ce gratuit ?

Oui. Les réglages Shorts sont gratuits et sans limite de temps. Le Mode sommeil, le Mode strict, la Limite quotidienne et les blocages de plus de 2 heures font partie de minulo Pro.
