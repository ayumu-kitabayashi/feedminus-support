Le temps d’arrêt de Temps d’écran ne bloque pas Instagram sur iPhone ? 5 causes (2026)

Si Instagram s’ouvre encore pendant le temps d’arrêt, la cause habituelle est que « Bloquer l’appareil » est désactivé. D’après Apple, le temps d’arrêt affiche alors seulement un rappel et vous laisse continuer. Activez l’option dans Réglages › Temps d’écran › Temps d’arrêt, ce qui demande un code Temps d’écran. Vérifiez ensuite qu’Instagram ne fait pas partie de « Toujours autorisées », que quelqu’un d’autre garde le code et que « Programmé » est actif pour les bons jours. Sur iOS 27, le guide d’Apple utilise les programmes « Temps d’écran » au lieu du temps d’arrêt, et ils demandent iOS 27 sur tous vos appareils Apple.

1. Activer « Bloquer l’appareil » (iOS 26)

Apple précise que, par défaut, les limites de Temps d’écran peuvent être ignorées une fois atteintes. Pour le temps d’arrêt, cela veut dire : si Bloquer l’appareil est désactivé, vous voyez un rappel du temps d’arrêt, mais vous pouvez choisir de continuer à utiliser l’app. Si l’option est activée, les apps concernées ne peuvent pas être ouvertes pendant le temps d’arrêt. Elles apparaissent grisées avec une icône de sablier.

  1. Ouvrez Réglages et touchez Temps d’écran.
  2. Si vous n’avez pas encore de code, faites défiler, touchez Verrouiller les réglages Temps d’écran et saisissez deux fois un code à quatre chiffres.
  3. Touchez Temps d’arrêt, puis activez Bloquer l’appareil.

D’après Apple, vous choisissez entre bloquer et griser les apps une fois que vous avez défini un code Temps d’écran. Si vous ne voyez pas l’option, définissez d’abord le code.

2. Retirer Instagram de « Toujours autorisées »

Apple décrit « Toujours autorisées » comme les apps utilisables à tout moment, même pendant le temps d’arrêt. Si Instagram est dans cette liste, le temps d’arrêt ne l’arrêtera jamais. Allez dans Temps d’écran › Toujours autorisées et retirez Instagram des Apps autorisées. Sur iOS 27, touchez Modifier dans « Toujours autorisées » et retirez-la là.

3. Ne pas garder le code pour vous

Le code Temps d’écran doit être saisi avant de pouvoir modifier les réglages de Temps d’écran. Si vous le définissez vous-même et que vous le connaissez, rien ne vous empêche de le taper le soir. La solution simple : demandez à un ami ou à un proche de le définir. C’est notre conseil, pas celui d’Apple. Pour les enfants, Apple conseille, si un enfant découvre son code Temps d’écran, de le changer et d’activer le temps d’arrêt pour le reste de la journée.

4. Vérifier le programme lui-même

Allez dans Temps d’écran › Temps d’arrêt. Activer Temps d’arrêt jusqu’à demain ne fonctionne qu’une fois. Pour tous les soirs, activez Programmé et choisissez Tous les jours ou Personnaliser les jours, puis les heures de début et de fin. Avec « Personnaliser les jours », chaque jour de la semaine a ses propres heures, alors vérifiez aussi le week-end. Les étapes d’Apple disent aussi d’activer Activité dans les apps et sur les sites web si ce n’est pas déjà fait.

Quand le temps d’arrêt est programmé, un rappel arrive cinq minutes avant son début, et vous pouvez l’ignorer ou démarrer le temps d’arrêt tout de suite. Qu’Instagram soit vraiment bloqué ensuite dépend toujours de « Bloquer l’appareil ».

5. Sur iOS 27 : les programmes « Temps d’écran »

Dans le guide d’Apple pour iOS 27, la page sur les programmes Temps d’écran ne parle plus du temps d’arrêt. Elle présente à la place les programmes et les temps accordés. Allez dans Temps d’écran › Programme de temps d’écran, activez Programme, touchez Ajouter un programme et choisissez quelles catégories de temps accordés, comme « Réseaux sociaux », sont disponibles dans chaque plage horaire.

D’après Apple, ces fonctionnalités demandent iOS 27, iPadOS 27, macOS 27, watchOS 27, visionOS 27 ou une version ultérieure sur tous vos appareils Apple, et dans un groupe de partage familial tous les appareils doivent être mis à niveau. Si un iPad ou un Mac a encore une ancienne version, mettez-le à jour. « Toujours autorisées » s’applique aussi ici : les apps de cette liste restent disponibles quels que soient les programmes et les temps accordés.

Pourquoi le temps d’arrêt ne bloque-t-il pas Instagram ?

En général parce que « Bloquer l’appareil » est désactivé : le temps d’arrêt affiche alors seulement un rappel et vous laisse continuer. Activez l’option dans Temps d’écran, Temps d’arrêt. Il faut un code Temps d’écran. Vérifiez aussi qu’Instagram ne fait pas partie de « Toujours autorisées ».

Pourquoi puis-je encore ouvrir des apps pendant le temps d’arrêt ?

Les apps de « Toujours autorisées » restent disponibles pendant le temps d’arrêt. Sans « Bloquer l’appareil », les autres apps affichent un rappel que vous pouvez passer. Avec « Bloquer l’appareil », les apps concernées sont grisées avec un sablier et ne s’ouvrent pas.

Où se trouve « Bloquer l’appareil » ?

Dans Réglages, Temps d’écran, Temps d’arrêt. D’après Apple, vous pouvez choisir de bloquer complètement les apps pendant le temps d’arrêt une fois que vous avez défini un code Temps d’écran. Définissez-en donc un d’abord avec « Verrouiller les réglages Temps d’écran ».

Où est passé le temps d’arrêt dans iOS 27 ?

Dans le guide d’Apple pour iOS 27, la page des programmes présente les programmes « Temps d’écran » et les temps accordés au lieu du temps d’arrêt. Allez dans Temps d’écran, Programme de temps d’écran, et activez Programme. Il faut iOS 27 ou une version ultérieure sur tous vos appareils Apple.

Le temps d’arrêt peut-il bloquer seulement les Reels d’Instagram ?

Non. Le temps d’arrêt agit sur des apps entières, donc les messages sont bloqués aussi. Pour masquer seulement les Reels, ouvrez Instagram dans une app qui les masque. Dans minulo, c’est gratuit et les messages fonctionnent toujours.
