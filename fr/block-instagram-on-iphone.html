Bloquer Instagram sur iPhone : l’app, Safari et une solution intermédiaire (2026)

Pour bloquer Instagram sur iPhone, utilisez Temps d’écran. Sous iOS 26, ajoutez une limite d’app pour Instagram et activez l’option qui bloque l’app une fois la limite atteinte. Le temps d’arrêt bloque Instagram à certaines heures, et dans « Contenu et confidentialité », ajoutez instagram.com sous « Ne jamais autoriser » pour qu’il ne s’ouvre pas non plus dans Safari. Sous iOS 27, les temps autorisés et le programme de temps d’écran remplacent les limites d’app et le temps d’arrêt. Un code Temps d’écran vous empêche d’ignorer la limite, mais si vous l’avez choisi vous-même, vous pouvez toujours tout annuler. Toutes ces méthodes bloquent aussi vos messages. Pour les garder, masquez seulement les Reels et Explorer avec minulo, gratuitement, et laissez minulo verrouiller l’app officielle.

Bloquer l’app Instagram avec une limite d’app (iOS 26)

  1. Ouvrez Réglages et touchez Temps d’écran. Si « Activité dans les apps et sur les sites web » est désactivée, activez-la.
  2. Touchez Limites d’app, puis Ajouter une limite.
  3. Touchez le nom de la catégorie pour voir ses apps, sélectionnez Instagram, puis touchez Suivant.
  4. Définissez la durée autorisée (touchez Personnaliser les jours pour varier selon les jours) et enregistrez la limite.
  5. Définissez un code Temps d’écran : dans Temps d’écran, faites défiler vers le bas et touchez Verrouiller les réglages Temps d’écran.
  6. Rouvrez la limite d’Instagram et activez l’option qui bloque l’app à la fin de la limite (Block at End of Limit en anglais).

Apple indique que, par défaut, les limites de Temps d’écran peuvent être ignorées une fois atteintes. Sans code et sans cette option, la limite n’est qu’un rappel que vous pouvez passer d’un geste.

Bloquer Instagram à certaines heures avec le temps d’arrêt (iOS 26)

  1. Allez dans Réglages > Temps d’écran > Temps d’arrêt.
  2. Touchez Programmé, choisissez Tous les jours ou Personnaliser les jours, puis définissez les heures de début et de fin. Pour aujourd’hui seulement, touchez Activer Temps d’arrêt jusqu’à demain.
  3. Une fois un code Temps d’écran défini, activez Bloquer l’appareil. Les apps ne peuvent alors plus être ouvertes pendant le temps d’arrêt et apparaissent grisées avec une icône de sablier.

Les apps de la liste Toujours autorisées restent disponibles pendant le temps d’arrêt : vérifiez qu’Instagram n’y figure pas (Réglages > Temps d’écran > Toujours autorisées).

Bloquer instagram.com dans Safari (iOS 26)

  1. Allez dans Réglages > Temps d’écran > Contenu et confidentialité, puis activez Activer les restrictions.
  2. Touchez App Store, contenu multimédia, Web et jeux, puis Contenu web.
  3. Sélectionnez Limiter les sites pour adultes.
  4. Sous Ne jamais autoriser, touchez Ajouter un site web et saisissez instagram.com.

Les limites d’app s’appliquent aux apps et cette liste aux sites web : si vous ne voulez ni l’un ni l’autre, configurez les deux.

Si votre iPhone est sous iOS 27

Pour iOS 27, le guide d’Apple décrit les temps autorisés et les programmes de temps d’écran à la place des limites d’app et du temps d’arrêt. Apple précise qu’il faut iOS 27 ou une version ultérieure sur tous vos appareils Apple.

  • Temps autorisés : Réglages > Temps d’écran > Temps autorisés. Définissez une durée pour une catégorie comme Réseaux sociaux, ou touchez Gérer les catégories pour en ajouter une. Si une app déclare un site web associé, le temps autorisé s’applique aux deux.
  • Programme de temps d’écran : Réglages > Temps d’écran > Programme de temps d’écran, activez Programme, touchez Ajouter un programme, choisissez les jours, puis les catégories disponibles dans chaque plage horaire.
  • Code : Réglages > Temps d’écran > Gérer le temps d’écran > Verrouiller les réglages « Temps d’écran ».

Nous n’avons pas trouvé dans le guide d’utilisation de l’iPhone pour iOS 27 d’étapes pour bloquer un site web précis pour soi-même (vérifié le 2026-10-23). Pour un enfant du partage familial, un parent peut aller dans Réglages > Famille > nom de l’enfant > Apps et sites web, sélectionner l’app ou le site, puis toucher « Bloquer l’app » ou « Bloquer le site web ».

Supprimer l’app Instagram

  1. Maintenez le doigt sur Instagram sur l’écran d’accueil ou dans la bibliothèque d’apps.
  2. Touchez Supprimer l’app, puis à nouveau Supprimer l’app.
  3. Touchez Supprimer pour confirmer.

Supprimer de l’écran d’accueil ne fait que déplacer l’app dans la bibliothèque d’apps, d’où elle s’ouvre toujours. La suppression efface l’app et ses données de votre iPhone, pas votre compte Instagram. C’est aussi le blocage le plus facile à annuler : Instagram se retélécharge en une minute, et instagram.com s’ouvre toujours dans Safari.

Le problème : bloquer Instagram bloque aussi vos messages

Toutes les méthodes ci-dessus agissent sur l’app entière ou sur le site entier. Quand Instagram est bloqué, vos messages et vos discussions de groupe le sont aussi. Temps d’écran ne peut pas bloquer seulement les Reels ou Explorer.

Temps d’écran est aussi facile à contourner seul. Le code n’est demandé que pour modifier les réglages : si c’est vous qui l’avez choisi, vous le saisissez et la limite disparaît. Pour un blocage que vous ne pouvez pas lever sur un coup de tête, demandez à un ami ou à un proche de définir le code. Attention : si vous avez configuré le code de secours pour Temps d’écran, votre compte Apple permet de réinitialiser un code oublié.

Comment bloquer Instagram sur mon iPhone ?

Avec Temps d’écran. Sous iOS 26, allez dans Réglages > Temps d’écran > Limites d’app, ajoutez une limite pour Instagram, définissez un code Temps d’écran et activez l’option qui bloque l’app à la fin de la limite. Sous iOS 27, utilisez plutôt les temps autorisés et le programme de temps d’écran. Vous pouvez aussi supprimer l’app, mais c’est le blocage le plus facile à annuler.

Comment bloquer Instagram dans Safari ?

Sous iOS 26, allez dans Réglages > Temps d’écran > Contenu et confidentialité et activez les restrictions. Touchez App Store, contenu multimédia, Web et jeux > Contenu web, sélectionnez Limiter les sites pour adultes et ajoutez instagram.com sous Ne jamais autoriser. Sous iOS 27, un temps autorisé s’applique aussi au site web que l’app déclare comme associé.

Peut-on bloquer Instagram tout en gardant ses messages ?

Pas avec Temps d’écran, qui bloque toute l’app, messages compris. Utilisez une app qui ouvre Instagram sans les Reels ni Explorer. Dans minulo, c’est gratuit, les messages continuent de fonctionner, et minulo peut verrouiller l’app officielle avec Temps d’écran gratuitement jusqu’à 2 heures par blocage.

Pourquoi Instagram s’ouvre-t-il encore après ma limite de temps ?

Parce que, par défaut, les limites de Temps d’écran peuvent être ignorées une fois atteintes. Définissez un code Temps d’écran et activez l’option qui bloque l’app à la fin de la limite. Vérifiez aussi qu’Instagram ne figure pas dans Toujours autorisées et que vous n’utilisez pas instagram.com dans Safari.

Peut-on bloquer Instagram de façon à ne pas pouvoir l’annuler soi-même ?

Seulement si quelqu’un d’autre connaît le code. Si vous avez défini le code Temps d’écran vous-même, vous pouvez le saisir et lever le blocage : demandez plutôt à un ami ou à un proche de le choisir. Dans minulo, le mode strict (Pro) fait volontairement durer quelques minutes la désactivation d’un blocage.
