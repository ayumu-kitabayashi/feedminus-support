À quoi sert Snapchat pour le Web

L’article de l’assistance Snapchat sur Snapchat pour le Web vous dit d’aller sur web.snapchat.com depuis un ordinateur. Snap l’a annoncé en juillet 2022 pour continuer vos conversations depuis votre ordinateur portable, d’abord pour les abonnés Snapchat+ dans quelques pays. L’article d’aide actuel ne parle pas d’abonnement.

  • Navigateurs : la dernière version de Google Chrome, Microsoft Edge ou Safari.
  • Compte : gardez l’app Snapchat à jour sur votre téléphone et connectez-vous avec le même compte.
  • Un ordinateur à la fois : vous connecter sur un autre ordinateur vous déconnecte du premier.
  • Fonctions réservées à l’app : d’après Snapchat, voir les Snaps photo et vidéo de vos Souvenirs, gérer vos Stories et leurs analyses, modifier votre nom d’utilisateur et mettre à jour vos réglages de confidentialité se font encore dans l’app mobile.

Spotlight n’est pas absent du site. Snapchat indique qu’on peut voir Spotlight sur Snapchat pour le Web, à l’adresse web.snapchat.com : le site seul ne vous éloigne donc pas des vidéos courtes.
