Recevoir les notifications Instagram seulement pour les messages (iPhone, 2026)

Nous n’avons trouvé aucun bouton « messages seulement » dans l’aide d’Instagram, mais vous pouvez vous en approcher. Allez sur votre profil › Menu › Notifications, et sous Suspendre les notifications push, ouvrez chaque type de notification et désactivez-le, en laissant activées les notifications de messages. Vérifiez ensuite qu’Instagram est toujours autorisé dans Réglages › Notifications sur l’iPhone. Si un groupe est trop bruyant, mettez seulement cette conversation en sourdine. Nous n’avons pas pu confirmer dans l’aide d’Instagram le nom exact de chaque type de notification : repérez-les plutôt à ce qu’ils concernent (publications, stories, commentaires, abonnements, vidéos en direct, Reels).

Tout couper sauf les messages dans Instagram

  1. Touchez Profil ou votre photo de profil en bas à droite.
  2. Touchez Menu en haut à droite.
  3. Sous Comment vous utilisez Instagram (How you use Instagram), touchez Notifications.
  4. Sous Suspendre les notifications push (Pause push notifications), touchez chaque réglage de notification qui ne concerne pas les messages et désactivez ces notifications.
  5. Ouvrez celui qui concerne les messages et vérifiez qu’il reste activé.

L’aide d’Instagram indique que vous pouvez désactiver des types de notifications depuis cet écran, mais ne donne pas le nom de chaque catégorie : nous ne pouvons donc pas vous indiquer les libellés exacts. Revérifiez après les grosses mises à jour de l’app, car un nouveau type de notification peut arriver activé.

Couper les alertes des comptes que vous suivez

Si vous avez un jour activé les alertes pour les publications de quelqu’un, elles continuent d’arriver même après le tri dans les réglages principaux. Ouvrez le profil de ce compte, touchez Notifications et désactivez les publications, les stories, les reels et les vidéos en direct (Posts, Stories, Reels, Live videos dans l’app en anglais).

Mettre en sourdine une seule conversation plutôt que tous les messages

Pour garder vos messages mais calmer un groupe très actif : touchez Messages en bas, ouvrez la conversation, touchez le nom en haut, puis l’option de sourdine (Mute), et activez la sourdine des messages ou des appels (Mute messages, Mute calls). Instagram ne prévient pas les personnes que vous avez mises en sourdine.

Vérifier côté iPhone

Ouvrez Réglages › Notifications, puis touchez Instagram sous Style. Autoriser les notifications doit être activé pour que les alertes de messages Instagram vous parviennent. Le guide d’Apple précise que certaines apps proposent Personnaliser les notifications pour choisir les types de notifications. Nous n’avons pas pu confirmer si Instagram le propose, donc faites le tri dans Instagram.

Pourquoi les notifications de messages Instagram n’arrivent pas

Vérifiez dans l’ordre : Autoriser les notifications est désactivé sur l’iPhone, la suspension des notifications push est activée dans Instagram, le mode Sommeil est en cours, la conversation est en sourdine, ou un bloqueur d’apps, comme Temps d’écran ou minulo, a verrouillé l’app Instagram. Tant qu’une app est bloquée, ses notifications n’arrivent pas.

Ce que minulo fait, et ce qu’il ne fait pas

minulo s’occupe de l’autre moitié du problème : vous touchez une notification de message, vous répondez, et les Reels prennent l’heure suivante. minulo ouvre le site officiel d’Instagram dans une app iPhone, avec les onglets Reels et Explorer et les publications suggérées masqués. Le masquage est gratuit.

minulo lui-même n’envoie aucune notification. Si vous avez besoin des alertes de messages, gardez l’app Instagram officielle installée et déverrouillée avec les réglages ci-dessus, et utilisez minulo quand vous voulez lire et répondre sans les Reels. Si minulo verrouille l’app officielle avec Temps d’écran, ses notifications s’arrêtent tant qu’elle est verrouillée. minulo n’existe que sur iPhone.

Comment recevoir les notifications Instagram seulement pour les messages ?

Allez dans Profil › Menu › Notifications. Sous Suspendre les notifications push, ouvrez chaque type de notification qui ne concerne pas les messages et désactivez-le, en laissant les messages activés. Gardez Instagram autorisé dans Réglages › Notifications sur l’iPhone.

Pourquoi je ne reçois pas les notifications de messages Instagram ?

Vérifiez qu’Autoriser les notifications est activé pour Instagram dans Réglages › Notifications sur l’iPhone, que la suspension des notifications push et le mode Sommeil sont désactivés dans Instagram, que la conversation n’est pas en sourdine et qu’aucun bloqueur n’a verrouillé l’app Instagram.

Comment mettre une seule conversation en sourdine sur Instagram ?

Ouvrez la conversation, touchez le nom en haut, puis l’option de sourdine, et activez la sourdine des messages ou des appels. L’autre personne n’est pas prévenue.

minulo envoie-t-il les notifications de messages Instagram ?

Non. minulo n’envoie aucune notification, et tant qu’il verrouille l’app Instagram officielle, les notifications de cette app n’arrivent pas non plus. Pour recevoir les alertes de messages, laissez l’app officielle déverrouillée.
