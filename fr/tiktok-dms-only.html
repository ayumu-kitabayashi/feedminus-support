Utiliser TikTok seulement pour les messages sur iPhone, sans le fil « Pour toi » (2026)

TikTok s'ouvre directement sur « Pour toi », et aucun réglage n'en fait une app de messages. Temps d'écran peut limiter TikTok, mais bloque aussi vos messages. Si vos amis vous écrivent sur TikTok, voici comment garder les messages sans le fil.

Mis à jour le 2026-10-19

Cette page est rédigée par le développeur de minulo. Les noms des menus peuvent changer avec les mises à jour des apps et d'iOS.

Étapes avec minulo

  1. Installez minulo depuis l'App Store.
  2. Ouvrez TikTok dans minulo et connectez-vous sur la page de connexion de TikTok. minulo ne reçoit ni n'enregistre votre mot de passe.
  3. Dans les réglages TikTok de minulo, activez Tous les onglets sauf les messages. « Pour toi » et les autres onglets disparaissent ; les messages restent.
  4. Facultatif : bloquez l'app TikTok officielle avec Temps d'écran ; l'écran « bloqué » propose Ouvrir dans minulo.

Masquer « Pour toi » est gratuit. Instagram a le même réglage.

TikTok a-t-il un mode messages seulement ?

Pas à notre connaissance. Il y a un onglet Abonnements, mais l'app s'ouvre sur « Pour toi ». minulo masque « Pour toi » et peut n'afficher que les messages.

Mes amis pourront-ils encore m'écrire ?

Oui. Les messages fonctionnent dans minulo ; seuls les fils sont masqués.

Et pour Instagram ?

Le même réglage existe pour Instagram dans minulo.
