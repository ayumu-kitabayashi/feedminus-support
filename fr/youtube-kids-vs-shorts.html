Sur votre propre compte, la limite peut être ignorée

  1. Connectez-vous à l’application YouTube.
  2. Appuyez sur l’onglet Vous, puis sur Paramètres.
  3. Appuyez sur Gestion du temps, puis sur Limite du flux Shorts.
  4. Choisissez une durée dans la liste. Zéro fait partie des choix.

L’aide YouTube indique que lorsque vous atteignez la limite dans le flux Shorts, un message vous le rappelle, et vous êtes invité à ignorer ce rappel ou la limite définie. Sur un compte adulte, la limite est donc un coup de pouce que l’on peut balayer d’un geste.

Sur un compte supervisé pour adolescent, c’est le parent qui la définit

Un compte supervisé pour adolescent est le compte Google de l’adolescent, associé au compte d’un parent. YouTube le présente comme volontaire : le parent comme l’adolescent peuvent lancer la configuration, les deux doivent accepter l’association, et l’un ou l’autre peut mettre fin à la supervision à tout moment. YouTube précise que les adolescents peuvent aussi utiliser le Centre pour la famille pour voir le parent associé et activer ou désactiver la supervision.

Une fois l’association faite, un parent peut définir des limites pour le flux Shorts, régler les rappels « Faire une pause » et d’aller au lit, et modifier les paramètres de contenu de l’adolescent. Pour cela, l’aide YouTube indique de se connecter sur ordinateur, de cliquer sur votre photo de profil, puis sur Paramètres, de faire défiler jusqu’au Centre pour la famille et de cliquer sur Gérer les profils enfant et les fonctionnalités pour les adolescents, puis de sélectionner l’adolescent. Les pages d’aide que nous avons lues ne donnent pas la liste des durées proposées pour les adolescents.

Quand YouTube a annoncé cette fonctionnalité le 14 janvier 2026, il a indiqué que les parents pourraient fixer le temps qu’un adolescent passe à faire défiler les Shorts, et qu’une option pour régler le minuteur sur zéro arriverait bientôt. En avril 2026, YouTube a indiqué que le réglage sur zéro est désormais proposé à tous les parents. Son exemple : zéro pendant les devoirs et 60 minutes pendant un long trajet en voiture.

Ce que l’aide YouTube ne dit pas

La page d’aide pour les adultes dit que vous pouvez ignorer la limite. Les pages pour les adolescents disent qu’un parent peut définir la limite, mais aucune des pages que nous avons lues ne dit si l’adolescent voit la même option pour l’ignorer. Nous n’avons pu le confirmer dans un sens ni dans l’autre : ne comptez donc pas sur le fait qu’une limite fixée par un parent soit impossible à contourner. De plus, comme un adolescent peut mettre fin à la supervision, la limite ne tient que tant que les deux comptes restent associés.

Comptes enfant et YouTube Kids : deux choses différentes

Un compte supervisé pour enfant est une version de YouTube gérée par un parent, pour les enfants de moins de 13 ans. La page de comparaison de YouTube indique que les parents peuvent utiliser le Centre pour la famille pour gérer ses limites de temps d’écran, dont une limite du flux Shorts. Certaines fonctionnalités sont désactivées sur ces comptes, et la création de Shorts en fait partie.

YouTube Kids est une application à part. YouTube indique que le temps d’écran s’y règle avec un minuteur intégré : un parent ouvre les Paramètres, résout un problème de multiplication ou saisit un code secret, appuie sur Régler un minuteur et le démarre. Quand le temps est écoulé, l’application se verrouille jusqu’à ce qu’un parent la déverrouille. Ce minuteur couvre toute l’application, pas seulement les vidéos courtes.

Peut-on ignorer la limite du flux Shorts sur YouTube ?

Sur votre propre compte, oui. L’aide YouTube indique que lorsque vous atteignez la limite, un rappel s’affiche et vous pouvez ignorer ce rappel ou la limite définie.

Les parents peuvent-ils fixer une limite de Shorts sur le compte YouTube d’un adolescent ?

Oui, avec un compte supervisé pour adolescent. Un parent associé peut définir des limites pour le flux Shorts dans le Centre pour la famille, ainsi que les rappels « Faire une pause » et d’aller au lit et les paramètres de contenu. La supervision est volontaire, et le parent comme l’adolescent peuvent y mettre fin.

Un adolescent peut-il passer outre une limite de Shorts fixée par un parent ?

L’aide YouTube ne le dit pas. La page pour les adultes indique que la limite peut être ignorée, et les pages pour les adolescents disent seulement que les parents peuvent la définir. Nous n’avons donc pas pu confirmer si les adolescents voient une option pour l’ignorer.

Un compte supervisé pour enfant a-t-il une limite de Shorts ?

La page de comparaison de YouTube indique que les parents peuvent utiliser le Centre pour la famille pour gérer les limites de temps d’écran des comptes supervisés pour enfant, dont une limite du flux Shorts. La création de Shorts fait partie des fonctionnalités désactivées sur ces comptes.

Comment fonctionnent les limites de temps dans YouTube Kids ?

YouTube Kids a un minuteur intégré. Un parent ouvre les Paramètres, résout un problème de multiplication ou saisit un code secret, appuie sur Régler un minuteur et le démarre. Quand le temps est écoulé, les enfants voient une notification « C’est terminé ! » et l’application se verrouille.
