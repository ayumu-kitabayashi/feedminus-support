L’aide de Snapchat ne mentionne aucune app Snapchat pour Mac. Sur Mac, on utilise Snapchat pour le Web sur web.snapchat.com dans Safari, Chrome ou Edge : vous pouvez y discuter, appeler et envoyer des Snaps, et Chrome ou Edge peuvent l’ajouter à votre Dock. minulo est une app pour iPhone et Mac ; sur iPhone, elle ouvre Snapchat avec Spotlight et Découvrir masqués, sans couper vos discussions, gratuitement.

Sur Mac : télécharger l’app Mac (.dmg)

Snapchat pour le Web fonctionne dans le navigateur que vous avez déjà. Connectez-vous avec le même compte que sur votre téléphone : vous retrouvez vos discussions, vous pouvez passer des appels audio et vidéo et prendre des Snaps avec la caméra de votre Mac. Ce n’est pas l’app complète : les Souvenirs, la gestion de vos Stories, le changement de nom d’utilisateur et les réglages de confidentialité demandent toujours le téléphone, et Spotlight est aussi sur le site.

Démarrer Snapchat sur Mac

  1. Mettez à jour l’app Snapchat sur votre téléphone. Snapchat demande la dernière version.
  2. Sur votre Mac, ouvrez la dernière version de Safari, Chrome ou Edge et allez sur web.snapchat.com.
  3. Connectez-vous avec le même compte Snapchat que sur votre téléphone.
  4. Cliquez sur le nom d’un·e ami·e dans le flux de chat pour lui écrire. Cliquez sur l’icône de la caméra vidéo pour un appel vidéo, ou sur l’icône du téléphone pour un appel audio.
  5. Pour envoyer un Snap, ouvrez l’appareil photo, cliquez sur l’icône de la Lens pour prendre une photo, ou faites un appui long dessus pour enregistrer une vidéo.

Autoriser la caméra, le micro et les notifications

Safari : ouvrez le menu Safari, choisissez Paramètres pour web.snapchat.com et réglez la caméra et le micro sur Autoriser. Pour les notifications, ouvrez Safari › Réglages › Sites Web › Notifications et réglez web.snapchat.com sur Autoriser.

Chrome ou Edge : cliquez sur l’icône de verrouillage dans la barre d’adresse, activez la caméra, le micro et les notifications, puis actualisez la page. Si vous ne voyez pas les boutons, activez-les dans Réglages du site (Chrome) ou Autorisations pour ce site (Edge).

Mettre Snapchat dans le Dock (Chrome ou Edge)

Cliquez sur le lien en haut de votre fil pour installer l’application de bureau, ou cliquez sur votre Bitmoji en haut à droite et choisissez Créer un raccourci de bureau. Pour la retirer, ouvrez Snapchat pour le Web, cliquez sur le menu à trois points en haut à droite, puis sur Désinstaller Snapchat et enfin sur Supprimer.

Ce qui ne marche pas sur Mac

  • Un seul ordinateur à la fois. Vous connecter à Snapchat pour le Web sur un autre ordinateur vous déconnecte du premier.
  • Fonctions réservées à l’app. D’après Snapchat, voir les Snaps photo et vidéo de vos Souvenirs, gérer vos Stories et leurs analyses, modifier votre nom d’utilisateur et mettre à jour vos réglages de confidentialité ne se font encore que dans l’app mobile.
  • Spotlight est toujours là. Snapchat indique qu’on peut voir Spotlight sur Snapchat pour le Web : passer sur ordinateur ne vous tient donc pas à l’écart des vidéos courtes.

Existe-t-il une app Snapchat pour Mac ?

Nous n’en avons pas trouvé dans l’aide de Snapchat. La page de Snapchat sur les appareils pris en charge cite iOS, Android et Fire OS. Sur Mac, utilisez Snapchat pour le Web sur web.snapchat.com dans Safari, Chrome ou Edge. Dans Chrome ou Edge, vous pouvez l’ajouter à votre Dock avec « Créer un raccourci de bureau ».

Snapchat fonctionne-t-il dans Safari sur Mac ?

Oui. L’aide de Snapchat indique la dernière version de Google Chrome, Microsoft Edge ou Safari pour Snapchat pour le Web. Pour utiliser la caméra et le micro dans Safari, ouvrez le menu Safari, choisissez « Paramètres pour web.snapchat.com » et réglez les deux sur « Autoriser ».

Comment recevoir les notifications Snapchat sur Mac ?

Dans Safari, ouvrez Safari, Réglages, Sites Web, Notifications et réglez web.snapchat.com sur « Autoriser ». Dans Chrome ou Edge, cliquez sur l’icône de verrouillage dans la barre d’adresse, activez les notifications et actualisez la page.

Peut-on être connecté à Snapchat sur son Mac et sur un autre ordinateur ?

Non. Snapchat indique qu’on ne peut être connecté à Snapchat pour le Web que sur un seul ordinateur à la fois, et que se connecter sur un autre ordinateur vous déconnecte du premier.

Peut-on masquer Spotlight sur Snapchat sur Mac ?

Snapchat indique que Spotlight est aussi sur Snapchat pour le Web, et nous n’avons trouvé aucun réglage pour le retirer.
