Arrêter de contourner vos propres limites Temps d’écran sur iPhone (2026)

Apple a un réglage pour chacune des cinq failles par lesquelles vous contournez en général vos propres limites Temps d’écran, et si ce que vous voulez arrêter, ce sont les Reels ou les Shorts, minulo masque seulement ceux-ci et garde les messages. Ces failles sont : ignorer la limite, un code que vous connaissez déjà, supprimer puis réinstaller l’app, ouvrir le site dans Safari, et Toujours autorisées.

Le code est le point le plus important. Si vous le choisissez vous-même, vous vous en souviendrez devant l’écran de limite, alors demandez à un proche ou à un ami de le définir. Bloquer une app entière bloque aussi les messages Instagram. Si ce que vous voulez arrêter, ce sont les Reels ou les Shorts, minulo masque seulement ceux-ci et garde les messages. Masquer est gratuit.

1. Empêcher d’ignorer la limite

Le guide d’utilisation de l’iPhone d’Apple pour iOS 26 indique que, par défaut, les limites de Temps d’écran peuvent être ignorées une fois atteintes. Sans code, une limite que vous fixez ressemble plutôt à un rappel. Pour les limites d’app, les étapes pour retirer la possibilité d’ignorer sont dans comment supprimer « Ignorer la limite ».

Le temps d’arrêt fonctionne de la même façon. D’après Apple, si vous définissez un code Temps d’écran et activez Bloquer l’appareil, les apps soumises à restriction ne peuvent pas être ouvertes pendant le temps d’arrêt. Si l’option est désactivée, vous voyez seulement un rappel et pouvez continuer à utiliser les apps.

2. Laisser quelqu’un d’autre choisir le code

D’après Apple, si vous oubliez votre code Temps d’écran, vous pouvez le réinitialiser avec votre compte Apple, à condition d’utiliser le même compte que celui saisi lors de la configuration du code de secours pour Temps d’écran (code Temps d’écran oublié). Cela protège votre appareil, mais cela veut aussi dire que vous pouvez défaire une limite que vous vous êtes imposée.

Pour vraiment vous y tenir, demandez à un proche ou à un ami de définir le code, et n’indiquez pas votre propre compte Apple pour la récupération. En contrepartie, quelqu’un qui peut déverrouiller doit être à portée quand vous en avez vraiment besoin.

3. Rendre plus difficile la suppression et la réinstallation

Le guide d’Apple pour iOS 26 indique que vous pouvez aller dans Réglages › Temps d’écran › Contenu et confidentialité, activer les restrictions, puis toucher Achats dans l’iTunes et l’App Store pour définir des restrictions sur les achats et les re-téléchargements. Le guide ne détaille pas chaque option de cet écran, alors cherchez sur le vôtre celle qui couvre l’app que vous voulez garder. Là encore, cela n’a de sens que si quelqu’un d’autre détient le code.

La page du guide d’iOS 27 sur les restrictions de contenu, vérifiée le 2026-11-02, ne mentionne pas ce menu. Sous iOS 27, vérifiez l’écran de votre iPhone.

4. Fermer la porte de Safari

Bloquer l’app n’empêche pas instagram.com ou youtube.com dans Safari. Sous iOS 26, les étapes d’Apple sont Contenu et confidentialité › App Store, contenu multimédia, Web et jeux › Contenu web : sélectionnez Limiter les sites pour adultes, puis touchez Ajouter un site web sous Ne jamais autoriser et saisissez l’adresse. Sous iOS 27, Apple indique que si une app déclare un site web associé, le temps accordé s’applique aux deux.

5. Vérifier Toujours autorisées

D’après Apple, les apps de Toujours autorisées peuvent être utilisées à tout moment, quels que soient vos programmes de temps d’écran ou vos temps autorisés sous iOS 27, et même pendant le temps d’arrêt sous iOS 26. Si l’app que vous voulez arrêter est dans cette liste, aucune limite ne la fermera.

Si vous voulez seulement arrêter les Reels et les Shorts

Temps d’écran bloque l’app entière, donc les messages Instagram et les discussions de groupe partent avec. C’est souvent pour cela qu’on finit par le désactiver. Si ce que vous voulez arrêter, ce sont les Reels ou les Shorts, retirer seulement ceux-ci laisse moins de failles.

  1. Installez minulo, choisissez Instagram et connectez-vous. Dans minulo, les onglets Reels et Explorer d’Instagram et les publications suggérées sont masqués.
  2. Si vous utilisez YouTube, ouvrez-le aussi dans minulo. La section et l’onglet Shorts disparaissent, tandis que les vidéos normales, la recherche et les abonnements restent.
  3. Dans l’onglet Blocage, choisissez les apps officielles Instagram, YouTube et TikTok et lancez un blocage. Avec la version gratuite, un blocage dure jusqu’à 2 heures.
  4. Si vous ouvrez une app officielle pendant un blocage, l’écran de blocage s’affiche. Touchez Ouvrir dans minulo pour répondre aux messages sur un écran sans Reels.

Dans minulo, le mode strict (Pro) oblige volontairement à passer quelques minutes pour désactiver un blocage. minulo Pro coûte 9,99 $ par mois ou 39,99 $ par an aux États-Unis. Masquer est gratuit.

Les limites, pour que vous puissiez choisir en connaissance de cause : les Reels et les Shorts ne sont masqués que dans minulo, et les apps officielles ne changent pas. Tant que minulo bloque une app officielle, ses notifications n’arrivent pas, et minulo n’en envoie aucune. Publier des Stories, les messages vocaux et les appels ne sont pas disponibles. minulo est une app pour iPhone, avec une version Mac qui fonctionne dans Safari et Chrome, et il n’existe pas encore de version Android. Par où commencer si je contourne sans arrêt mon propre Temps d’écran ?

Faites définir le code Temps d’écran par quelqu’un d’autre. Ensuite, activez Bloquer l’appareil et vérifiez que les apps que vous voulez arrêter ne sont pas dans Toujours autorisées.

Puis-je m’empêcher de supprimer puis réinstaller une app ?

Sous iOS 26, d’après Apple, Réglages › Temps d’écran › Contenu et confidentialité › Achats dans l’iTunes et l’App Store permet de définir des restrictions sur les achats et les re-téléchargements. Le guide d’Apple pour iOS 27 ne décrit pas ce menu.

Temps d’écran bloque-t-il Instagram dans Safari ?

Pas si vous avez seulement limité l’app. Sous iOS 26, ajoutez l’adresse sous Ne jamais autoriser dans Contenu web. Sous iOS 27, Apple indique qu’un temps accordé s’applique aussi au site web que l’app déclare.

Pourquoi un code que j’ai choisi moi-même ne marche-t-il pas ?

Vous le connaissez, donc vous le tapez devant l’écran de limite. Et avec la récupération du code sur votre propre compte Apple, vous pouvez le réinitialiser même si vous l’oubliez. La limite ne tient que si quelqu’un d’autre la définit.

Puis-je bloquer les Reels mais garder les messages ?

Temps d’écran ne bloque que des apps entières. Si vous ouvrez Instagram dans minulo, les onglets Reels et Explorer sont masqués et les messages continuent de fonctionner. Masquer est gratuit.
