Ne plus voir les publications Threads sur Instagram (iPhone, 2026)

Nous n’avons trouvé dans l’aide d’Instagram aucun réglage qui retire les publications Threads de votre fil. Meta a commencé à les afficher directement sur Instagram et Facebook fin 2023. Ce qui marche aujourd’hui : masquer chaque publication Threads depuis son menu, ou passer sur la vue Suivi(e)s, qui n’affiche que les comptes que vous suivez. Le réglage Threads Suggestion des publications sur les autres applications concerne vos propres publications, pas ce que vous voyez. Si vous n’ouvrez Instagram que pour les messages, minulo peut l’ouvrir sans aucun fil, gratuitement.

Pourquoi des publications Threads apparaissent sur Instagram

En novembre 2023, Adam Mosseri, le patron d’Instagram, a écrit que Meta lançait une fonctionnalité qui affiche les publications Threads directement sur Facebook et Instagram, pour aider les gens à toucher plus de monde sur Threads. Ce que vous voyez, ce sont donc des publications Threads que Meta place dans votre fil Instagram, souvent de comptes que vous ne suivez pas.

Masquer les publications Threads une par une

  1. Repérez une publication Threads dans votre fil Instagram.
  2. Touchez les trois points à côté.
  3. Choisissez l’option pour la masquer (elle s’appelle Hide dans l’app en anglais).

Guiding Tech décrit ces étapes et indique qu’il faut parfois les répéter plusieurs fois. L’aide d’Instagram n’en parle pas pour les publications Threads, et nous n’avons pas pu vérifier qu’en masquer quelques-unes suffit à les faire disparaître pour de bon. Nous n’avons pas pu vérifier non plus le nom de l’option dans l’app en français.

Pour les notifications Threads dans Instagram, Guiding Tech explique que vous pouvez balayer l’une d’elles vers la gauche dans l’onglet des notifications, toucher les trois points et choisir Turn off notifications like this (désactiver ce type de notifications). Ce nom non plus, nous n’avons pas pu le vérifier en français.

Passer sur la vue Suivi(e)s

Appuyez sur Instagram en haut à gauche de votre fil, puis sur Suivi(e)s. D’après l’aide d’Instagram, cette vue montre les publications des personnes que vous suivez, les plus récentes en haut, et Meta indique qu’elle ne contient pas de publications suggérées. Quand vous rouvrez Instagram, vous revenez au fil habituel : il faut donc choisir Suivi(e)s à nouveau.

Ce que fait vraiment le réglage de Threads

Dans Threads, appuyez sur Profil, puis sur Menu en haut à droite, sur Confidentialité et sur Suggestion des publications sur les autres applications. Sous Autoriser vos publications à être suggérées sur, vous pouvez désactiver Instagram, Facebook ou les deux. Ce réglage décide si vos publications Threads peuvent apparaître dans le fil Instagram des autres. Il n’empêche pas les publications Threads des autres d’apparaître dans le vôtre. L’aide d’Instagram ajoute que les réponses et les « J’aime » d’une publication peuvent encore s’afficher dans d’autres apps.

Utiliser Instagram sans le fil avec minulo

minulo ouvre le site officiel d’Instagram dans l’app. Avec la roue dentée à côté d’Instagram, vous pouvez masquer les Publications suggérées, masquer tout le fil ou activer Tous les onglets sauf les messages. Quand tout le fil est masqué, plus rien n’y apparaît, publications Threads comprises, et vos messages et vos publications continuent de fonctionner. Vous pouvez aussi ajouter Threads dans minulo et l’ouvrir sur Abonnements plutôt que sur les recommandations.

Le masquage est gratuit. Bloquer l’app Instagram officielle avec Temps d’écran est gratuit jusqu’à 2 heures par blocage. Tant qu’elle est bloquée, ses notifications n’arrivent pas. minulo Pro ajoute les plannings par jour et par heure, des blocages plus longs, le Mode strict et plusieurs listes de blocage.

Pourquoi des publications Threads apparaissent-elles dans mon fil Instagram ?

Meta affiche des publications Threads directement sur Instagram et Facebook. Adam Mosseri, le patron d’Instagram, l’a annoncé en novembre 2023 pour aider les publications Threads à toucher plus de monde. Elles peuvent venir de comptes que vous ne suivez pas.

Peut-on désactiver complètement les publications Threads sur Instagram ?

Nous n’avons trouvé aucun réglage pour cela dans l’aide d’Instagram (octobre 2026). Vous pouvez masquer les publications Threads une par une depuis leur menu, ou passer sur Suivi(e)s, qui n’affiche que les comptes que vous suivez. Si vous utilisez surtout Instagram pour les messages, minulo peut l’ouvrir sans aucun fil, gratuitement.

Le réglage « Suggestion des publications sur les autres applications » retire-t-il Threads d’Instagram ?

Pas pour ce que vous voyez. Ce réglage Threads décide si vos propres publications sont suggérées sur Instagram et Facebook. Les publications Threads des autres peuvent toujours apparaître dans votre fil Instagram.

La vue Suivi(e)s retire-t-elle les publications Threads ?

Suivi(e)s n’affiche que les publications des comptes que vous suivez, sans publications suggérées : les publications Threads d’autres comptes qu’Instagram vous suggère n’y apparaissent donc pas. Instagram revient au fil habituel quand vous le rouvrez, il faut donc choisir Suivi(e)s à chaque fois.

Comment arrêter les notifications Threads sur Instagram ?

D’après Guiding Tech, vous pouvez balayer vers la gauche une notification Threads dans l’onglet des notifications d’Instagram, toucher les trois points et choisir Turn off notifications like this. Nous n’avons pas trouvé cette étape dans l’aide d’Instagram, ni le nom de l’option en français.
