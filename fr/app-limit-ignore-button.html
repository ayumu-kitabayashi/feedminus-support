Ce que fait « Ignorer la limite » dans Temps d’écran, et comment le supprimer (iPhone, 2026)

Quand une limite d’app est écoulée, Temps d’écran affiche un écran de limite, mais Apple indique que les limites de Temps d’écran peuvent être ignorées par défaut une fois atteintes. Le bouton pour ignorer, sur cet écran, vous permet de continuer à utiliser l’app. Pour supprimer ce choix, configurez un code Temps d’écran et faites bloquer l’app à la fin de la limite : il faudra alors le code pour continuer. Cela ne marche que si quelqu’un d’autre choisit le code. Sur iOS 27, les limites d’app sont remplacées par les temps autorisés. Si l’app dont vous ignorez sans cesse la limite est Instagram ou YouTube, et que ce sont les Reels ou les Shorts que vous voulez voir disparaître, minulo les masque gratuitement et vos messages continuent de fonctionner.

Ce que fait vraiment le bouton pour ignorer

Les limites d’app fixent un temps quotidien pour une app ou une catégorie, comme les réseaux sociaux. Quand ce temps est épuisé, un écran de limite recouvre l’app. Le guide de l’iPhone d’Apple indique : « par défaut, les limites de “Temps d’écran” peuvent être ignorées une fois atteintes ». La limite fonctionne donc comme un rappel. Le bouton de l’écran de limite vous laisse continuer, et l’app s’ouvre de nouveau.

Le guide d’Apple ne détaille pas les choix exacts derrière ce bouton, nous ne les listons donc pas ici. Ce qui compte : rien ne vous empêche de le toucher tant qu’aucun code n’entre en jeu.

Comment le supprimer : d’abord le code

  1. Ouvrez Réglages › Temps d’écran.
  2. Faites défiler vers le bas, touchez Verrouiller les réglages Temps d’écran, puis saisissez deux fois un code à quatre chiffres. Mieux encore : confiez l’iPhone à un ami ou à un proche et laissez-le choisir le code.
  3. Revenez dans Limites d’app, touchez la limite de l’app (ou Ajouter une limite pour en créer une) et activez l’option qui bloque l’app à la fin de la limite.

Le guide de l’iPhone d’Apple ne nomme pas ce dernier interrupteur. Le guide du Mac d’Apple décrit la même option des limites d’app sous le nom Bloquer à la fin de la limite et indique qu’elle bloque l’app quand la limite expire. Une fois activée, il faut le code pour utiliser l’app au-delà de la limite.

Apple indique que le code Temps d’écran doit être saisi avant de pouvoir modifier les réglages de Temps d’écran. Si vous choisissez le code vous-même, vous le connaîtrez au moment où la limite tombe : mieux vaut laisser quelqu’un d’autre le définir. Vous pouvez configurer le code de secours pour Temps d’écran avec votre compte Apple au cas où il serait oublié.

Le temps d’arrêt a le même problème, et la même solution

Le temps d’arrêt vous laisse aussi continuer par défaut. Apple indique que lorsque l’option Bloquer l’appareil est désactivée, vous voyez un rappel du temps d’arrêt, mais vous pouvez choisir de continuer à utiliser les apps. Avec un code Temps d’écran configuré, allez dans Temps d’écran › Temps d’arrêt et activez Bloquer l’appareil. Les apps concernées ne peuvent alors plus être ouvertes pendant le temps d’arrêt.

Vérifiez aussi Toujours autorisées. Apple indique que les apps choisies là restent disponibles pendant le temps d’arrêt et une fois les limites atteintes : une app limitée qui figure sur cette liste ne sera donc jamais bloquée.

Sur iOS 27 : les temps autorisés

Pour iOS 27, le guide d’Apple décrit les Temps autorisés (Réglages › Temps d’écran › Temps autorisés) et le Programme de temps d’écran à la place des limites d’app. Vous donnez un temps quotidien à une catégorie comme Réseaux sociaux, et si une app déclare un site web associé, le temps accordé s’applique aux deux. Apple précise que ces fonctionnalités demandent iOS 27 ou une version ultérieure sur tous vos appareils Apple. Nous n’avons pas trouvé dans la page d’Apple sur iOS 27 de description de ce qui s’affiche quand un temps autorisé est écoulé, ni s’il peut être ignoré.

Que fait « Ignorer la limite » dans Temps d’écran ?

Il vous permet de continuer à utiliser une app une fois sa limite d’app écoulée. Apple indique que les limites de Temps d’écran peuvent être ignorées par défaut une fois atteintes : l’écran de limite reste donc un rappel, sauf si vous ajoutez un code et faites bloquer l’app à la fin de la limite.

Comment supprimer « Ignorer la limite » sur iPhone ?

Configurez un code Temps d’écran dans Réglages › Temps d’écran › Verrouiller les réglages Temps d’écran, puis modifiez la limite de l’app et activez le blocage à la fin de la limite. Ensuite, il faut le code pour aller au-delà de la limite. Laissez quelqu’un d’autre choisir le code, sinon vous le saisirez simplement.

Peut-on empêcher d’ignorer les limites de Temps d’écran sans code ?

Nous n’avons pas trouvé de moyen dans les pages d’Apple. Apple lie le blocage au code Temps d’écran : pour le temps d’arrêt, il indique que vous pouvez choisir de bloquer complètement les apps une fois un code configuré.

Pourquoi puis-je encore ouvrir l’app après la limite, même avec le blocage activé ?

Vérifiez si l’app figure dans Toujours autorisées : Apple indique que ces apps restent disponibles une fois les limites atteintes. Vérifiez aussi que vous avez limité la bonne app ou la bonne catégorie, et rappelez-vous que quiconque connaît le code peut toujours le saisir.

Le bouton « Ignorer la limite » existe-t-il sur iOS 27 ?

iOS 27 remplace les limites d’app par les temps autorisés et le programme de temps d’écran. La page d’Apple sur iOS 27 ne décrit pas ce qui s’affiche quand un temps autorisé est écoulé : nous n’avons donc pas pu confirmer s’il peut être ignoré.
