Ce que fait le mode restreint de TikTok, et ce qu’il ne fait pas (iPhone, 2026)

Le mode restreint filtre ce que TikTok vous montre. L’aide de TikTok indique qu’il limite les contenus qui ne conviennent pas forcément à tout le monde, comme les thèmes pour adultes ou complexes, et que certaines fonctionnalités cessent de marcher tant qu’il est activé : le fil Abonnements, les LIVE et les cadeaux en LIVE. Il ne retire pas le fil Pour toi. Pour toi continue de défiler, simplement avec certaines vidéos filtrées. Activez-le dans Paramètres et confidentialité › Préférences de contenu › Mode restreint (Settings and privacy › Content preferences › Restricted Mode), avec un code. Si c’est Pour toi lui-même que vous voulez voir disparaître, le mode restreint n’est pas le bon outil. minulo masque Pour toi gratuitement et garde vos messages.

Activer ou désactiver le mode restreint

  1. Dans l’app TikTok, touchez Profil en bas.
  2. Touchez le bouton Menu ☰ en haut, puis Paramètres et confidentialité (Settings and privacy).
  3. Touchez Préférences de contenu (Content preferences), puis Mode restreint (Restricted Mode).
  4. Suivez les étapes pour créer ou saisir un code, puis activez ou désactivez le mode. La première fois, vous touchez Activer (Turn on) avant de créer le code.

Si vous avez plusieurs comptes, TikTok indique qu’il faut activer le mode restreint sur chacun séparément. Les parents et tuteurs peuvent l’activer sur le compte d’un adolescent avec Connexion Famille (Family Pairing).

Ce que filtre le mode restreint

TikTok indique que des systèmes automatisés et des modérateurs humains décident de ce qui est écarté. Sa liste de ce que vous ne devriez pas voir comprend la vulgarité, les contenus à caractère sexuel suggestif, la violence réaliste ou les images menaçantes, les armes à feu ou autres armes dans un cadre inapproprié, les substances illégales ou réglementées, et les références explicites à des thèmes adultes ou complexes destinés à un public plus âgé. TikTok précise aussi que la fonctionnalité est encore en cours d’amélioration et demande de signaler les vidéos qui ne devraient pas y figurer.

Ce que le mode restreint ne fait pas

Il ne désactive pas Pour toi, ne limite pas votre temps et n’empêche pas une vidéo d’enchaîner sur la suivante. L’aide de TikTok liste les fonctionnalités qui cessent de marcher, et Pour toi n’en fait pas partie, alors que le fil Abonnements, si. Avec le mode restreint activé, vous pouvez donc vous retrouver avec le seul fil recommandé et plus aucun fil des comptes que vous suivez, soit l’inverse de ce que cherchent beaucoup de gens qui tombent sur ce réglage.

Pour le temps, TikTok propose un réglage distinct de temps d’écran quotidien, et Temps d’écran sur iPhone peut limiter toute l’app. Aucun des deux ne retire Pour toi non plus.

Le mode restreint de TikTok désactive-t-il la page Pour toi ?

Non. Le mode restreint filtre certains contenus de ce que TikTok affiche, mais Pour toi continue de fonctionner. L’aide de TikTok cite le fil Abonnements, les LIVE et les cadeaux en LIVE comme les fonctionnalités qui deviennent indisponibles.

Pourquoi mon fil Abonnements a-t-il disparu sur TikTok ?

Si le mode restreint est activé, c’est normal. L’aide de TikTok indique que le fil Abonnements est indisponible en mode restreint. Désactivez-le dans Paramètres et confidentialité › Préférences de contenu › Mode restreint, avec votre code.

Que bloque le mode restreint de TikTok ?

Les contenus que TikTok juge ne pas convenir à tout le monde, comme la vulgarité, les contenus à caractère sexuel suggestif, la violence réaliste, les armes dans un cadre inapproprié, les drogues et les références explicites à des thèmes adultes. TikTok s’appuie sur des systèmes automatisés et des modérateurs humains.

Faut-il activer le mode restreint sur chaque compte ?

Oui. TikTok indique que si vous avez plusieurs comptes, vous devez activer le mode restreint sur chacun séparément.

Comment se débarrasser de Pour toi sur TikTok ?

TikTok n’a aucun réglage qui le retire. Dans minulo, TikTok s’ouvre gratuitement avec Pour toi, Explorer et Créer masqués, tandis que les messages et Abonnements continuent de fonctionner.
