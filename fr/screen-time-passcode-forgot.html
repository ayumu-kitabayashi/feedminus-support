Vous avez oublié le code Temps d’écran que vous avez défini vous-même ? Les étapes officielles d’Apple (iPhone, 2026)

Si vous avez oublié le code de Temps d’écran de votre propre iPhone, voici les étapes d’Apple : ouvrez Réglages, touchez Temps d’écran, puis Gérer le temps d’écran, et touchez deux fois Modifier le code de « Temps d’écran ». Si on vous le demande, saisissez l’adresse e-mail et le mot de passe du compte Apple utilisés pour configurer le code, puis saisissez deux fois un nouveau code. Cela fonctionne grâce au code de secours pour Temps d’écran, qu’Apple recommande de ne pas passer. Si cela échoue, Apple conseille de vérifier que vous utilisez le même compte Apple qu’à la configuration, qui n’est pas forcément celui connecté sur l’iPhone.

Réinitialiser le code Temps d’écran sur votre propre iPhone

  1. Ouvrez l’app Réglages et touchez Temps d’écran.
  2. Touchez Gérer le temps d’écran.
  3. Touchez Modifier le code de « Temps d’écran », puis touchez de nouveau Modifier le code de « Temps d’écran ».
  4. Si on vous le demande, saisissez l’adresse e-mail et le mot de passe du compte Apple que vous avez utilisés pour configurer le code de Temps d’écran.
  5. Saisissez un nouveau code, puis saisissez-le à nouveau pour le confirmer.

Apple précise que le code de Temps d’écran n’est pas le code de déverrouillage de votre iPhone. Il sert à modifier les réglages, les limites ou les restrictions de l’appareil. C’est pour cela que l’oublier vous empêche de toucher à vos propres limites.

Pourquoi le compte Apple compte

Apple recommande de ne pas passer l’étape d’ajout d’un code de secours pour Temps d’écran, car c’est ce qui vous permet de réinitialiser un code oublié avec votre compte Apple. Si vous avez plusieurs comptes Apple, vous devez utiliser celui que vous avez saisi lors de la configuration du code de secours.

La page d’Apple ne décrit pas d’autre moyen de réinitialiser le code sur votre propre appareil. Si les étapes ci-dessus ne fonctionnent pas pour vous, la page se termine par un lien Obtenir des suggestions vers l’assistance Apple.

Si la réinitialisation ne marche toujours pas

Apple conseille de vérifier que vous utilisez la même adresse e-mail et le même mot de passe de compte Apple que lors de la configuration du code de Temps d’écran. Il peut s’agir d’un autre compte Apple que celui auquel vous êtes connecté sur l’iPhone. Si vous faites partie d’un groupe de partage familial, il peut s’agir du compte Apple d’un membre de votre famille ou de celui de votre enfant.

Si un parent gère votre compte Apple avec le partage familial, c’est le responsable ou un parent qui doit réinitialiser le code sur son propre appareil. Les étapes d’Apple : Réglages › Temps d’écran, faites défiler et touchez votre nom sous Famille, touchez Gérer le temps d’écran, puis deux fois Modifier le code de « Temps d’écran », et saisissez deux fois le nouveau code.

Que faire si j’ai oublié mon code de Temps d’écran ?

Ouvrez Réglages, touchez Temps d’écran, puis Gérer le temps d’écran, et touchez deux fois Modifier le code de « Temps d’écran ». Si on vous le demande, saisissez l’adresse e-mail et le mot de passe du compte Apple utilisés pour configurer le code, puis saisissez deux fois un nouveau code.

Peut-on réinitialiser le code de Temps d’écran sans son compte Apple ?

La page d’Apple ne décrit que la réinitialisation avec le compte Apple saisi pour le code de secours pour Temps d’écran. Elle ne donne pas d’autre moyen pour votre propre appareil. Pour les autres cas, la page renvoie vers l’assistance Apple.

Pourquoi mon compte Apple ne fonctionne-t-il pas pour réinitialiser le code de Temps d’écran ?

Il faut le même compte Apple que celui utilisé pour configurer le code de Temps d’écran. Apple indique qu’il peut être différent de celui connecté sur votre iPhone, ou être celui d’un membre de la famille si vous utilisez le partage familial.

Le code de Temps d’écran est-il le même que le code de mon iPhone ?

Non. Apple indique que le code de Temps d’écran n’est pas le code de déverrouillage de votre appareil. Il sert uniquement à modifier les réglages, limites et restrictions de Temps d’écran.

minulo peut-il réinitialiser mon code de Temps d’écran ?

Non. minulo ne peut ni le voir ni le réinitialiser. Suivez les étapes d’Apple dans Réglages, Temps d’écran, Gérer le temps d’écran, Modifier le code de « Temps d’écran ».
