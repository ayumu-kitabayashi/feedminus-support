SocialLite で無料でできること

SocialLite の App Store の説明には、ショート動画のフィード・おすすめ・発見・ライブ・ショッピングのタブと広告を消し、DM は残し、公式アプリを止められる、とアプリでできることが並んでいます。ただ、そのどれが無料でどれが有料かは分けて書かれていません。自分の場合どうなるかは、入れてみて、どこで支払いを求められるかを見るしかありません。App Store のページにはいくつものプランが出るので、見える料金が人によって違うこともあります。

無料でリールを消すには

  1. App Store から minulo を入れます。
  2. minulo の中で Instagram を開き、Instagram のログイン画面でログインします。パスワードは minulo には届きません。
  3. Instagram の横の歯車から、リール・発見・おすすめ投稿を消せます。DM だけにするなら［DM以外のタブ］をオンにします。
  4. YouTube と TikTok も同じように足せます。ショートや「おすすめ」を消すのも無料です。
  5. 必要なら「ブロック」タブで、公式アプリをスクリーンタイムで止めます。1回2時間まで無料です。

SocialLite のほうが合う人

SocialLite には minulo に無い Instagram と Snapchat のプッシュ通知があり、評価の数もずっと多い（米国で15,412件・平均4.7）です。料金より通知が大事なら、先に SocialLite を試す価値があります。

minulo の弱いところも書いておきます。公式アプリそのものは変えられないので、リールやショートが消えるのは minulo の中だけです。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は、各SNSのウェブ版に無いので使えません。使えるのは iPhone と Mac（ほかに Chrome と Safari の機能拡張）で、Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

SocialLite は無料？

無料でダウンロードでき、アプリ内課金があります。App Store の説明には、どの機能が無料でどれに Pro が要るかは書かれていません。

SocialLite の Pro はいくら？

米国の App Store（2026-10-26 確認）では、Pro は表示されるプランによって月6.99〜17.99ドル、年19.99〜47.90ドルで、ファミリープランは月12.99ドルです。比べると、minulo の Pro は日本で月1,480円・年6,800円（7日間の無料体験つき）・買い切り23,800円です。

SocialLite のような無料のアプリはある？

Nope と noShorts は完全に無料です。Nope は Safari の instagram.com と youtube.com だけ、noShorts はアプリの中で使えます。SocialLite と同じ仕組みのアプリでは、minulo・Stillfeed・Reelmute・Awhile がリールを消すのは無料で、お金がかかるのは追加の機能だけです。minulo は Instagram と TikTok を DM だけにする設定も無料です。

無料のアプリでも通知は来る？

minulo なら、公式アプリを止めていなければ来ます。通知はいつもどおり公式アプリから届き、返信は minulo の中でできます。公式アプリを止めている間は届きません。SocialLite には Instagram と Snapchat のプッシュ通知があります。

minulo の Pro で何が増える？

曜日と時間帯で切り替わる予定、2時間を超えるブロック、ハードモード、SNS を完全に止める機能、複数のブロックリストです。リール・ショート・おすすめ投稿を消す機能は、ずっと無料で時間の制限もありません。
