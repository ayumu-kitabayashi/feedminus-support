パソコン（Mac）でリールとショートだけ消す方法：minulo for Mac（無料）

パソコン（Mac）でインスタのリールや YouTube のショートだけを消すなら、minulo for Mac を入れます。Safari と Chrome では、10のSNSのフィードとショート動画だけが消え、DM やふつうの動画はそのまま使えます。Edge・Brave・Arc では、フィードやショート動画のページを開くと、DM など用事のページへ移ります。無料で、アカウント登録もいりません。

ダウンロードのボタンは Mac で開いたときに出ます。iPhone・iPad では、このページを Mac で開いてください。

minulo for Mac の入れ方

  1. ダウンロードする：［macOS 版をダウンロード］を押して、minulo.dmg をダウンロードします。
  2. アプリケーションに入れて開く：minulo.dmg を開き、minulo をアプリケーションのフォルダへドラッグして、アプリケーションから開きます。開いた画面の［はじめに］で、「フィードを開いたら、用事のページへ移す」の［オンにする］を押します。初めてブラウザを使うときに、minulo がそのブラウザを制御してよいかを聞かれるので［OK］を押します。
  3. Safari の機能拡張をオンにする：Safari の［設定］→［機能拡張］で、「minulo Blocker」と「minulo Extension」にチェックを入れます。ページの中のリールやショートを消すのは「minulo Blocker」です。
  4. Chrome・Edge・Brave・Arc で使う：Chrome では、Mac アプリの［はじめに］の［Chrome で開く］から機能拡張を足すと、ページの中のリールやショートも消えます。Edge・Brave・Arc では、フィードやショート動画のページを開くと、DM など用事のページへ移ります。

minulo for Mac にできないこと

  • Windows 版はありません。
  • Android 版はありません。
  • 消すものを選ぶ設定は Mac アプリでします。機能拡張の側では変えられません。
  • 対応は macOS 26.5 以降です。

パソコンでインスタのリールや YouTube のショートだけを消せる？

Mac なら消せます。minulo for Mac を入れると、Safari と Chrome で、インスタのリールや YouTube のショートなど、10のSNSのフィードとショート動画だけが消えます。Edge・Brave・Arc では、フィードやショート動画のページを開くと、DM など用事のページへ移ります。DM やふつうの動画はそのまま使えます。消すところは iPhone 版と同じです。

minulo for Mac は無料？

無料です。Mac 版に有料の機能はなく、アカウント登録もいりません。

対応しているブラウザと macOS は？

Safari・Chrome・Edge・Brave・Arc で、macOS 26.5 以降に対応しています。Safari と Chrome ではページの中のフィードとショート動画が消え、Edge・Brave・Arc ではフィードやショート動画のページを開くと用事のページへ移ります。どのブラウザでも、先に Mac アプリを入れます。Chrome の機能拡張は Mac アプリから足します。

Windows や Android で使える？

使えません。minulo には Windows 版も Android 版もありません。パソコンは Mac、スマホは iPhone に対応しています。

minulo for Mac は何か送信する？

送りません。外とつなぐのは、新しいバージョンが出ていないかを1日1回確かめるときだけです。

iPhone でも使うなら

iPhone 版の minulo は App Store にあります。インスタのリールや YouTube のショートだけを消し、DM やふつうの動画は残せます。消す機能は無料です。
