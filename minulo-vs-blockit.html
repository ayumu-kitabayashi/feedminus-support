minulo と #blockit（BlockIt）の違い：リールとショートを Safari で隠すか、アプリで隠すか（2026年）

#blockit と minulo は、同じ悩みを別の場所で解決します。#blockit は Safari の中で動き、いつもどおりログインしたまま使えます。2020年からあり、米国の評価は169件です。minulo は別のアプリで、TikTok を含む10の SNS を、リールとショートを消して見せます。SNS を Safari で見ていて、サイトごとに細かいスイッチがほしいなら #blockit です。TikTok や Snapchat も使いたい人、公式アプリをロックしたい人、消すためにサブスクを払いたくない人は minulo です。

#blockit（BlockIt と書かれることも多いです。App Store での名前は「#blockit: Block Shorts & Reels」、開発は Jordi Kitto）は、Safari のコンテンツブロッカーです。Safari で開いた6つのサイトからショート・リール・終わりのないフィードを取り除き、検索・メッセージ・通知は残します。説明には、アカウントも内蔵のブラウザもなく、サーバーには何も送らないとあります。運動するとアプリのロックが外れる「BlockIt - Pushups Screen Time」という別のアプリもありますが、ここで比べているのはそちらではありません。

#blockit が合う人

  • Instagram・YouTube・Reddit をすでに Safari で使っていて、そのままがいい人
  • YouTube のコメントや終了画面、Facebook の Marketplace など、とても細かいスイッチがほしい人
  • iPad や Mac でも使える、安いサブスクがひとつでいい人
  • 長く続いていて（2020年から）、評価の多いアプリがいい人

minulo が合う人

  • TikTok・Threads・Pinterest・Snapchat もフィードなしで使いたい人
  • 消す機能はサブスクなしの無料がいい人
  • 公式アプリをスクリーンタイムでロックして、minulo から開くようにしたい人
  • Instagram や TikTok を DM だけにする無料の設定がほしい人

minulo が見せるのは公式アプリではなく各 SNS のウェブ版なので、画面は公式アプリと少し違います。公式アプリを minulo でロックしている間は、その通知も届きません。ただし 1.0.19 からは、Pro の方はベータ機能の DM の通知をオンにすると、Instagram を止めている間も Instagram の DM の通知だけは届きます（スリープモード・ワークモードの間と、1日の上限に達した後は届きません）。minulo は出たばかりで、評価はまだ少ないです。

#blockit の代わりに minulo は使える？

SNS をどこで使っているかによります。#blockit は Safari の中でしか動かないので、Instagram・YouTube・Reddit をすでに Safari で開いている人に向いています。minulo は専用のアプリで、TikTok・Threads・Snapchat を含む10の SNS に対応し、公式アプリをスクリーンタイムでロックでき、消す機能は無料です。サイトごとのスイッチの細かさと、続いてきた年数では #blockit が上です。

#blockit は無料？

ダウンロードは無料で、7日間の無料体験があります。そのあとはサブスクで、米国の App Store には月額0.99ドル・年額3.99ドル・年額＋ファミリー共有7.99ドルが並んでいます（2026-11-04 確認）。minulo ではリール・ショート・おすすめ投稿を消す機能は無料で、Pro は米国で月9.99ドル・年39.99ドル（日本は月1,480円・年6,800円）です。

#blockit は Instagram のアプリのリールもブロックできる？

いいえ。説明には、Apple の Safari のコンテンツブロッカーの仕組みを使っていて、Safari のアプリで見るサイトの一部しか取り除けないとあります（2026-11-04 確認）。minulo も公式の Instagram のアプリは変えませんが、スクリーンタイムでロックでき、Instagram を minulo の中でリールを消して開けます。
