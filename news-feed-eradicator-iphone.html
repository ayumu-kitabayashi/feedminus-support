News Feed Eradicator の iPhone 版はある？SNS のフィードだけ消してメッセージは残す方法（2026年）

iPhone で News Feed Eradicator にいちばん近いのは minulo です。Facebook・LinkedIn・インスタ・YouTube などをフィードを消した状態で開き、メッセージはそのまま使えて、消すのは無料です。

News Feed Eradicator はブラウザの拡張機能です。Chrome ウェブストアの説明によると、Facebook や Twitter などのフィードを消して代わりに名言を出すもので、iPhone や Safari の記載はありません。minulo は名言は出さず、オンにしたところだけを SNS ごとに消します。

  1. minulo を入れ、「サービスを追加」から Facebook・LinkedIn・インスタなどを選びます。
  2. それぞれの SNS 自身のログイン画面でログインします。minulo がパスワードを受け取ったり保存したりすることはありません。
  3. SNS の横の歯車を押し、フィードの項目をオンにします。Facebook は「ホームのフィード」、LinkedIn は「ニュースフィード」、インスタは「DM以外のタブ」、YouTube は「検索窓以外のホーム」です。
  4. 「ブロック」タブで、公式アプリをスクリーンタイムで止めます（1回2時間まで無料）。ブロック画面の「minulo で開く」から移れます。

News Feed Eradicator とは

Chrome ウェブストアの説明では、Facebook や Twitter などの SNS でいちばんハマりやすいところとしてフィードを消し、その場所に名言を出す Chrome の拡張機能とされています。ほかの機能はそのまま使えます。対応するサイトの一覧は書かれておらず、iPhone・Safari・App Store のアプリについても触れていません。

iPhone では別のやり方になるわけ

ブラウザの拡張機能が変えられるのはウェブページです。公式の Facebook・LinkedIn・インスタのアプリはウェブページではなく、アプリの中のフィードを外から消せるアプリはありません。minulo は各 SNS の公式サイトを自分のアプリの中で開き、選んだところを消します。公式アプリはスクリーンタイムで止められるので、いつものアイコンを押しても静かな方に移れます。

SNS ごとに消せるフィードは上の表のとおりです。何を消すかはあとからいつでも変えられ、消さなかったところはその SNS のウェブ版と同じように使えます。10の SNS すべてで、消すのは無料で時間の制限もありません。minulo Pro では、予定・ハードモード・2時間より長いブロック・複数のブロックリストが使えます。

パソコンでは

パソコンの Chrome で News Feed Eradicator がうまく使えているなら、そちらはそのままで大丈夫です。minulo にも Safari と Chrome で使える Mac 版があります。Chrome で使うときは、まず Mac アプリを入れ、Mac アプリの中から Chrome 拡張を足します。

minulo の弱いところも書いておきます。消えるのは minulo の中だけで、公式アプリは変わりません。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は使えません。minulo は iPhone のアプリで、Safari と Chrome で使える Mac 版もあります。Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

News Feed Eradicator は iPhone で使える？

Chrome ウェブストアの説明は Chrome の拡張機能としてのもので、iPhone や Safari の記載はありません。iPhone では minulo で Facebook のホームのフィード、LinkedIn のニュースフィード、インスタの DM 以外のタブを消せて、消すのは無料です。

iPhone で Facebook のフィードだけ消してメッセージは使える？

minulo の中なら使えます。Facebook を開いて「ホームのフィード」をオンにすると、メッセージとお知らせは残ります。リールと Watch、マーケットプレイスも消せます。

LinkedIn のフィードを消してメッセージは使える？

使えます。minulo で LinkedIn の「ニュースフィード」をオンにすれば、メッセージと求人だけで使えます。

minulo も名言を出す？

出しません。オンにしたところを消すだけです。

公式アプリの中のフィードも消える？

消えません。消えるのは minulo の中だけです。公式アプリを開かないようにするには、「ブロック」タブで止めます（1回2時間まで無料）。

minulo は無料で使える？

10の SNS すべてで、消すのは無料で時間の制限もありません。予定・長いブロック・ハードモードは minulo Pro です。
