Unhook の iPhone 版はある？YouTube のおすすめ・ショート・コメントを消す方法（2026年）

パソコンで Unhook を使ってしていることは、iPhone では minulo でできます。minulo は YouTube をショート・ホームのおすすめ・コメントを消した状態で開き、消すのは無料です。

Unhook はブラウザの拡張機能です。公式サイトには Chrome・Firefox・Edge 向けのボタンがあり、Chrome ウェブストアの説明には Safari や iPhone の記載がありません。App Store には Be Timeful Inc の「Unhook:」という iPhone アプリがあり、YouTube のフィードを止めると書いていますが、拡張機能のサイトからはリンクされていないので、同じ開発元かは分かりません。私たちは試していません。

  1. minulo を入れ、「サービスを追加」から YouTube を選びます。
  2. YouTube の横の歯車を押し、「ショート」・「ホームのおすすめ」・「コメント」をオンにします。「検索窓以外のホーム」にすると、ホームには検索窓だけが残ります。
  3. 登録チャンネル・後で見る・検索から動画を開きます。
  4. 「ブロック」タブで公式の YouTube アプリを選びます。1回2時間まで無料です。

Unhook とは、どこで使えるか

Unhook の公式サイトは、気が散るものなしで YouTube を見るための拡張機能として、おすすめのフィードやコメントなどを止めると説明し、Chrome・Firefox・Edge に入れるボタンを置いています。Chrome ウェブストアの説明には、消せるものとしてホームのフィード、横のおすすめ動画、ショート、終了画面のおすすめ、コメント、ライブチャット、探索と急上昇などが並んでいます。スマホについての記載は、Android の Firefox でモバイル版の YouTube（m.youtube.com）に使えるという一文だけで、Safari や iPhone には触れていません。

2026-11-01 に App Store で Unhook と検索すると、Be Timeful Inc の「Unhook:」という iPhone アプリが出てきました。2026-11-12 には米国の App Store のページが開かず、検索にも出なくなっていました。拡張機能のサイトにも iPhone アプリへの案内はありません。

minulo で YouTube のおすすめ・ショート・コメントを消す

minulo は YouTube の公式サイトをアプリの中で開き、オンにしたものを消します。消せるのは「ショート」・「ホームのおすすめ」・「検索窓以外のホーム」・「コメント」です。登録チャンネル・後で見る・検索はそのまま使え、何を消すかはあとからいつでも変えられます。消すのは無料で、時間の制限もありません。

切り替えの数は Unhook より少なく、横のおすすめや終了画面を個別に消すスイッチはありません。Unhook でそこを使っている人には、まったく同じにはなりません。そのかわり minulo は iPhone ならではのこともできます。公式の YouTube アプリをスクリーンタイムで止められ、ブロック画面の「minulo で開く」から移れます。

YouTube の設定でできること

YouTube ヘルプには、ショートをオフにするスイッチは見つかりませんでした。YouTube アプリではショート フィードの上限を0分にできますが、上限に達したときに出るのはリマインダーで、閉じることも無視することもできます。Google のヘルプには、ホームにおすすめ動画を表示したくない場合は、再生履歴を削除してオフにする方法があるとあります。次の動画が勝手に始まらないようにするには、プロフィール写真→設定→［自動再生］をオフにします。

パソコンでは

パソコンの Chrome や Firefox で Unhook がうまく使えているなら、そちらはそのままで大丈夫です。minulo にも Safari と Chrome で使える Mac 版があります。Chrome で使うときは、まず Mac アプリを入れ、Mac アプリの中から Chrome 拡張を足します。このページでは、Mac 版が YouTube のどこを消すかまでは扱いません。

minulo の弱いところも書いておきます。消えるのは minulo の中だけで、公式アプリは変わりません。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ただし 1.0.19 からは、Pro の方はベータ機能の DM の通知をオンにすると、Instagram を止めている間も Instagram の DM の通知だけは届きます（スリープモード・ワークモードの間と、1日の上限に達した後は届きません）。ストーリーズの投稿・音声メッセージ・通話は使えません。minulo は iPhone のアプリで、Safari と Chrome で使える Mac 版もあります。Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

Unhook の iPhone 版はある？

Unhook の拡張機能のサイトにあるのは Chrome・Firefox・Edge 向けで、Chrome ウェブストアの説明には Safari や iPhone の記載がありません。App Store にあった Be Timeful Inc の「Unhook:」は、2026-11-12 には米国のページが開かなくなっていました。iPhone では minulo で YouTube のショート・ホームのおすすめ・コメントを消せて、消すのは無料です。

Unhook は iPhone の Safari で使える？

公式サイトにも Chrome ウェブストアの説明にも Safari の記載はありません。スマホについては、Android の Firefox でモバイル版の YouTube に使えるとだけ書かれています。

iPhone で YouTube のおすすめを消すには？

minulo で YouTube を開き、「ホームのおすすめ」か「検索窓以外のホーム」をオンにします。YouTube 自体では、Google のヘルプによると、再生履歴を削除してオフにするとホームにおすすめ動画が出なくなります。

iPhone で YouTube のコメントを消せる？

minulo の中なら消せます。「コメント」は YouTube で消せる項目の1つで、無料です。YouTube ヘルプのコメントの設定は、自分の動画を管理するクリエイター向けのものです。

minulo で公式の YouTube アプリも変わる？

変わりません。ショートやおすすめが消えるのは、minulo の中で YouTube を開いたときだけです。公式アプリを開かないようにするには、minulo の「ブロック」タブで止めます（1回2時間まで無料）。

minulo は無料で使える？

ショート・ホームのおすすめ・コメントを消すのは無料で、時間の制限もありません。スリープモード・ワークモード・2時間より長いブロック・ハードモードは minulo Pro です。
