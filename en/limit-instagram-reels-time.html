How to set a Screen Time limit for Instagram

This limits all of Instagram, not just Reels.

iOS 26 and earlier

  1. Open Settings and tap Screen Time.
  2. Tap App Limits, then Add Limit.
  3. Tap a category name, select Instagram, tap Next and set the time.
  4. Limits can be ignored by default. To make them stick, set a Screen Time passcode and turn on Block at End of Limit.

iOS 27

  1. Open Settings, tap Screen Time, then Time Allowances.
  2. Set how long you can use a category such as Social Media each day.
  3. If an app declares an associated website, the Time Allowance applies to both (Apple).

Set a daily time limit in Instagram (a reminder) or a Screen Time limit (a block, with a passcode). Both cover all of Instagram. If Reels are the problem, open Instagram in an app that hides Reels instead.
