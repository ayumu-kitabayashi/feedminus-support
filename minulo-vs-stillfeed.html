minulo と Stillfeed の違い：リールとショートを消して DM は残すアプリを比べる（2026年）

Stillfeed と minulo の仕組みは同じです。アプリの中で Instagram や YouTube にログインすると、そこではリール・発見・ショートが消え、DM はそのまま使えます。違うのは、対応している SNS の数、メッセージだけにする見方にお金がかかるかどうか、そして公式アプリをどう扱うかです。

2026-10-24

このページは minulo の開発者・北林歩（Ayumu Kitabayashi）が書いています。自分のアプリと比べているので、その点は割り引いて読んでください。Stillfeed については、米国の App Store の説明と公式サイト（stillfeed.pages.dev）だけをもとにしていて、2026-10-20 に確かめました。日本の App Store の評価数だけは 2026-10-24 に確かめています。機能や料金は変わることがあります。

Stillfeed が合う人

  • 使うのは Instagram と YouTube だけで、その2つのためだけのアプリがいい人
  • YouTube で何が消えるかを細かく知りたい人（検索結果のショートや /shorts/ のリンクまで書いてある）
  • 1週間に消した数を見たい人
  • 公式アプリには手を付けず、開く前に確認してくれるくらいがちょうどいい人

minulo が合う人

  • Instagram と YouTube のほかに、TikTok・Snapchat・X・Threads なども使っている人
  • Instagram を DM だけで使いたいけれど、お金はかけたくない人
  • アプリを日本語で使いたい人
  • つい公式アプリを開いてしまうので、アイコンを押したらリールのない画面に行くようにしたい人

minulo が見せるのは公式アプリではなく各 SNS のウェブ版なので、画面は公式アプリと少し違います。公式アプリを minulo で止めている間は、その通知も届きません。

グループDMのためにインスタが要る学生には、どっちがいい？

どちらも、リールを消したまま Instagram の DM が使え、そこまではどちらも無料です。Instagram をメッセージだけにしたいなら、Stillfeed の「DMs Only」は Pro の機能で、minulo の「DM以外のタブ」は無料です。Instagram と YouTube しか使わないなら、Stillfeed でも足ります。

Stillfeed は TikTok に対応している？

App Store のページには TikTok の名前がなく、書かれているのは Instagram と YouTube です。minulo では TikTok の「おすすめ」を消してメッセージは使え、TikTok を DM だけにする設定もあります。

公式の Instagram のアイコンを押すとどうなる？

Stillfeed は、消すのは自分のブラウザの中で、Instagram のアプリの中ではないと書いていて、公式アプリを止める機能は App Store のページにないので、公式アプリはいつもどおり開きます。minulo はスクリーンタイムで公式アプリをロックでき、アイコンを押すとブロック画面が出て、「minulo で開く」からリールのない Instagram に移れます。

実績があるのはどっち？

どちらも新しいアプリです。Stillfeed は2026年7月から、minulo は2026年9月から App Store にあります。2026-10-20 の時点で、どちらも米国の評価はありませんでした。
