iPhoneでXの「おすすめ」だけを消して、メッセージは使う方法

minulo を使うと、X はそのまま使いながら、「おすすめ」のように時間を取られる部分だけを非表示にできます。消せるものと、やり方をまとめました。

2026年9月27日 更新

Xで消せるものは何ですか？

minulo の中で X を開くと、次のものを1つずつ選んで非表示にできます。どれを消すかは、あとからいつでも変えられます。

  • おすすめ

消したあとも、何が使えますか？

メッセージ、通知、フォロー中 は、minulo のホームからすぐに開けます。消したもの以外は、X のウェブ版と同じように使えます。

やり方は？

  1. App Store で minulo を入れます。
  2. ホームの「サービスを追加」から X を選びます。
  3. X の横の歯車を押し、消したいものをオンにします。
  4. 公式アプリも止めたいときは、「ブロック」のタブでスクリーンタイムを許可し、「ブロックするアプリ」に X を選びます。

公式のXアプリはどうなりますか？

iPhone のスクリーンタイムの仕組みで、公式の X アプリを開けないようにできます。開こうとすると「ブロック中です」という画面が出て、「minulo を開く」のボタンから minulo に移れます。このブロックは無料です。

無料で使えますか？

X の非表示と、公式アプリのブロックは無料です。曜日や時間帯で自動で切り替わる予定、ロックモード、複数のブロックリストは minulo Pro の機能です。
