iPhoneでXの「おすすめ」だけを非表示にして、メッセージは使う方法

minulo を使うと、X はそのまま使いながら、「おすすめ」のように時間を取られる部分だけを非表示にできます。消せるものと、やり方をまとめました。

2026年11月6日 更新

Xで非表示にできるものは何ですか？

minulo の中で X を開くと、次のものを1つずつ選んで非表示にできます。どれを消すかは、あとからいつでも変えられます。

  • おすすめ

非表示にしたあとも、何が使えますか？

メッセージ、通知、フォロー中 は、minulo のホームからすぐに開けます。非表示にしたもの以外は、X のウェブ版と同じように使えます。

やり方は？

  1. App Store で minulo を入れます。
  2. ホームの「サービスを追加」から X を選びます。
  3. X の横の歯車を押し、非表示にしたいものをオンにします。
  4. 公式アプリも止めたいときは、「ブロック」のタブでスクリーンタイムを許可し、「ブロックするアプリ」に X を選びます。

公式のXアプリはどうなりますか？

iPhone のスクリーンタイムの仕組みで、公式の X アプリを開けないようにできます。開こうとすると「ブロック中です」という画面が出て、「minulo で開く」のボタンから minulo に移れます。このブロックは無料です。

無料で使えますか？

X の非表示と、公式アプリのブロックは無料です。寝る時間と起きる時間を決めるスリープモード、仕事の曜日と時間を決めるワークモード、ハードモード、1日の上限は minulo Pro の機能です。

［フォロー中］に切り替えて、そのままにするやり方

  1. X を開き、ホームにします。
  2. 上の［フォロー中］を押すか、［おすすめ］から左にスワイプします。
  3. ［フォロー中］を表示したまま X を閉じます。

X のヘルプには、X を閉じた際に選択されていたタイムラインが、次回開いたときに再度表示されると書かれています。一度でも［おすすめ］をのぞいてから閉じると、次は［おすすめ］から始まるので、閉じる前に［フォロー中］へ戻しておきます。

つい見てしまう話題をミュートする

決まった話題でいつも［おすすめ］に引き込まれるなら、その言葉をミュートします。［設定とプライバシー］→［プライバシーとセキュリティ］→［ミュートとブロック］→［ミュートするキーワード］を開き（通知タブからも行けます）、言葉・ハッシュタグ・@ユーザー名を入れて、ホームタイムライン・通知のどちらか、または両方を選びます。期間は無期限・24時間・7日・30日から選べます。

X のヘルプによると、ミュートしたキーワードも検索には出ます。また、特定のアカウントの通知をオンにしている場合、その通知はミュートされません。
