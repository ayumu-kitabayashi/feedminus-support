Safari и Chrome на Mac: приложение minulo для Mac

У minulo есть версия для Mac, которая работает в Safari и Chrome. Сначала установите приложение для Mac с главной страницы minulo.app, а чтобы пользоваться Chrome, добавьте расширение для Chrome через приложение для Mac. Пока приложение для Mac есть только на японском.

В политике конфиденциальности minulo (на японском) сказано, что приложение для Mac читает только адрес страницы, открытой в браузере, и, если эта страница ведет в ленту или к коротким видео, переводит вас в выбранное вами место. В приложении для Mac и в расширениях для Chrome и Safari аналитики нет, а в расширениях нет кода, который обращается к внешним серверам. Какие части YouTube скрывает приложение для Mac, на этой странице не описано. minulo работает на iPhone и Mac, версий для Windows и Android нет.

Что умеют собственные настройки YouTube на компьютере

На youtube.com можно нажать на значок меню рядом с названием раздела на главной, в том числе полки Shorts, и выбрать «Не интересует». Справка YouTube описывает это как отзыв, по которому настраиваются рекомендации, и не говорит, надолго ли раздел пропадает. Второй способ связан с историей просмотра: YouTube пишет, что если ее отключить и недавней истории нет, рекомендации на главной странице убираются. Какое расширение скрывает YouTube Shorts?

В Chrome, Firefox и Edge есть Unhook, и в его карточке в Chrome Web Store есть переключатель Hide YouTube Shorts. В Safari и Chrome на Mac можно использовать приложение minulo для Mac. Сначала установите приложение для Mac, затем добавьте расширение для Chrome через него.

Работает ли Unhook в Safari?

На сайте Unhook есть кнопки для Chrome, Firefox и Edge, а в карточке в Chrome Web Store Safari не упоминается. В Safari на Mac можно использовать приложение minulo для Mac.

Как пользоваться minulo в Chrome?

Сначала установите приложение для Mac с главной страницы minulo.app, затем добавьте расширение для Chrome через приложение для Mac. Оно работает в Chrome на Mac, а приложение для Mac пока есть только на японском.

Можно ли скрыть Shorts на youtube.com без расширения?

Настройки, которая убирает Shorts, у YouTube нет. «Не интересует» на полке Shorts может сократить их число, но справка YouTube описывает это как отзыв, и полка может вернуться.

Как скрыть YouTube Shorts на iPhone?

Откройте YouTube в minulo, нажмите на шестеренку и включите «Shorts». Скрытие бесплатное, а подписки и поиск работают.

Почему полка Shorts возвращается

Справка YouTube описывает отметку «Не интересует» как то, что помогает улучшать рекомендации. Она не обещает, что раздел останется скрытым, и срока мы не нашли. Кроме того, справка YouTube о Shorts называет главную страницу YouTube одним из мест, где зрители находят Shorts, наряду с поиском, подписками и уведомлениями. Так что полка входит в главную по замыслу, и нажатие «Не интересует» опускает ее, а не удаляет.

Отметки хранятся в вашем аккаунте Google, поэтому полка вернется и в таких случаях: если удалить отметки «Не интересует» в «Моих действиях», выйти из аккаунта или зайти в другой аккаунт Google.

Как отменить «Не интересует» на YouTube?

Откройте «Мои действия», выберите «Другие действия» и удалите «Видео, которые вы скрыли на YouTube». Так сразу удаляются все отметки «Не интересует» и «Не рекомендовать канал».
