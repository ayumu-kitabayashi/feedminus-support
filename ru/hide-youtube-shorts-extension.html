Расширения, которые скрывают YouTube Shorts на компьютере (2026)

В Chrome, Firefox или Edge на компьютере у расширения Unhook есть переключатель, который скрывает Shorts. В Safari или Chrome на Mac можно использовать приложение minulo для Mac: сначала установите приложение для Mac, а если пользуетесь Chrome, добавьте расширение для Chrome изнутри этого приложения.

У самого YouTube нет настройки, которая убирает Shorts с главной страницы youtube.com. «Не интересует» на полке Shorts служит лишь отзывом для ваших рекомендаций, и полка может вернуться, поэтому если вы хотите скрыть Shorts как настройку, нужно расширение. На сайте Unhook есть кнопки установки для Chrome, Firefox и Edge, а для Safari нет.

  1. На Mac откройте главную страницу minulo.app и установите приложение minulo для Mac кнопкой загрузки для macOS. Пока приложение для Mac только на японском.
  2. Откройте youtube.com в Safari.
  3. Чтобы пользоваться Chrome, добавьте расширение для Chrome изнутри приложения для Mac, затем откройте youtube.com в Chrome.
  4. На iPhone откройте YouTube в minulo, нажмите на шестеренку и включите «Shorts». Скрытие бесплатное.

Скрыть Shorts с помощью Unhook (Chrome, Firefox, Edge)

На сайте Unhook описан как способ смотреть YouTube без отвлечений, который блокирует ленты рекомендаций, комментарии и другое, и там есть кнопки установки для Chrome, Firefox и Edge. В карточке в Chrome Web Store около 30 переключателей, в том числе Hide YouTube Shorts, лента на главной, боковая панель с рекомендациями, подсказки в конце видео, комментарии, а также Explore и Trending. Когда мы смотрели 2026-11-02, в карточке было указано 1 000 000 пользователей, оценка 4,9 по 4,6 тыс. оценок, обновление от 22 марта 2026 года (версия 1.6.9), цена не указана, и была просьба о пожертвованиях.

Ни на сайте, ни в карточке Safari не упоминается. Из телефонов описан только мобильный YouTube (m.youtube.com) через Firefox на Android. Другие расширения в Chrome Web Store тоже пишут, что скрывают Shorts, но на этой странице указан только Unhook, сайт и карточку которого мы проверили. Сам Unhook мы не тестировали.

Safari и Chrome на Mac: приложение minulo для Mac

У minulo есть версия для Mac, которая работает в Safari и Chrome. Сначала нужно приложение для Mac: установите его с главной страницы minulo.app, а чтобы пользоваться Chrome, добавьте расширение для Chrome изнутри приложения для Mac. Пока приложение для Mac только на японском.

В политике конфиденциальности minulo (на японском) сказано, что приложение для Mac читает только адрес страницы, открытой в браузере, и, если эта страница ведет в ленту или к коротким видео, переводит вас в выбранное вами место. В приложении для Mac и в расширениях для Chrome и Safari аналитики нет, а в расширениях нет кода, который обращается к внешним серверам. Какие части YouTube скрывает приложение для Mac, на этой странице не описано. minulo работает на iPhone и Mac, версий для Windows и Android нет.

Что умеют собственные настройки YouTube на компьютере

На youtube.com можно нажать на значок меню рядом с названием раздела на главной, в том числе полки Shorts, и выбрать «Не интересует». Справка YouTube описывает это как отзыв, по которому настраиваются рекомендации, и не говорит, надолго ли раздел пропадает. Второй способ связан с историей просмотра: YouTube пишет, что если ее отключить и недавней истории нет, рекомендации на главной странице убираются. Какое расширение скрывает YouTube Shorts?

В Chrome, Firefox и Edge есть Unhook, и в его карточке в Chrome Web Store есть переключатель Hide YouTube Shorts. В Safari и Chrome на Mac можно использовать приложение minulo для Mac. Сначала установите приложение для Mac, затем добавьте расширение для Chrome изнутри него.

Работает ли Unhook в Safari?

На сайте Unhook есть кнопки для Chrome, Firefox и Edge, а в карточке в Chrome Web Store Safari не упоминается. В Safari на Mac можно использовать приложение minulo для Mac.

Как пользоваться minulo в Chrome?

Сначала установите приложение для Mac с главной страницы minulo.app, затем добавьте расширение для Chrome изнутри приложения для Mac. Оно работает в Chrome на Mac, а приложение для Mac пока только на японском.

Можно ли скрыть Shorts на youtube.com без расширения?

Настройки, которая убирает Shorts, у YouTube нет. «Не интересует» на полке Shorts может сократить их число, но справка YouTube описывает это как отзыв, и полка может вернуться.

Как скрыть YouTube Shorts на iPhone?

Откройте YouTube в minulo, нажмите на шестеренку и включите «Shorts». Скрытие бесплатное, а подписки и поиск работают.
