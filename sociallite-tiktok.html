TikTok が抜けやすい理由

この種類のアプリの多くは、Instagram と YouTube から始まっています。よく知られた2つのうち、SocialLite は App Store のページに TikTok が無く、UNDOOMED は非対応と書いています。夜に開いてしまうのが TikTok なら、払う前に対応SNSの一覧を確かめてください。

minulo で「おすすめ」を消す

  1. minulo を入れ、ホームから TikTok を足します。
  2. minulo の中で、TikTok のログイン画面からログインします。
  3. TikTok の横の歯車をタップし、［おすすめ］（おすすめ・見つける・投稿を非表示）をオンにします。［おすすめアカウントを非表示］もあります。
  4. メッセージだけにしたいときは［DM以外のタブ］を選びます。この場合は「フォロー中」も消えます。
  5. 必要なら、公式の TikTok アプリをスクリーンタイムで止めます。1回2時間まで無料です。

メッセージと「フォロー中」は minulo のホーム画面からすぐ開けます。公式の TikTok アプリを止めている間は通知が届かず、minulo が代わりに通知を送ることもありません。

minulo の弱いところも書いておきます。公式アプリそのものは変えられないので、リールやショートが消えるのは minulo の中だけです。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は、各SNSのウェブ版に無いので使えません。使えるのは iPhone と Mac（ほかに Chrome と Safari の機能拡張）で、Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

SocialLite は TikTok に対応している？

米国の App Store の説明と更新履歴には TikTok が出てきません。書かれているのは Instagram・YouTube・Snapchat・X・Reddit などです。

UNDOOMED は TikTok に対応している？

していません。UNDOOMED は TikTok と Snapchat を非対応としています。対応しているのは Instagram・Threads・Reddit・Facebook・X・YouTube・LinkedIn です。

TikTok のアプリで「おすすめ」をオフにできる？

TikTok に消す設定はありません。制限モードは一部の動画を除くだけで「おすすめ」は流れ続け、1日の利用時間は画面に出るパスコードを入れれば見続けられるお知らせです。

TikTok の「おすすめ」を消して DM は残せるアプリは？

minulo なら無料でできます。TikTok を開くと「おすすめ」・見つける・投稿が消え、メッセージと「フォロー中」は使えます。Reelmute も「おすすめ」を隠せると書いていて、DM だけの表示は Premium です。

Instagram と TikTok をまとめて使えるアプリは？

minulo は両方に対応していて、ほかに YouTube・X・Threads・Facebook・Pinterest・Reddit・LinkedIn・Snapchat も使えます。Instagram だけで通知も欲しいなら、SocialLite も有力です。
