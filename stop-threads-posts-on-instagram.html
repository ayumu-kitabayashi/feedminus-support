インスタに出るスレッズ（Threads）の投稿を消す方法（iPhone・2026年）

Instagram のフィードに出る Threads の投稿をまとめて止める設定は、Instagram のヘルプでは見つかりませんでした。Meta は2023年の終わりから、Threads の投稿を Instagram と Facebook に直接出しています。今できるのは、Threads の投稿を1件ずつ非表示にすることと、フォローしている人だけが出る［フォロー中］に切り替えることです。Threads の設定にある「他のアプリでのおすすめ」は自分の投稿の話で、自分に見える投稿は変わりません。インスタは DM だけ使えればいいなら、minulo でフィードごと消して開けます。無料です。

2026-10-24

このページは minulo の開発者、北林 歩が書いています。Instagram と Threadsについては、下の出典を 2026-10-24 に確かめました。メニューの名前は、アプリの更新で変わることがあります。

方法できること限界
投稿を非表示（Threads の投稿の「…」）その投稿をフィードから消す（Guiding Tech の手順）。1件ずつ。Instagram のヘルプには書かれていない。
［フォロー中］（左上の［Instagram］を押す）フォローしている人の投稿だけを新しい順に、おすすめなしで表示する。開くたびに選び直す。
他のアプリでのおすすめ（Threads の設定）自分の Threads の投稿が Instagram・Facebook でおすすめされないようにする。自分に見える投稿は変わらない。
minulo（無料）おすすめの投稿を消して、またはフィードをまるごと消して Instagram を開く。DM と自分の投稿は使える。公式の Instagram アプリそのものは変わらない。

インスタに Threads の投稿が出る理由

2023年11月、Instagram の責任者アダム・モセリ氏が、Threads の投稿を Facebook と Instagram に直接出す機能を入れたと書いています。Threads の投稿をより多くの人に届けるためです。フィードに出る Threads の投稿は、Meta が選んで Instagram に出しているもので、フォローしていない人の投稿も多く混ざります。

Threads の投稿を1件ずつ非表示にする

  1. Instagram のフィードで Threads の投稿を見つけます。
  2. 投稿の横の「…」を押します。
  3. ［非表示］を押します。

この手順は Guiding Tech が紹介しているもので、何度かくり返す必要があるとも書かれています。Instagram のヘルプには Threads の投稿についての説明がなく、数件非表示にすれば出なくなるのかは確かめられませんでした。

Instagram の通知に出る Threads のお知らせは、通知タブでその通知を左にスワイプし、「…」から「このような通知をオフにする」を選ぶと止められる、と Guiding Tech は書いています。

［フォロー中］に切り替える

フィードの左上の［Instagram］を押して［フォロー中］を選びます。Instagram のヘルプによると、フォローしている人の投稿が新しい順に並び、Meta の説明ではおすすめ投稿は出ません。開き直すとふつうのフィードに戻るので、毎回選び直します。くわしくはインスタでフォロー中の人だけを見る方法にまとめました。

Threads の設定でできること

Threads の［設定］→［プライバシー］に、自分の投稿を他のアプリでおすすめするかどうかの項目があります（英語の画面では Suggesting posts on other apps）。Threads の公式アカウントによると、ここで Instagram と Facebook のどちらか、または両方でのおすすめをオフにできます。これは自分の Threads の投稿が、ほかの人の Instagram に出るかどうかの設定です。ほかの人の Threads の投稿が自分のフィードに出るのは止まりません。

minulo でフィードなしの Instagram にする

minulo は、アプリの中で Instagram の公式のウェブ版を開きます。Instagram の横の歯車から、［おすすめの投稿］［フィードをまるごと非表示］［DM 以外のタブ］をオンにできます。フィードをまるごと消せば、Threads の投稿も含めてフィードには何も出ません。DM と自分の投稿はそのまま使えます。Threads も minulo に追加すれば、おすすめではなく［フォロー中］から開けます。

消すのは無料です。スクリーンタイムで公式の Instagram アプリを止めるのも1回2時間までは無料で、止めている間は公式アプリの通知は届きません。minulo Pro では、曜日と時間で切り替わるスケジュール、もっと長いブロック、ハードモード、複数のブロックリストが使えます。

インスタのフィードに Threads の投稿が出るのはなぜ？

Meta が Threads の投稿を Instagram と Facebook に直接出しているからです。2023年11月に Instagram の責任者アダム・モセリ氏が、Threads の投稿をより多くの人に届けるための機能として発表しました。フォローしていない人の投稿も出ます。

インスタに出る Threads の投稿を完全にオフにできる？

2026年10月の時点で、Instagram のヘルプにはその設定が見つかりませんでした。Threads の投稿を「…」から1件ずつ非表示にするか、フォローしている人だけが出る［フォロー中］に切り替えます。インスタは主に DM で使うなら、minulo でフィードをまるごと消して開けます。無料です。

Threads の「他のアプリでのおすすめ」をオフにすれば、インスタに出なくなる？

自分に見える投稿は変わりません。この設定は、自分の Threads の投稿が Instagram と Facebook でおすすめされるかどうかを決めるものです。ほかの人の Threads の投稿は、これまでどおり自分のフィードに出ることがあります。

［フォロー中］にすれば Threads の投稿は消える？

［フォロー中］にはフォローしている人の投稿だけが、おすすめなしで出るので、ほかの人の Threads の投稿がおすすめとして出ることはありません。ただ、開き直すとふつうのフィードに戻るので、毎回選び直します。

インスタに来る Threads の通知を止めるには？

Guiding Tech によると、Instagram の通知タブで Threads の通知を左にスワイプし、「…」から「このような通知をオフにする」を選びます。Instagram のヘルプではこの手順は見つかりませんでした。
