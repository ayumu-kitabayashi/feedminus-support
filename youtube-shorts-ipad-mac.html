ショートをオフにする設定はある？

2026年10月の時点で、YouTube のヘルプには、アプリでも youtube.com でも見つかりませんでした。ヘルプに書かれているのは、ショートの表示を減らすことと、ショート フィードに上限をつけることで、ショートを消すことではありません。下に、YouTube 自身の機能を端末ごとにまとめました。

iPad：ショート動画の表示を減らす

  1. YouTube アプリで［ホーム］を開きます。
  2. ショート動画のグリッドまでスクロールします。
  3. グリッドの上のその他アイコンをタップします。
  4. ［ショート動画の表示を減らす］をタップします。

取り消すときは、マイ アクティビティの左のメニューで［その他のアクティビティ］を開き、［ショート動画の表示を減らす］で［削除］を選びます。

iPad：ショート フィードの上限を設定する

  1. YouTube アプリにログインします。
  2. ［マイページ］タブ →［設定］をタップします。
  3. ［時間管理］→［ショート フィードの上限］をタップします。
  4. 時間を選びます。0 も選べます。

ショート フィードで上限に達するとリマインダーが出て、閉じるか、上限を無視するかを選べます。ヘルプの手順は YouTube アプリのもので、youtube.com については書かれていません。

Mac（Safari）：［興味がない］と［チャンネルをおすすめに表示しない］

  1. youtube.com のホームで、見たくない動画・再生リスト・投稿・セクションを見つけます。
  2. タイトルの横のその他アイコンをクリックします。
  3. ［興味がない］をクリックします。

何度も出てくるチャンネルは、その動画やショート動画の横のその他アイコンから［チャンネルをおすすめに表示しない］を選びます。どちらのフィードバックも、あとからマイ アクティビティの［YouTube の「興味なし」のフィードバック］で削除できます。

Mac（Safari）：再生履歴をオフにする

  1. マイ アクティビティ（myactivity.google.com）を開き、ログインします。
  2. 左のサイドバーで［管理］タブをクリックします。
  3. ［オフにする］を選びます。

YouTube のヘルプによると、関連性の高い、または最近の再生履歴が少なく、その履歴にもとづくおすすめを希望しないと指定している場合、YouTube のトップページのおすすめなどの機能は無効になります。Google アカウントの設定なので、Mac だけでなくほかの端末にも効きます。オフの間に見た動画は履歴に残りません。検索結果やチャンネルのページでもショートが消えるかどうかは、ヘルプに書かれていません。

iPad：スクリーンタイムで Web サイトを止める

Apple によると、特定の Web サイトを URL でブロックできます。［設定］→［スクリーンタイム］→［コンテンツとプライバシーの制限］をオンにし、［App Store、メディア、Web、およびゲーム］→［Webコンテンツ］を開きます。［成人向けWebサイトを制限］を選び、［常に許可しない］の［Webサイトを追加］からアドレスを入れます。youtube.com のショートのアドレスを入れたときにショートのページだけが止まるかは試していないので、使う前にご自身の iPad で確かめてください。

minulo でできること・できないこと

minulo は iPhone のアプリです。アプリの中で YouTube の公式のウェブ版を開き、YouTube の横の歯車から消すものを選べます。［ショートの棚を非表示］［下のショートタブを非表示］［ショートを普通の再生画面で開く］［ホームのおすすめ］（登録チャンネルは残ります）です。消すのは無料です。公式の YouTube アプリそのものは変わりません。スクリーンタイムで公式アプリを止めることもでき、1回2時間までは無料です。止めている間は公式アプリの通知は届かず、minulo からも通知は送りません。minulo Pro では、曜日と時間で切り替わるスケジュール、もっと長いブロック、ハードモード、複数のブロックリストが使えます。

minulo には iPad 版がないので、iPad では上の YouTube の設定を使ってください。minulo にできないことのページには、使えるのは iPhone・Mac・Chrome・Safari と書いていますが、このページでは Mac などの版は扱っていません。Android 版はまだありません。

2026年10月の時点で、YouTube のヘルプにはその設定は見つかりませんでした。YouTube アプリでは、ホームのショート動画のグリッドのその他アイコンから［ショート動画の表示を減らす］を選べます。［マイページ］→［設定］→［時間管理］の［ショート フィードの上限］は 0 にもできますが、リマインダーは閉じたり無視したりできます。

Mac の Safari で youtube.com のショートを消せる？

YouTube にはそのスイッチはありません。youtube.com では、ホームの動画やセクションの横のその他アイコンから［興味がない］を選べます。マイ アクティビティで再生履歴をオフにし、最近の履歴がなければ、トップページのおすすめは表示されなくなります。

YouTube のヘルプの手順は YouTube アプリのものだけで、ブラウザの youtube.com については書かれていないため、確かめられませんでした。
