ショート動画をやめたいときの、見ない方法（YouTube・インスタ・TikTok／iPhone・2026年）

minulo なら、YouTube のショート、インスタのリール、TikTok のおすすめを消したまま、検索・DM・フォロー中は使えます（消す機能は無料）。

ショート動画は、アプリを開いた最初の画面や、動画を見終わったあとに出てきます。見るつもりがなくても目の前に出てくるので、やめたいと思っても続いてしまいます。アプリを消せば見なくなりますが、YouTube の調べもの、インスタの DM、TikTok のメッセージまで使えなくなります。アプリごとに公式の設定でできることと、ショート動画だけを消す方法をまとめます。

2026-11-02

このページは minulo の開発者、北林 歩が書いています。比べている方法のひとつが自分のアプリなので、その点は割り引いて読んでください。YouTube と TikTok と iPhone の設定は、下の出典を 2026-11-02 に確かめました。メニューの名前は、アプリや iOS の更新で変わることがあります。

minulo の2026年10月のデータでは、minulo の中で SNS を開いた人の87%が Instagram を、37%が YouTube を開きました（minulo 調べ・2026年10月）。

アプリ公式の設定でできること限界minulo で消せるもの
YouTube［ショート フィードの上限］を 0 にできる上限に達するとリマインダーが出て、閉じるか無視するかを選べるショートとおすすめ
インスタリールのタブをオフにする設定は見つからないアプリを開けばリールに行けるリールと発見タブ、おすすめの投稿
TikTokおすすめのリセット、興味なし、1日の時間制限おすすめそのものは消えないおすすめ（DM 以外のタブ全部も選べる）
iPhone のスクリーンタイムアプリやカテゴリごとに時間を決める、時間帯で止めるショート動画だけは選べず、DM も止まるなし（公式アプリを止めるのに使う）

YouTube のショートを 0 分にする（公式の設定）

  1. YouTube アプリにログインします。
  2. ［マイページ］タブ →［設定］を押します。
  3. ［時間管理］→［ショート フィードの上限］を押します。
  4. 上限のリストから時間を選びます。0 にもできます。

YouTube のヘルプによると、上限に達するとリマインダーが出て、ショート フィードを閉じるか、上限を無視するかを選ぶことになります。止める機能ではなく、知らせる機能です。くわしくは YouTube ショートの上限を 0 分にする方法へ。

インスタと TikTok は公式の設定で消せない

インスタには、リールのタブをオフにする設定が見つかりません（インスタのリールをオフにする方法）。TikTok は 2023 年に「おすすめ」フィードをリセットする機能を出しました。TikTok の発表では、リセットすると登録したばかりのころのような内容が出て、そこからまたおすすめが作られます。すでにしている設定やフォローしているアカウントは変わりません。おすすめのフィード自体は残ります（TikTok の「おすすめ」をオフにする方法はある？）。

ショート動画だけを minulo で消す

  1. App Store から minulo を入れます。
  2. minulo の中でインスタや YouTube、TikTok を開き、それぞれのログイン画面でログインします。minulo はパスワードを受け取りません。
  3. インスタの横の歯車で［リールと発見タブ］や［おすすめの投稿］を、YouTube の歯車で［ショートとおすすめを非表示］を、TikTok の歯車で［おすすめ］を選びます。消すのは無料です。
  4. 「ブロック」タブで公式のインスタや YouTube、TikTok を選んでブロックを始めます。アイコンを押すと「ブロック中です」の画面が出て、「minulo で開く」から移れます。無料では1回2時間までです。

これで、YouTube は検索と普通の動画、インスタは DM とフォローしている人の投稿、TikTok はメッセージが残ります。消した設定は自分でオフにするまで続きます。

minulo の弱いところも書いておきます。リールやショートが消えるのは minulo の中だけで、公式アプリは変わりません。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は使えません。minulo は iPhone のアプリで、Safari と Chrome で使える Mac 版もあります。Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

それでも公式アプリを開いてしまうとき

公式アプリは minulo の「ブロック」で止めておきます。無料では1回2時間までで、終わったらすぐ次を始められます。毎晩のスリープモードや2時間より長いブロック、解除にわざと数分かかるハードモード（文を書き写す・暗算に答える・60秒待つ）は minulo Pro です（日本は月1,480円・年6,800円）。iPhone のスクリーンタイムのスケジュールで、夜などの時間帯にアプリを止める方法もあります。

ショート動画はアプリを消さずにやめられる？

やめやすくはできます。YouTube はショート フィードの上限を 0 にでき、minulo なら YouTube のショート、インスタのリール、TikTok のおすすめを消したまま、検索や DM は使えます（消すのは無料）。

YouTube のショートの上限を 0 にしたら、もう見られない？

見られます。YouTube のヘルプでは、上限に達するとリマインダーが出て、閉じるか上限を無視するかを選ぶと説明されています。

インスタのリールはオフにできる？

インスタのアプリには、リールのタブをオフにする設定が見つかりません。minulo の中でインスタを開けば、リールと発見タブを消して DM は使えます。

TikTok のおすすめは消せる？

TikTok にはおすすめをリセットする機能はありますが、おすすめのフィードは残ります。minulo の中で TikTok を開けば、おすすめを消してメッセージは使えます。
