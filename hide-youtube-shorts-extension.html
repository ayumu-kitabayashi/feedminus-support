YouTube のショートを非表示にする拡張機能（パソコン・2026年）

パソコンの Chrome・Firefox・Edge なら、ショートを消す切り替えがある拡張機能 Unhook が使えます。Mac の Safari と Chrome なら minulo の Mac アプリが使え、Chrome で使うときは先に Mac アプリを入れ、その中から Chrome 拡張を足します。

YouTube 自体には、youtube.com のホームからショートを消す設定はありません。ショートの棚の［興味がない］はおすすめを調整するための意見で、棚はまた出てくることがあります。設定として消しておきたいなら、拡張機能を使うことになります。Unhook の公式サイトにあるのは Chrome・Firefox・Edge 向けのボタンで、Safari 向けはありません。

  1. Mac で minulo.app のトップを開き、「macOS 版をダウンロード」から minulo の Mac アプリを入れます。Mac アプリの表示は、いまは日本語だけです。
  2. Safari で youtube.com を開きます。
  3. Chrome で使うときは、Mac アプリの案内から Chrome 拡張を足し、Chrome で youtube.com を開きます。
  4. iPhone では minulo で YouTube を開き、歯車から「ショート」をオンにします。消すのは無料です。

Unhook でショートを非表示にする（Chrome・Firefox・Edge）

Unhook の公式サイトは、おすすめのフィードやコメントなどを止めて YouTube を見るための拡張機能だと説明し、Chrome・Firefox・Edge に入れるボタンを置いています。Chrome ウェブストアの説明には、Hide YouTube Shorts のほか、ホームのフィード、横のおすすめ動画、終了画面、コメント、探索と急上昇など、およそ30の切り替えが並んでいます。2026-11-02 に見たときの表示は、利用者 1,000,000 人・評価 4.9（4,600件）・更新 2026-03-22（1.6.9）で、価格の表示はなく寄付を募っていました。

Safari については、公式サイトにも Chrome ウェブストアの説明にも書かれていません。スマホは、Android の Firefox でモバイル版の YouTube（m.youtube.com）に使えるとだけあります。Chrome ウェブストアには、ほかにもショートを消すという拡張機能がありますが、このページでは公式サイトと掲載を確かめた Unhook だけを挙げています。私たちは Unhook を試していません。

Mac の Safari と Chrome では minulo の Mac アプリ

minulo には、Safari と Chrome で使える Mac 版があります。順番は Mac アプリが先です。minulo.app のトップから Mac アプリを入れ、Chrome で使うときは Mac アプリの案内から Chrome 拡張を足します。Mac アプリの表示は、いまは日本語だけです。

プライバシーポリシーによると、Mac 版はブラウザで開いているページの URL だけを読み、そこがフィードやショート動画の入口なら、自分で選んだ場所へ振り替えます。Mac 版と Chrome・Safari の機能拡張には計測ツールを組み込んでおらず、機能拡張は外部と通信するコードを含んでいません。このページでは、Mac 版が YouTube のどこを消すかまでは扱いません。minulo は iPhone と Mac 向けで、Windows 版と Android 版はありません。

YouTube の設定でできること（パソコン）

youtube.com では、ホームの各セクション（ショートの棚を含む）のタイトルの横にあるその他アイコンから［興味がない］を選べます。YouTube ヘルプはこれをおすすめを調整するための意見として説明していて、どのくらいの間消えるかは書いていません。もう1つは再生履歴で、オフにして最近の履歴がなければ、ホームのおすすめが表示されなくなると YouTube は説明しています。くわしくは YouTube のショートを PC で非表示にする方法へ。

iPhone では

minulo は YouTube の公式サイトをアプリの中で開き、「ショート」や「ホームのおすすめ」をオンにすると消します。登録チャンネル・後で見る・検索はそのまま使え、消すのは無料で時間の制限もありません。公式の YouTube アプリは変わりませんが、「ブロック」タブで止められ（1回2時間まで無料）、ブロック画面の「minulo で開く」から移れます。

minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

YouTube のショートを非表示にする拡張機能は？

Chrome・Firefox・Edge なら Unhook があり、Chrome ウェブストアの説明に「Hide YouTube Shorts」の切り替えがあります。Mac の Safari と Chrome なら minulo の Mac アプリが使えます。Mac アプリを先に入れ、Chrome 拡張はその中から足します。

Unhook は Safari で使える？

Unhook の公式サイトにあるのは Chrome・Firefox・Edge 向けのボタンで、Chrome ウェブストアの説明にも Safari の記載はありません。Mac の Safari では minulo の Mac アプリが使えます。

minulo を Chrome で使うには？

まず minulo.app のトップから Mac アプリを入れ、Mac アプリの案内から Chrome 拡張を足します。使えるのは Mac の Chrome で、Mac アプリの表示はいまは日本語だけです。

拡張機能なしで youtube.com のショートを消せる？

YouTube にショートを消す設定はありません。ショートの棚の［興味がない］で減らせますが、YouTube ヘルプはこれを意見として説明していて、棚はまた出てくることがあります。

iPhone で YouTube のショートを消すには？

minulo で YouTube を開き、歯車から「ショート」をオンにします。消すのは無料で、登録チャンネルと検索はそのまま使えます。
