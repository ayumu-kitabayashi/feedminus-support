インスタのアプリを消して Safari で使うと、DM とリールはどうなる？（iPhone・2026年）

インスタを DM だけに使いたいなら、minulo がインスタのウェブ版を開き、リールと発見のタブとおすすめ投稿を無料で消します。「DM以外のタブ」をオンにすれば、DM だけが残ります。アプリを消して Safari の instagram.com を使うのは、これとは別物です。ウェブ版にもリールと発見があるので、少し開きにくくなるだけです。Safari でリールを消すには、Nope（無料）や ScrollGuard のような Safari の機能拡張が要ります。アプリが無いとインスタの通知も届かなくなり、入れ直せば1分で元に戻ります。

インスタのアプリを消せば、リールは消える？

消えません。消えるのはアプリだけです。インスタのウェブ版にもリールと発見のタブがあり、だからこそ minulo のようにウェブ版を開くアプリには、それを隠すスイッチがあります。変わるのは、ホーム画面からワンタップで開けなくなることで、人によってはそれで十分です。

Apple のガイドによると、アプリを削除すると、アプリとそのデータが iPhone から消えます。インスタのアカウントと DM は残ります。削除するには、ホーム画面でインスタを長押しして「アプリを削除」をタップし、もう一度「アプリを削除」、最後に「削除」をタップします。ただ、入れ直せば1分で戻りますし、Safari では instagram.com がそのまま開きます。くわしくはインスタは消す・止める・リールだけ隠す、どれが続く？へ。

instagram.com で DM と通知は使える？

DM は使えます。minulo も同じウェブ版を開いていて、DM の返信や写真の投稿はできます。インスタの公式サイト（About Instagram）は、［メッセージ］→［作成］→ 相手を選んで［チャット］→［送信］という送り方を説明しています。Safari で開くスマホのウェブ版で、DM のどの機能が使えるかまでは、インスタのヘルプで確かめられませんでした。

大きく変わるのは通知です。インスタの通知は公式アプリから届くので、アプリが無いと届きません。Apple は、ホーム画面に追加したウェブサイトによっては通知の許可を求めることがあると説明していますが、instagram.com が iPhone でそうするかは確かめられませんでした。DM の通知が要るなら、アプリは残してインスタの通知をメッセージだけにする方法を使うのが確実です。

Safari の機能拡張でリールを消す

  1. Safari を開き、ページメニューのボタンをタップしてから「機能拡張を管理」をタップします。
  2. 機能拡張を検索するか、「機能拡張を閲覧」から App Store で探し、「入手」をタップします。
  3. 設定アプリで「アプリ」→「Safari」→「機能拡張」の順にタップし、入れた機能拡張をタップして「機能拡張を許可」をオンにします。

Nope は、App Store のページによると無料で、サブスクもアプリ内課金も広告もありません。instagram.com と youtube.com で使える Safari の機能拡張で、リール・ショート・発見・ストーリーズ・自動再生を隠します。iOS 17 以降が必要です。ScrollGuard は無料で、Pro のアプリ内課金があります。Safari で SNS のフィード・リール・ストーリーズ・発見を隠し、1.2.1 の更新内容でインスタの「DMs only mode」が加わりました。どちらも Safari の中だけで効くので、インスタのアプリが残っていれば、アプリの方はそのままです。

instagram.com をホーム画面に置く

  1. Safari で instagram.com を開きます。
  2. ページメニューのボタンをタップしてから「共有」をタップします。タブレイアウトが「下」か「上」なら、共有ボタンをタップします。
  3. 下にスクロールして「ホーム画面に追加」をタップします。
  4. アプリのように開きたいなら「ウェブアプリとして開く」を選び、「追加」をタップします。

中身は同じウェブ版なので、リールと発見も出ます。ウェブアプリとして開いたときにも Safari の機能拡張が効くかは、確かめられませんでした。

minulo でリールの無いインスタのウェブ版を使う

  1. minulo を入れ、その中でインスタを開きます。
  2. インスタ自身のログイン画面でログインします。minulo がパスワードを受け取ったり保存したりすることはありません。
  3. インスタの横の歯車をタップし、リールと発見のタブを隠すスイッチと、おすすめ投稿を隠すスイッチをオンにします。DM だけにしたいなら「DM以外のタブ」をオンにします。
  4. 公式アプリは消さなくてかまいません。必要なら「ブロック」タブで、公式のインスタをスクリーンタイムで止めます。1回2時間まで無料で、ブロック画面の「minulo で開く」からリールの無いインスタに移れます。

消す設定は、自分で変えるまでそのままです。minulo Pro では、曜日と時間帯の予定、長いブロック、ハードモード、複数のブロックリストが使えます。

minulo の弱いところも書いておきます。リールが消えるのは minulo の中だけで、公式アプリは変わりません。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は使えません。インスタでは、リールと発見のタブが1つのスイッチです。使えるのは iPhone と Mac（ほかに Chrome と Safari の機能拡張）で、Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

インスタはアプリ無しで DM だけ使える？

使えます。minulo がインスタのウェブ版を開き、リール・発見・おすすめ投稿を無料で消します。「DM以外のタブ」で DM だけにもできます（消えるのは minulo の中だけです）。ふつうの Safari でも instagram.com で DM は使えますが、リールと発見のタブは残ります。

インスタのウェブ版にもリールはある？

あります。ウェブ版にもリールと発見のタブがあるので、minulo のようにウェブ版を開くアプリには、それを隠すスイッチがあります。Safari なら、Nope のような機能拡張で隠せます。

インスタのアプリを消すと、アカウントも消える？

消えません。Apple のガイドによると、アプリを削除すると消えるのは iPhone の中のアプリとそのデータです。インスタのアカウントと DM は残り、ウェブ版でも、アプリを入れ直してもログインできます。

アプリが無いと DM の通知は来る？

アプリからは来ません。インスタの通知は公式アプリから届くためです。Apple は、ウェブサイトによっては通知の許可を求めることがあると説明していますが、instagram.com が iPhone でそうするかは確かめられませんでした。

インスタのリールを消す無料の Safari 機能拡張はある？

あります。Nope は App Store のページによると無料で、サブスクもアプリ内課金も広告もなく、Safari の instagram.com でリール・発見・ストーリーズを隠します。効くのは Safari の中だけです。

minulo は Safari でインスタを使うのと同じ？

同じウェブ版を使うので、DM・写真の投稿・コメントはでき、音声メッセージと通話はできません。違うのは、minulo はリール・発見・おすすめ投稿を消し、公式アプリを消さずに止められることです。
