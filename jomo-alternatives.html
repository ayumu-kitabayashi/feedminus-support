Jomo の代わりになるアプリ：リールとショートは消して DM は残す（2026年）

minulo はインスタのリール、YouTube のショート、TikTok のおすすめを消し、DM はそのまま使えます。消すのは無料です。

Jomo はスクリーンタイムを使うブロックアプリです。アプリやサイト、カテゴリをまるごと止め、1日にアプリを開ける回数を決め、ルールを何日も固定できます。アプリそのものを遠ざけたいなら、それで足ります。ただ、グループチャットのためにインスタが要るなら、インスタを止めるとチャットも止まります。minulo が違うのはそこです。

Jomo でできること

米国の App Store にある Jomo - Screen Time Blocker のページには、アプリやサイトを1つずつ（サイトはすべてのブラウザで）止めることも、SNS・ゲーム・買い物のようなカテゴリをまとめて止めることもでき、好きな予定で動かせると書かれています。2.0 の更新内容によると、ロック（Locks）はアプリを止め続けたり、1日に開ける回数を決めたり、解除の前に運動を求めたりできます。Strict Mode は、ルールを決めた日数のあいだ固定します。Jomo は Apple のスクリーンタイム API を使い、メッセージやパスワードは見られないと書いています。

ブロックアプリで学生が困るところ

クラスのグループチャット、部活やサークルの予定、友だちからのメッセージは、インスタの DM や Snapchat にあることが多いです。ブロックアプリはインスタを1つのアプリとして扱うので、リールを止めればそのチャットも止まります。返信するためにブロックを切ってしまう人も少なくありません。minulo はアプリの中身を分けて扱います。DM・フォロー中のフィード・検索は残り、リール・発見・おすすめ投稿は出てきません。

サイトを止めたい人、カテゴリをワンタップで止めたい人、アプリを開く回数を厳しく決めたい人には Jomo のほうが合います。minulo はサイトを止めません。

minulo でリールを消して DM は残す

  1. minulo の中でインスタ・YouTube・TikTok を開くminulo を入れ、その中でインスタ・YouTube・TikTok を開いて、それぞれのサービス自身のログイン画面でログインします。
  2. 消すものを選ぶインスタならリール・発見・おすすめ投稿、YouTube ならショート、TikTok ならおすすめを、1つずつ選んで消します。消すのは無料です。
  3. 公式アプリを止める「ブロック」タブでスクリーンタイムを許可し、公式アプリを選びます。無料のブロックは1回2時間までで、終わったらまた始められます。
  4. DM は minulo で使う返信したいときは、ブロック画面の「minulo で開く」を押し、minulo の中で DM を使います。リールとショートは消えたままです。

minulo Pro（米国では月9.99ドルか年39.99ドル）にすると、2時間より長いブロック、寝る時間と起きる時間を決めるスリープモード、仕事の曜日と時間を決めるワークモード、ハードモードが使えます。

minulo の弱いところも書いておきます。リールやショートが消えるのは minulo の中だけで、公式アプリは変わりません。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は使えません。minulo は iPhone のアプリで、Safari と Chrome で使える Mac 版もあります。Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

Jomo は無料？

Jomo は無料で入れられ、有料の Jomo Plus もあります。リールやショートだけを消せればいいなら、minulo の消す機能は無料です。米国の App Store のページには、Jomo Plus が月5.99ドルか年29.99ドルで、ほかに買い切りもあると書かれています。無料版でできることは App Store のページで確かめてください。

Jomo はインスタの DM も止める？

Jomo は選んだアプリを止めるので、インスタを止めれば DM も止まります。minulo はリールとおすすめ投稿を消し、minulo の中で DM はそのまま使えます。

Jomo でインスタのリールだけを消せる？

App Store のページに書かれているのはアプリ・サイト・カテゴリを止めることで、アプリの一部を消すことではありません。minulo ならリール・発見・おすすめ投稿を1つずつ消せます。

Jomo と minulo は一緒に使える？

どちらも iPhone のスクリーンタイムでアプリを止めます。2つを並べて試してはいないので、両方使うなら、同じアプリを両方で同時に止めていないか確かめてください。

無料で使える Jomo の代わりはある？

iPhone のスクリーンタイムには「アプリ使用時間の制限」（iOS 27 では「許容時間」）と「休止時間」（iOS 27 では「スクリーンタイムのスケジュール」）があります。minulo は無料で入れられ、リールとショートを消すのも、公式アプリを止めるのも無料です（1回2時間まで）。
