あります。minulo の Instagram の［DM以外のタブ］は無料で、リール・発見・ホームのフィード・おすすめ投稿が消え、残るのは DM とお知らせのタブだけです。DM だけの表示があるほかのアプリでは、その表示はたいてい有料です。UNDOOMED の Messages Only は公式サイトでは Pro、Stillfeed の DM だけの表示は Pro、Reelmute は Premium、Konvo は Instagram の DM を使うのに有料の購読が要ります。Instagram 自体には DM だけのモードはありません。

minulo での設定

  1. App Store から minulo を入れます。
  2. minulo の中で Instagram を開き、Instagram のログイン画面でログインします。パスワードは minulo には届かず、保存もされません。
  3. Instagram の横の歯車をタップし、［DM以外のタブ］をオンにします。
  4. 必要なら、公式の Instagram アプリをスクリーンタイムで止めます。いつものアイコンを押すとブロック画面が出て、「minulo で開く」から DM に移れます。止めるのは1回2時間まで無料です。

使えるもの・使えないもの

DM とグループのやりとり（グループも Instagram の DM の一部です）、お知らせのタブは使えます。ストーリーズの投稿・音声メッセージ・通話は、Instagram のウェブ版に無いので使えません。必要なときは「休憩する」で、決めた分だけ公式アプリを開けます。

通知は公式の Instagram アプリから届きます。止めていなければいつもどおり届き、返信は minulo の中でできます。minulo が止めている間は届かず、minulo が代わりに通知を送ることもありません。

minulo の弱いところも書いておきます。公式アプリそのものは変えられないので、リールやショートが消えるのは minulo の中だけです。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は、各SNSのウェブ版に無いので使えません。使えるのは iPhone と Mac（ほかに Chrome と Safari の機能拡張）で、Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

インスタを DM だけで使える無料アプリはある？

あります。minulo の［DM以外のタブ］は無料です。リール・発見・ホームのフィード・おすすめ投稿が消え、DM とお知らせのタブが残ります。

ほかのアプリはなぜ DM だけの表示が有料なの？

この種類のアプリでは、リールを消すのは無料で、もっと絞った表示が有料になっていることが多いです。UNDOOMED（公式サイト）と Stillfeed は Pro、Reelmute は Premium で、Konvo は DM を使うこと自体に購読が要ります。

グループの DM も使える？

使えます。グループも Instagram の DM の一部なので、DM だけの表示でもそのまま読み書きできます。

通話やビデオ通話はできる？

minulo の中ではできません。Instagram のウェブ版に通話と音声メッセージが無いためです。「休憩する」を押すと、決めた分だけ公式アプリを開けます。

DM の通知は来る？

公式の Instagram アプリを止めていなければ来ます。通知は公式アプリから届くので、minulo が止めている間は届きません。
