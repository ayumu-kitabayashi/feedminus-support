推し活で X・インスタ・YouTube を推しの投稿だけにする方法（iPhone・2026年）

minulo で開けば、X は［おすすめ］が消えて［フォロー中］から、インスタはおすすめ投稿・リール・発見なしで、YouTube は登録チャンネルから開きます（消す機能は無料）。

推しの新しい投稿を見に来たのに、おすすめに流れて1時間たっている。各 SNS にも推しだけを追う機能はあります。X ではリストを作ってホームに固定でき、ライブやドラマのネタバレはミュートするキーワードで期間を決めて外せます。インスタは［お気に入り］に入れた人（50件まで）の投稿だけを新しい順に見られ、YouTube はホームの上の［登録チャンネル］に新しい動画が並びます。ただ、どれもおすすめのタブやリール、ショートはそのまま残ります。開くたびにそこを消しておきたいなら minulo を使います。

X：推しのリストを作ってホームに固定する

X のヘルプ（英語）によると、リストは人をグループごとにまとめて、そのリストのタイムラインを見る機能です。作るときに名前と説明を入れ、初期設定は公開で、スイッチで非公開にできます。固定したリストは、ホームの［おすすめ］［フォロー中］の右に並びます。ライブやドラマのネタバレを避けたいときは、［ミュートするキーワード］に言葉やハッシュタグを入れ、24時間・7日・30日・無期限から期間を選びます。ミュートした言葉も検索には出ます。

X のヘルプには［おすすめ］タブを消す設定は見当たりません。閉じたときに見ていたタブで次も開くので、［フォロー中］かリストのまま閉じます。くわしくは X のおすすめタブを消す方法へ。

インスタ：推しを［お気に入り］に入れる

フィードの左上の［Instagram］から［お気に入り］を選ぶと、お気に入りに入れた人の投稿だけが新しい順に出ます。入れられるのは50件までです。ただし変わるのはホームのフィードだけで、リールのタブと発見タブにはおすすめが出続けます。開き直すと、またおすすめの混ざったフィードに戻ります（親しい友達・お気に入りの投稿だけ見る方法）。

YouTube：登録チャンネルから見る

YouTube アプリはいつも［ホーム］で開き、［登録チャンネル］はホームの上のバーにあります。登録チャンネルから開く設定は、YouTube ヘルプでは見つかりませんでした（YouTube を登録チャンネルだけで見る方法）。

minulo で推し以外を消す

  1. App Store から minulo を入れ、その中で X・インスタ・YouTube を開いてログインします。minulo はパスワードを受け取りません。
  2. X の横の歯車で［フォロー中を先に開く］をオンにします。［おすすめ］タブが消え、［フォロー中］から開きます。最初からオンです。
  3. インスタの歯車で［リールと発見タブ］と［おすすめの投稿］をオンにします。DM とフォローしている人の投稿は残ります。
  4. YouTube の歯車で［ショートとおすすめを非表示］か［登録チャンネルだけにする］を選びます。消すのは無料です。

ひとつ気をつけたいのは、minulo でショートを消すと、ショートの棚とショートのタブが消えることです。推しのショートが次々に流れてくることはなくなり、ショートのリンクはふつうの再生画面で開きます。ショートのタブで続けて見たいときは公式アプリで見てください。

minulo の弱いところも書いておきます。リールやショートが消えるのは minulo の中だけで、公式アプリは変わりません。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は使えません。minulo は iPhone のアプリで、Safari と Chrome で使える Mac 版もあります。Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

X で推しの投稿だけ見るには？

X のリストに推しを入れ、そのリストをホームに固定します。リストは作るときに非公開にもできます。［フォロー中］のまま閉じれば、次も［フォロー中］から開きます。［おすすめ］タブ自体を消したいなら、minulo で X を開けば無料で消えます。

ライブのネタバレを X で見ないようにするには？

［ミュートするキーワード］に公演名やハッシュタグを入れ、ホームと通知のどちらか、または両方を選びます。期間は24時間・7日・30日・無期限から選べます。X のヘルプによると、ミュートした言葉も検索には出ます。

インスタで推しの投稿だけ見るには？

推しを［お気に入り］に入れ、フィードの左上の［Instagram］から［お気に入り］を選びます。50件まで入れられ、新しい順に出ます。リールのタブと発見タブは残るので、そこを消すなら minulo を使います。

minulo でショートを消すと推しのショートも消える？

minulo の中では、ショートの棚とショートのタブが消えます。ショートのリンクはふつうの再生画面で開くので、推しが共有したショートを1本ずつ見ることはできます。ショートのタブで続けて見たいときは公式の YouTube アプリを使います。

推しの DM やコメントは使える？

minulo の中のインスタと X で、DM やコメントは使えます。ストーリーズの投稿・音声メッセージ・通話は使えません。
