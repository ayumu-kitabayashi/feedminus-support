iPhone で YouTube のショートを無料で消して、ふつうの動画は見る方法（2026年）

YouTube にはショートをオフにするスイッチはありませんが、お金をかけずに消す方法はあります。YouTube アプリでショートのフィードの上限を0分にするのは無料ですが、大人のアカウントでは自分で閉じられます。ふつうの動画・検索・登録チャンネルは残してショートだけ消したいなら、ショートを隠すアプリで YouTube を開きます。minulo と Stillfeed はショートを消すのが無料、noShorts はアプリの中で使えて完全に無料、Nope は Safari の youtube.com で無料です。iPhone のスクリーンタイムも無料ですが、YouTube のアプリごと止まります。

ショートのフィードの上限を0分にする

YouTube アプリで［マイページ］→［設定］→［時間管理］→［ショート フィードの上限］を開き、0分にします。いちばん手軽な無料の方法ですが、止める機能ではなくお知らせです。大人のアカウントは上限の表示を閉じて見続けられます。YouTube のヘルプの手順はアプリのもので、youtube.com で効くかは書かれていません。ホームのショート動画のグリッドで、上のその他アイコンから［ショート動画の表示を減らす］を選ぶこともできます。

minulo でショートだけ消して、ふつうの動画は見る

  1. minulo を入れ、ホームの「サービスを追加」から YouTube を選びます。
  2. YouTube の横の歯車をタップし、［ショートの棚を非表示］・［下のショートタブを非表示］・［ショートを普通の再生画面で開く］をオンにします。登録チャンネルだけにしたいなら［ホームのおすすめ］もあります。
  3. 登録チャンネル・後で見る・検索は、minulo のホーム画面からすぐ開けます。
  4. 必要なら「ブロック」タブで、公式の YouTube アプリをスクリーンタイムで止めます。1回2時間まで無料で、ブロック画面の「minulo で開く」からショートの無い YouTube に移れます。

消す設定は、自分で変えるまでそのままです。minulo Pro では、曜日と時間帯の予定、長いブロック、ハードモード、複数のブロックリストが使えます。minulo に iPad 版はありません。

minulo の弱いところも書いておきます。公式アプリそのものは変えられないので、リールやショートが消えるのは minulo の中だけです。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は、各SNSのウェブ版に無いので使えません。使えるのは iPhone と Mac（ほかに Chrome と Safari の機能拡張）で、Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

iPhone で YouTube のショートを無料で消せるアプリは？

minulo・Stillfeed・Reelmute（日本の App Store では「リールとショートを非表示」）は、アプリの中でショートを消すのが無料で、お金がかかるのは追加の機能だけです。noShorts は完全に無料、Nope も完全に無料ですが Safari の youtube.com だけです。

ショートだけ消して、ふつうの動画は見られる？

YouTube のアプリ自体ではできません。minulo で YouTube を開き、ショートの棚とショートのタブを消せば、ふつうの動画・登録チャンネル・後で見る・検索はそのまま使えます。

ショートの上限を0分にすればショートは消える？

0分に達すると上限の画面が出ますが、大人のアカウントは閉じて見続けられます。YouTube のヘルプにあるのはアプリでの手順だけです。

公式の YouTube アプリからショートを消せるアプリはある？

ありません。iPhone では、ほかのアプリの表示を変えられないためです。minulo は公式の YouTube アプリをスクリーンタイムで止め、ショートの無い minulo の画面に案内できます。止めている間は YouTube の通知は届きません。

スクリーンタイムは無料の方法としてどう？

ほかの人にパスコードを決めてもらえば、無料の中ではいちばん破りにくい方法です。ただ YouTube のアプリごと止まるので、見たかった動画も見られなくなります。
