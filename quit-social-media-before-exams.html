テスト期間・受験前にインスタをやめる方法（グループDMは残す）

テスト前は、疲れた夜10時にいちばん戻しにくい方法を選ぶのがコツです。アプリを消しても1分で入れ直せますし、Safari なら instagram.com が開きます。利用解除（一時停止）はプロフィールを隠せますが、週1回しかできず、DM を見るためにログインした時点で解けます。クラスや部活の連絡がインスタにあるなら、リール・発見・おすすめ投稿だけ消して DM を残すほうが合っています。iPhone なら minulo で無料でできます。

方法何が起きるか戻しやすさグループDM
アプリを消すアカウント・投稿・DM は残る。ブラウザなら instagram.com が開く。App Store から1分ほどで入れ直せる。アプリでは見られない。見るならブラウザで。
ログアウトアプリは残り、開くとログインを求められる。パスワードを入れれば戻る。保存してあれば1タップ。ログアウト中は見られない。
利用解除（一時停止）ログインし直すまで写真・コメント・「いいね！」が非表示に。週1回まで。ログインすればその場で戻る。見るためにログインすると利用解除が終わる。
スクリーンタイム＋パスコード決めた時間はアプリが開かない。パスコードを知っていれば簡単。家族に設定してもらえば難しい。ほかと一緒に止まる。
フィードだけ消す（minulo）リール・発見・おすすめ投稿が消える。自分でオンに戻せる。Pro のハードモードなら数分かかる。そのまま使える。

テスト前の夜によくあること

夕食のあと、過去問を広げます。クラスのグループに通知が来て、読むためにインスタを開くと誰かがリールを送っていて、気づいたら1時間たってまだ大問2。意志が弱いわけではありません。必要な連絡と、いらないフィードが、同じアプリの1タップ先にあるだけです。

minulo の匿名の利用データでも、この時間帯ははっきり出ています。年齢を答えた韓国・日本の17歳以下の利用者（直近30日・80人）では、平日に SNS を開いた回数の64%が16時〜24時で、8時〜16時は19%でした。minulo の中で SNS を開いた時刻（現地時間）で数えています。学生にとって困るのは授業中より、放課後の自習室や家なのだと読めます。

テスト期間にインスタを利用解除（一時停止）する方法

Instagram ではアカウントを一時的に利用解除できます。ヘルプによると、ログインし直すまで写真・コメント・「いいね！」が非表示になり、プロフィールの利用解除は週1回しかできません。

  1. Instagram の「設定」から「アカウントセンター」を開きます。
  2. 自分のアカウントを選び、「利用解除または削除」に進みます。途中の画面の名前は、アカウントセンターの表示によって少し違います。
  3. 利用解除を選び、画面の案内に沿って進めます。

注意したいのは、DM を読むためにログインすると、その時点で利用解除が終わることです。LINE など別の連絡手段があって、インスタで連絡が来なくても困らない人に向いています。

アプリを消すか、ログアウトするか

アプリを消してもアカウントと DM は残り、いつでも入れ直せます。ホーム画面からアイコンがなくなるので、なんとなく開くことがなくなるのが効きます。ただし Safari の instagram.com は開けるので、そこも止めたいならスクリーンタイムの Web コンテンツの制限に入れます（手順はiPhone でインスタをブロックする方法）。

ログアウトは、パスワードを入れる手間が1つ増えるだけです。ログイン情報を保存しているなら、ほとんど効きません。

勉強の時間だけスクリーンタイムで止める

「アプリ使用時間の制限」で「制限終了時にブロック」を、または「休止時間」のスケジュールで「休止時間中にブロック」をオンにすると、決めた時間はインスタが開かなくなります。続くかどうかはパスコードしだいなので、親やきょうだいに設定してもらう人もいます。DM も一緒に止まり、Web も別に制限しないと開けます。手順はiPhone でインスタをブロックする方法にまとめています。

グループDMは残してフィードだけ消す

クラスや部活の連絡がインスタなら、minulo で残せます。minulo は、リール・発見・おすすめ投稿を消した状態でインスタを開ける iPhone アプリです。「DM以外のタブ」をオンにすると、DM と通知だけが残ります。消すのは無料です。公式アプリをスクリーンタイムで止めておけば、アイコンを押しても minulo に移るだけになります。公式アプリのロックは1回2時間まで無料で、終わったらすぐ次を始められます。曜日ごとの予定、2時間より長いブロック、ハードモードは Pro の機能です。

直近30日に minulo で始めたブロックの長さの平均は、17歳以下で74分、18〜24歳で82分でした。自習1コマくらいの長さです。

できないこともあります。公式の Instagram アプリの中身は変えられません。minulo が公式アプリを止めている間は、公式アプリの通知は届かないので、グループの連絡は自分で決めた時間に minulo で見てください。iPhone だけ（Safari と Chrome で使える Mac 版もあります）で、Android 版はまだありません。

テスト2週間前からの進め方

  1. 本当に必要な連絡を決めます。友だちには「夜9時にまとめて返す」と言っておきます。
  2. 連絡に使わない SNS（TikTok・YouTube など）は、ホーム画面から外すかアプリを消します。
  3. インスタは、連絡が来るならリールと発見を消します。来ないなら利用解除します。
  4. 勉強する1〜2時間は、公式アプリをブロックしておきます。
  5. テストが終わる日をカレンダーに入れて、その日に元に戻します。終わりが決まっていると始めやすくなります。

テスト前にインスタを利用解除したほうがいいですか？

連絡にインスタを使わないなら、利用解除は手堅い方法です。ログインし直すまでプロフィールが隠れ、利用解除は週1回までです。クラスの連絡がインスタにあるなら、読むためにログインした時点で解けてしまうので、DM を残してフィードだけ消すほうが続きます。

利用解除中もインスタのDMは使えますか？

使えません。DM を見るにはログインが必要で、ログインし直すと利用解除が終わります。DM が必要なら、アカウントは残してフィードを消す方法（minulo の無料の「DM以外のタブ」など）が合っています。

インスタの利用解除は何回できますか？

Instagram のヘルプには、プロフィールの利用解除は週1回しかできないと書かれています。ログインすればその場で元に戻ります。

テスト期間はインスタを消すのとログアウトはどちらがいいですか？

ログイン情報を保存しているなら、アイコンが消えるぶん、アプリを消すほうが効きます。どちらも Safari の instagram.com は止まらず、アプリの DM も見られなくなります。家族にパスコードを設定してもらったスクリーンタイムの制限のほうが戻しにくいです。

受験前にSNSをやめたいけどグループの連絡は残したいときは？

連絡は残して、終わりのないフィードだけをなくします。iPhone の minulo なら「DM以外のタブ」でインスタを DM と通知だけにでき、YouTube のショートや TikTok のおすすめも消せます。勉強の時間だけ公式アプリを止めることもできます。消すのは無料です。
