アプリ内ブラウザのアプリを比べる

  • minulo：10の SNS（インスタ・YouTube・TikTok・X・Threads・Facebook・Pinterest・Reddit・LinkedIn・Snapchat）。インスタと TikTok を DM だけにするのは無料（「DM以外のタブ」）。スクリーンタイムで公式アプリを止められ、ブロック画面に「minulo で開く」ボタンが出る。iPhone だけで、Android 版はない。2026年9月公開、日本の評価は2件（平均3.0）。日本の開発者1人が作っています。
  • UNDOOMED：7つの SNS（インスタ・Threads・Reddit・Facebook・X・YouTube・LinkedIn）。TikTok と Snapchat は使えないと書かれている。インスタと LinkedIn をメッセージだけにする Messages Only は Pro（同社のサイトより）。iPhone と Android。日本の評価は7件（平均5.0）、2025年10月から App Store にある。
  • Stillfeed：インスタと YouTube。リール・発見・ショートを隠すのは無料、DMs Only は Pro（米国では月4.99ドル・年39.99ドル）。公式アプリを開く前に確認が出る。日本の評価は1件（平均5.0）、2026年7月から App Store にある。
  • Scroll Less：YouTube・インスタなど（対応する SNS の一覧はない）を専用のシンプルなブラウザで開き、おすすめのフィードを消す。App Store のページに DM のことは書かれていない。英語のみ。日本の評価は0件、2025年3月から App Store にある。

どれが合うか

  • グループDMだけ使えればいい。メッセージだけの表示を使います。minulo の「DM以外のタブ」（無料）、UNDOOMED の Messages Only（Pro）、Stillfeed の DMs Only（Pro）。
  • 友だちの投稿は見たい。リールだけいらない。minulo・UNDOOMED・Stillfeed のどれでも無料でできます。
  • Android を使っている。iPhone と Android を行き来する。この中で Android 版があるのは UNDOOMED です。
  • 公式アプリを無意識に開いてしまう。スクリーンタイムで止めます。minulo ではブロック画面の「minulo で開く」から、リールのないインスタにそのまま移れます。グループDMはワンタップで開けます。
  • ボイスメッセージ・通話・ストーリーズの投稿が必要。公式アプリが要ります。画面の配信のアプリなら公式アプリのまま使えますが、リールが出るとアプリごと止まります。
  • アプリを増やしたくない。Safari の instagram.com を Nope（無料）か ScrollGuard で使います。またはスクリーンタイムだけにして、グループDMも止まるのを受け入れます。

グループDMの通知

minulo を使っても、通知は公式のインスタのアプリから届きます。公式アプリを止めていなければ、通知はいつもどおり届き、返信は minulo でできます。スクリーンタイムで公式アプリを止めている間は、通知も届きません。止めるのは勉強中など、通知がなくても困らない時間だけにしてください。

インスタをグループDMのために残して、リールだけ消すいちばんいい方法は？

リールを隠して DM は使えるアプリ（minulo・UNDOOMED・Stillfeed）の中でインスタを開きます。メッセージだけでいいなら、minulo の「DM以外のタブ」は無料です。UNDOOMED と Stillfeed のメッセージだけの表示は Pro です。公式アプリに戻ってしまうなら、スクリーンタイムで止めます。

公式のインスタのアプリからリールを消せる？

iPhone では、ほかのアプリの表示を別のアプリが変えることはできません。できるのは、自分のブラウザや Safari でインスタを表示するか、画面を見ていてリールが出たらアプリごと止めるかです。minulo は公式アプリをスクリーンタイムで止めて、リールのないインスタへ案内できます。

スクリーンタイムだけではだめ？

スクリーンタイムはインスタのアプリごと止めるので、リールと一緒にグループDMも止まります。リールだけを止める設定もありません。グループDMを別の場所で開けるアプリと組み合わせると役に立ちます。

無料でできる？

できます。DM を残してリールを隠すのは minulo・UNDOOMED・Stillfeed で無料です。minulo のメッセージだけの設定も無料です。instagram.com と youtube.com 用の Safari 拡張 Nope は、すべて無料としています。

YouTube のショートや TikTok にも使える？

minulo は YouTube のショートと TikTok のおすすめを消し、YouTube の検索・登録チャンネルと TikTok のメッセージは残します。UNDOOMED と Stillfeed は YouTube に対応しています。UNDOOMED は TikTok を使えないとしていて、Stillfeed の App Store のページには TikTok のことは書かれていません。
