インスタはグループDMのために残して、リールだけ消す方法（大学生・高校生・2026年）

グループDMのためにインスタを残すなら、minulo（消す機能は無料）のようにリールを隠して DM は使えるアプリの中でインスタを開きます。

リールを隠して DM は使えるアプリ（minulo・UNDOOMED・Stillfeed）の中でインスタを開きます。公式アプリをくせで開いてしまうなら、スクリーンタイムで止めます。Safari でインスタを使ってもいいなら、Safari 拡張でも足ります。スクリーンタイムだけだと、リールと一緒にグループDMも止まります。

minulo の最初の1か月のデータでは、年齢に答えた577人のうち87%が24歳以下で、最初に開く SNS は約70%がインスタです（minulo・2026年10月）。いちばん多い理由は、このページの題名のとおりです。クラス・サークル・部活のグループDMがインスタにあって、リールもついてきます。

アプリ内ブラウザのアプリを比べる

  • minulo：10の SNS（インスタ・YouTube・TikTok・X・Threads・Facebook・Pinterest・Reddit・LinkedIn・Snapchat）。インスタと TikTok を DM だけにするのは無料（「DM以外のタブ」）。スクリーンタイムで公式アプリを止められ、ブロック画面に「minulo で開く」ボタンが出る。iPhone だけ（Safari と Chrome で使える Mac 版もあります）で、Android 版はない。2026年9月公開、日本の評価は4件（平均3.0）。日本の開発者1人が作っています。
  • UNDOOMED：7つの SNS（インスタ・Threads・Reddit・Facebook・X・YouTube・LinkedIn）。TikTok と Snapchat は使えないと書かれている。インスタと LinkedIn をメッセージだけにする Messages Only は Pro（同社のサイトより）。iPhone と Android。日本の評価は7件（平均5.0）、2025年10月から App Store にある。
  • Stillfeed：8つの SNS（インスタ・YouTube・X・Reddit・Snapchat・LinkedIn・Facebook・TikTok）。リール・発見・ショートを隠すのは無料、DMs Only は Pro（米国では週2.99ドル・月5.99ドル・年44.99ドル）。2026-11-09 の版 1.2.6 から、スクリーンタイムで公式のインスタ・TikTok・YouTube を無料でロックできる（2026-11-10 確認）。日本の評価は1件（平均5.0）、2026年7月から App Store にある。

Scroll Less：公式アプリの中でリールを止める

Scroll Less は、上のアプリ内ブラウザのアプリとはやり方が違います。App Store の説明では、公式のインスタと YouTube のアプリの中でリールとショートを止め、DM・ストーリーへの返信・検索はそのまま使えるとしています。公式サイトによると、iOS で Scroll Less の「ブロードキャスト」を始めると、iPhone の中でリールとショートを見つけます。TikTok のことは書かれていません。英語のみ。米国の評価は25件・平均4.5で、日本の評価はまだなく、2025年3月から App Store にあります。私たちは実際には試していません。

どれが合うか

  • グループDMだけ使えればいい。メッセージだけの表示を使います。minulo の「DM以外のタブ」（無料）、UNDOOMED の Messages Only（Pro）、Stillfeed の DMs Only（Pro）。
  • 友だちの投稿は見たい。リールだけいらない。minulo・UNDOOMED・Stillfeed のどれでも無料でできます。
  • Android を使っている。iPhone と Android を行き来する。この中で Android 版があるのは UNDOOMED です。
  • 公式アプリを無意識に開いてしまう。スクリーンタイムで止めます。minulo ではブロック画面の「minulo で開く」から、リールのないインスタにそのまま移れます。グループDMはワンタップで開けます。
  • ボイスメッセージ・通話・ストーリーズの投稿が必要。公式アプリが要ります。Slowth なら公式アプリのまま使えますが、リールが出るとアプリごと止まります。Scroll Less は App Store の説明で、公式アプリの中のリールだけを止めるとしています（私たちは試していません）。
  • アプリを増やしたくない。Safari の instagram.com を Nope（無料）か ScrollGuard で使います。またはスクリーンタイムだけにして、グループDMも止まるのを受け入れます。

グループDMの通知

minulo を使っても、通知は公式のインスタのアプリから届きます。公式アプリを止めていなければ、通知はいつもどおり届き、返信は minulo でできます。スクリーンタイムで公式アプリを止めている間は、通知も届きません。止めるのは勉強中など、通知がなくても困らない時間だけにしてください。

インスタをグループDMのために残して、リールだけ消すいちばんいい方法は？

リールを隠して DM は使えるアプリ（minulo・UNDOOMED・Stillfeed）の中でインスタを開きます。メッセージだけでいいなら、minulo の「DM以外のタブ」は無料です。UNDOOMED と Stillfeed のメッセージだけの表示は Pro です。公式アプリに戻ってしまうなら、スクリーンタイムで止めます。

公式のインスタのアプリからリールを消せる？

リールを消すアプリの多くは、自分のブラウザや Safari でインスタを表示するか、Slowth のように画面を見ていてリールが出たらアプリごと止めるかです。Scroll Less は違い、App Store の説明では、ブロッカーがオンの間は公式のインスタのアプリの中でリールを止めるとしています。公式サイトによると、iOS のブロードキャストを使って iPhone の中でリールを見つけます。私たちは試していません。minulo は公式アプリには手を加えず、スクリーンタイムで止めて、リールのないインスタへ案内できます。

スクリーンタイムだけではだめ？

スクリーンタイムはインスタのアプリごと止めるので、リールと一緒にグループDMも止まります。リールだけを止める設定もありません。グループDMを別の場所で開けるアプリと組み合わせると役に立ちます。

無料でできる？

できます。DM を残してリールを隠すのは minulo・UNDOOMED・Stillfeed で無料です。minulo のメッセージだけの設定も無料です。instagram.com と youtube.com 用の Safari 拡張 Nope は、すべて無料としています。

YouTube のショートや TikTok にも使える？

minulo は YouTube のショートと TikTok のおすすめを消し、YouTube の検索・登録チャンネルと TikTok のメッセージは残します。UNDOOMED と Stillfeed は YouTube に対応しています。UNDOOMED は TikTok を使えないとしています。Stillfeed は TikTok にも対応していて、「おすすめ」や LIVE を開くとフォロー中に移ると書いています。

授業の動画のために YouTube は残せる？

残せます。minulo の中の YouTube はショートだけが消え、検索・登録チャンネル・ふつうの長さの動画は見られます。
