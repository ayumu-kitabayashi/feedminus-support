Studyplus の集中モードを使っても、休憩中にリールを見てしまうとき（iPhone・2026年）

minulo なら、Studyplus で計っていない休憩中や勉強のあとも、インスタのリールや YouTube のショートを消したまま SNS を使えます（消す機能は無料）。

App Store の Studyplus の説明によると、集中モードは勉強を始めると、前もって選んだアプリを一時的に使えないようにする機能です。タイマーと連動させれば計り始めたときに制限がかかり、解除したいときは自分で切り替えられます。止まるのは計っている間なので、休憩に入ってインスタを開けば、リールはいつもどおり出てきます。5分のつもりの休憩が30分になるのはこのときです。記録は Studyplus のまま続け、休憩と夜の SNS からリールとショートを消す、という分け方ができます。

Studyplus の集中モードで止まるもの・止まらないもの

App Store の説明では、集中モードは「勉強を始めると、あらかじめ選んでおいたアプリを一時的に使えないように制限します」とあります。使うには、端末の設定で権限を許可します。タイマーと連動させると、計り始めたと同時に制限がかかります。

止まらないのは、計っていない時間です。休憩でストップウォッチを止めたとき、その日の勉強を終えたとき、夜に布団に入ったとき。このときインスタを開けば、リールのタブも発見もおすすめ投稿もそのまま出ます。クラスの連絡を見るつもりで開いて、そのままリールに流れるのはよくある話です。

休憩中のリールを minulo で消す

  1. App Store から minulo を入れます。
  2. minulo の中でインスタや YouTube を開き、それぞれのログイン画面でログインします。minulo はパスワードを受け取りません。
  3. インスタの横の歯車で［リールタブ］・［発見タブ］や［おすすめの投稿］を、YouTube の歯車で［ショートとおすすめを非表示］を選びます。消すのは無料です。
  4. 「ブロック」タブで公式のインスタや YouTube を選んでブロックを始めます。アイコンを押すと「ブロック中です」の画面が出て、「minulo で開く」から移れます。無料では1回2時間までです。

これで、休憩中にインスタを開いても DM とフォローしている人の投稿だけが見え、YouTube は普通の動画と検索が残ります。勉強中のアプリの制限は Studyplus の集中モードに任せ、それ以外の時間の SNS は minulo の中で開く、という使い方です。

minulo の弱いところも書いておきます。リールやショートが消えるのは minulo の中だけで、公式アプリは変わりません。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ただし 1.0.19 からは、Pro の方はベータ機能の DM の通知をオンにすると、Instagram を止めている間も Instagram の DM の通知だけは届きます（スリープモード・ワークモードの間と、1日の上限に達した後は届きません）。ストーリーズの投稿・音声メッセージ・通話は使えません。minulo は iPhone のアプリで、Safari と Chrome で使える Mac 版もあります。Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

勉強の1日の流れ

  1. 机に向かったら、Studyplus でストップウォッチかタイマーを始めます。集中モードで SNS が止まります。
  2. 休憩では、インスタや YouTube を minulo の中で開きます。リールとショートは出ません。
  3. 勉強を終えたら Studyplus に記録します。そのあと SNS を開くときも minulo から開きます。
  4. 夜も公式アプリを開かないようにしたいなら、minulo の「ブロック」で止めておきます（1回2時間まで無料。毎晩のスリープモードは minulo Pro）。

Studyplus の集中モードは休憩中も SNS を止める？

App Store の説明では、集中モードは勉強を始めたときに選んだアプリを制限する機能で、タイマーと連動させると計り始めたときに制限がかかります。休憩中や勉強のあとまで止めるとは書かれていません。休憩中のリールが困るなら、minulo でリールとショートを消しておけます（無料）。

Studyplus の集中モードは自分で解除できる？

できます。App Store の説明に、制限を解除したいときはいつでも自分で切り替えられると書かれています。

Studyplus の集中モードは無料？

App Store の説明では、記録・教材ごとの管理・グラフ・勉強仲間とのつながりなどの基本機能は無料とされています。集中モードが無料かどうかは説明に書かれていないので、アプリの中で確かめてください。

Studyplus と minulo は一緒に使える？

別のアプリなので、両方入れて使えます。勉強の記録と計っている間の制限は Studyplus、休憩や夜にインスタや YouTube を開くときは minulo、という分け方です。私たちは2つを同時に動かした検証はしていません。

休憩中もインスタの DM は返したい

minulo の中でインスタを開けば、リールと発見を消したまま DM を使えます。minulo が公式アプリを止めている間は、公式アプリの通知は届きません。ただし 1.0.19 からは、Pro の方はベータ機能の DM の通知をオンにすると、Instagram を止めている間も Instagram の DM の通知だけは届きます（スリープモード・ワークモードの間と、1日の上限に達した後は届きません）。
