SNS を見る時間を減らす方法：まず時間を測り、リールとショートだけ消す（iPhone・2026年）

minulo なら、SNS の連絡は残したまま、リール・ショート・おすすめの投稿を消せます（消す機能は無料）。

SNS を見る時間を減らしたいと思っても、LINE やインスタの DM、部活やサークルの連絡まで止めるわけにはいきません。時間が延びるのは、たいていリールやショートを見ているときです。iPhone の設定で今の時間を確かめ、SNS 全体に上限や時間帯を決め、長くなる部分だけを消す、という順に書きます。

2026-11-02

このページは minulo の開発者、北林 歩が書いています。比べている方法のひとつが自分のアプリなので、その点は割り引いて読んでください。iPhone の設定は、Apple の iPhone ユーザガイド（iOS 27 と iOS 26）を 2026-11-02 に確かめました。iOS のバージョンで画面の名前が違います。

1. 今の SNS の時間を見る

  1. 設定アプリで［スクリーンタイム］を押し、まだなら［スクリーンタイムを管理］→［“アプリとウェブサイトのアクティビティ”をオンにする］を押します（iOS 27）。
  2. ［1日の平均］を押し、［週］か［日］を選びます。
  3. 下にスクロールすると、iPhone を持ち上げた回数や通知の数も見られます。

Apple のガイドでは、スクリーンタイムをオンにすると週間レポートが届き、使った時間やよく使ったアプリが分かります。見方は週間レポートの見方にまとめています。

2. SNS にまとめて上限を決める

iOS 27 では［スクリーンタイム］→［許容時間］で、「ソーシャルメディア」などのカテゴリごとに1日に使える時間を決めます。［カテゴリを管理］からカテゴリを押すと、そのカテゴリの1日の平均時間と、中のアプリごとの時間も見られます。iOS 26 では［アプリ使用時間の制限］→［制限を追加］でカテゴリかアプリを選びます。iOS 26 のガイドによると、制限は初期設定では、制限に達しても無視できます。

3. 時間帯で止める

iOS 27 では［スクリーンタイムのスケジュール］で［スケジュール］をオンにし、平日と週末、夜などの時間枠を作れます。LINE や家族の連絡先は［常に許可］に入れておけば、スケジュールや許容時間に関係なく使えます。iOS 26 では「休止時間」という名前です。

4. 長くなる部分だけ消す

スクリーンタイムはアプリ全体を止めるので、インスタを止めると DM も止まります。時間を食うのがリールやショートなら、そこだけ消して SNS は使い続ける方法があります。

  1. App Store から minulo を入れます。
  2. minulo の中でインスタや YouTube、TikTok を開き、それぞれのログイン画面でログインします。minulo はパスワードを受け取りません。
  3. インスタの横の歯車で［リールと発見タブ］や［おすすめの投稿］を、YouTube の歯車で［ショートとおすすめを非表示］を、TikTok の歯車で［おすすめ］を選びます。消すのは無料です。
  4. 「ブロック」タブで公式のインスタや YouTube、TikTok を選んでブロックを始めます。アイコンを押すと「ブロック中です」の画面が出て、「minulo で開く」から移れます。無料では1回2時間までです。

minulo の弱いところも書いておきます。リールやショートが消えるのは minulo の中だけで、公式アプリは変わりません。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ストーリーズの投稿・音声メッセージ・通話は使えません。minulo は iPhone のアプリで、Safari と Chrome で使える Mac 版もあります。Android 版はまだありません。公開されたばかりで、評価もまだ少ないです。くわしくは minulo にできないことへ。

SNS を何時間見ているかはどこで分かる？

設定アプリの［スクリーンタイム］で［1日の平均］を押すと、週ごと・日ごとの使った時間とよく使ったアプリが見られます（iOS 27）。

LINE も SNS の上限に入ってしまう？

どのアプリがどのカテゴリに入っているかは、iOS 27 なら［許容時間］の［カテゴリを管理］でカテゴリを押すと確かめられます。LINE を止めたくないなら［常に許可］に入れておけます。

SNS は1日何時間までにすればいい？

このページでは目安を決めていません。まず今の時間を見て、減らしたい時間帯やアプリから決めるのが続けやすい方法です。

DM は返したいけど SNS の時間は減らしたい

minulo の中で SNS を開けば、リール・ショート・おすすめの投稿を消したまま DM は使えます（消すのは無料）。公式アプリは minulo のブロックで止めておけます。

スクリーンタイムの上限を無視してしまう

iOS 26 のガイドでは、制限は初期設定で無視できます。外しにくくする方法は「スクリーンタイムを自分用に使う」と「制限を無視を消す方法」のページにまとめています。
