新年の目標「スマホ時間を減らす」を SNS をやめずに守る方法（2027年）

SNS をやめずに「スマホの時間を減らす」という新年の目標を守るなら、アプリをまるごと消すより、リールとショートだけを消して、DM や友だちの投稿はそのまま使うのが続けやすいやり方です。そのうえで1週ごとに1つずつ足します。2週目は夜に公式アプリをスクリーンタイムでロックし、3週目は1日の上限を決め、4週目に1か月を振り返ります。

「SNS をやめる」という目標は、アプリをまるごと消そうとします。でも夜の時間を持っていくのは、たいていもっと狭い場所です。リールのタブ、ショートのフィード、TikTok のおすすめ。この計画は、2027年の1月にそこだけを消して、クラスのグループ DM、友だちからのメッセージ、フォローしている人の投稿は残します。

  1. 1週目：リールとショートを消す。DM はそのまま使います。
  2. 2週目：夜は公式の Instagram と YouTube をスクリーンタイムでロックする。
  3. 3週目：1日の上限を決める。
  4. 4週目：スクリーンタイムの数字を見返して、効いたものを残す。

SNS をやめる目標が続かない理由

完全にやめると、まだ必要なものまで手放すことになります。クラスや部活の連絡、友だちとの約束が Instagram の DM に来るなら、結局アプリを入れ直し、フィードも一緒に戻ってきます。アプリを消しても、Safari で開けば1タップです。

もう1つは、つまずく瞬間です。リールを見ようと思って Instagram を開くことはあまりありません。メッセージに返事をしようと開いたら、もうリールが流れている。「スマホを減らす」という目標は、その瞬間にどうするかを決めていないので、結局いつもの癖が勝ちます。

私が作っているアプリの利用データも同じ方向を示しています。2026年10月1〜14日に初めてそのアプリを開いた378人のうち、初日にアプリの中で SNS を10回以上開いた人は73%が別の日にもまた開いていて、0回の人は10%でした。残ったのは、いちばん多くブロックした人ではなく、終わりのないフィードなしで SNS を使い続けた人です。また、アプリの中で SNS を開く時間は20時から1時の間がいちばん多くなっています（データの多くは日本の時刻です）。計画が試されるのは夜です。（利用データ、2026年10月）

2027年1月の4週間の計画

1週目：リールとショートを消す。YouTube はショート フィードの上限を 0 にし、Instagram はフォロー中のフィードに切り替えます（下の表を参照）。リールのタブまで消したいなら、アプリを使う方法もあります（最後の節）。この週はほかに何も変えません。フィードのない SNS に慣れるのが目的です。

2週目：夜は公式アプリをロックする。iPhone の設定 › スクリーンタイム › 休止時間で寝る時間を決め、「休止時間中にブロック」をオンにします（iOS 27 ではスクリーンタイムのスケジュール）。アプリごと止まるので、その時間は DM も使えません。

3週目：1日の上限を決める。iPhone の設定 › スクリーンタイム › App使用時間の制限で公式アプリに上限をかけられます。アプリ全体が対象で、スクリーンタイムのパスコードを設定していないと1タップで無視できます。Instagram の［1日の上限］は、お知らせが出るだけです。

4週目：振り返る。設定 › スクリーンタイムを開き、この週と1月の最初の週を比べます。効いたものは残します。まだ夜がつらいなら夜のロックを続け、学校や仕事が終わった直後がつらいなら、その時間にブロックを始めます。

iPhone・YouTube・Instagram に最初からある方法

方法できること気をつけること
ショート フィードの上限を 0 に（YouTube）YouTube アプリの［マイページ］→［設定］→［時間管理］→［ショート フィードの上限］。上限に達するとショートのフィードが止まる大人のアカウントは無視して見続けられる。報道では、登録チャンネルや送られてきたリンクのショートは残る
フォロー中のフィード（Instagram）フィードの左上の［Instagram］を押して［フォロー中］を選ぶと、フォローしている人の投稿だけが新しい順に並び、おすすめ投稿は出ないリールのタブと発見は残る。次に開いたら、また選び直す

YouTube しか使わないなら、ショート フィードの上限は最初の一歩になります。困っているのがインスタのリールなら、フォロー中のフィードはその場では効きますが、次に開くとまたいつものフィードです。休止時間はいちばん強い標準の機能で、メッセージまで止まるのもこれです。

DM は残してリールとショートだけ消したいとき

このページを書いた私は minulo の開発者なので、ここは自分のアプリの話です。minulo を使うと、上の4週間はこうなります。消す機能は無料で、サブスクも minulo のアカウント登録もいりません。

1週目：minulo を入れて、ホーム画面から Instagram と YouTube を追加します。Instagram の横の歯車からリールのタブと発見を消し、YouTube も同じようにショートを消します。ここまで全部無料です。メッセージに返事をするときや、ふつうの動画を見るときは minulo で開きます。

2週目：minulo の［ブロック］タブで公式の Instagram と YouTube を選び、布団に入るときにブロックを始めます。仕組みは iPhone のスクリーンタイムです。無料のブロックは1回2時間までで、終わったらすぐ次を始められます。癖で Instagram のアイコンを押すとブロック画面が出て、そこから minulo で開けるので、リールなしで返事はできます。毎晩自動でロックしたいなら、minulo Pro のスリープモードが寝る時間から起きる時間まで止めます。Pro は使わなくてもよい有料の機能です。

3週目：minulo Pro の［1日の上限］なら、SNS を使える時間を1日ごとに決められます（朝5時を過ぎるとまた開けます）。

4週目：minulo でも、アプリを開かずに済んだ回数と、SNS ごとの使用時間を無料で見られます。そのあとで、Pro がそもそも必要かを決めます。無料の消す機能だけで足りる人もいます。

できないこともあります。minulo は公式アプリを変えられないので、リールとショートが消えるのは minulo の中だけです。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ただし 1.0.19 からは、Pro の方はベータ機能の DM の通知をオンにすると、Instagram を止めている間も Instagram の DM の通知だけは届きます（スリープモード・ワークモードの間と、1日の上限に達した後は届きません）。夜も DM の通知がほしいなら、公式アプリはロックしないでください。ストーリーズの投稿・音声メッセージ・通話は、Instagram のウェブ版に無いので使えません。無料のブロックは1回2時間までで、自分で始めます。minulo が使えるのは iPhone と Mac で、Android 版はありません。公開されたばかりで、評価もまだ少ないです。それに、決めるのはアプリではなく自分です。自分で決めたスクリーンタイムのパスコードは、自分で外せてしまいます。くわしくは minulo にできないこと へ。

スマホ時間を減らす目標のために、インスタを消さないとだめ？

消さなくて大丈夫です。減らしたいのはフィードで、メッセージではありません。リールと発見を消した状態で Instagram を開けば、DM もグループも、フォローしている人の投稿もそのまま使えます。

minulo は無料？

リール・ショート・おすすめ投稿を消すのは無料で、サブスクもアカウント登録もいりません。minulo Pro は使わなくてもよい有料の機能で、スリープモード、ワークモード、ハードモード、1日の上限、2時間より長いブロックが加わります。

DM は届く？

はい。リールを消したアプリの中でも、DM もグループもそのまま使えます。ただし公式アプリをロックしている間はその通知が届かないので、DM の通知がほしいなら公式アプリはロックしないでください。

1週目でくじけたら？

目標ではなく、やり方を変えます。つい公式アプリを開いてしまうなら、スクリーンタイムでロックします。
