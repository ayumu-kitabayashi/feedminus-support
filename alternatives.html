Instagram の設定でリールを非表示にできる？

大人のアカウントでは、2026年10月の時点で Instagram の公式のヘルプにその設定は見当たりません。DM は使いながらリールだけを非表示にするなら、minulo（消す機能は無料）のようなアプリで Instagram を開きます。フォロー中のフィードにすると、フィードのおすすめ投稿は出なくなりますが、リールのタブは残ります。iPhone のスクリーンタイムは Instagram のアプリごと止めるので、DM も使えなくなります。

アプリ内ブラウザ型と Safari 拡張型はどう違う？

アプリ内ブラウザ型（minulo・SocialLite・UNDOOMED・Awhile・Dull・Stillfeed・noShorts など）は、アプリの中で Instagram などのウェブ版を開き、リールや発見タブを表示しないようにします。Safari を開かずアプリとして使え、複数のSNSをまとめて扱えるものが多い一方、画面はウェブ版なので公式アプリとは見た目や機能が少し違います。Safari 拡張型（Nope・ScrollGuard・SocialFocus・Slowth・tubetidy など）は、Safari で開いたサイトにだけ効きます。Nope のように完全に無料のものや、tubetidy のように買い切りのものもありますが、公式アプリを開けばリールはそのまま出ます。どちらの型でも、公式アプリをつい開くのを止めるにはスクリーンタイムを使います。minulo・SocialLite・noShorts・snowscroll は、公式アプリを止めて自分の画面へ案内する仕組みをアプリの中に持っています。

結局どれがいちばんいい？

何を重視するかで変わります。評価の数が圧倒的に多く、通知も届くのは SocialLite（米国で16,883件、2026-11-04 確認）。Instagram しか使わないなら Awhile がシンプルで、Nope は Safari で完全に無料です。TikTok やスナップチャットも含めて10のSNSをまとめて扱えるのは minulo で、リールやショートを非表示にするのは無料です。

インスタのリールだけ非表示にして、DMを使えるアプリはどれ？

minulo・SocialLite・UNDOOMED・Awhile・LoomWeb・Nope・Dull・Stillfeed・リールとショートを非表示 は、どれもリールを隠したまま DM は使えると説明しています。Awhile は Instagram だけ、Nope は Instagram と YouTube、UNDOOMED・LoomWeb・Dull・Stillfeed・リールとショートを非表示・minulo は複数のSNSに対応しています。minulo は TikTok と Snapchat を含む10のSNSに対応しています。

YouTubeのショートを非表示にするアプリは？

YouTube のショートにも対応しているのは、minulo・SocialLite・UNDOOMED・Nope・Stillfeed・Dull・noShorts・TheSNSisMine・リールとショートを非表示などです。YouTube だけでよく、Safari で見るなら tubetidy（買い切り500円）もあります。YouTube アプリの設定でショートのフィードの上限を 0 分にする方法もありますが、大人のアカウントでは上限の表示を閉じて見続けられます。

公式のInstagramアプリの中でリールを非表示にできるアプリはある？

公式アプリの中のリールだけを消せるアプリはありません。アプリの使用中にリールやショートを止めると説明しているのは WallHabit と Slowth です。Slowth は、画面の収録でリールやショートを見つけるとアプリを止めると説明しています。WallHabit の仕組みは説明に書かれていません。ほかのアプリは、公式アプリを変えるのではなく、自前のブラウザか Safari で Instagram を表示します。minulo は、公式の Instagram アプリをスクリーンタイムで止め、開こうとするとリールが消えた minulo へ案内できます。

完全に無料で使えるのはどれ？

Nope は、サブスクもアプリ内課金もない完全無料だと説明しており、Safari で Instagram と YouTube に使えます。アプリの中で使えるものでは、2026年10月に出た noShorts も、サブスクもアプリ内課金もないと説明しています。minulo は、10のSNSでリール・ショート・おすすめ投稿を非表示にする機能が無料で、有料なのはスリープモード・ハードモード・1日の上限・2時間を超えるブロックだけです。

SocialLiteの代わりになるアプリは？

評価の数は SocialLite が群を抜いて多く、米国で16,883件です。ほかに DM を残してショート動画を消すアプリなら、対応SNSがいちばん多いのは minulo（10）で、UNDOOMED と Stillfeed が7つです。minulo は TikTok・Threads・Pinterest・LinkedIn にも対応し、Safari と Chrome で使える Mac 版もありますが、新しいアプリなので米国の評価はまだ1件です。

minuloでログインしても安全？

ログインは、minulo の中で開いた各SNSの公式ページで行います。minulo は ID もパスワードも受け取らず、保存もしません。minulo 自体のアカウントもありません。使われ方の記録は匿名で、個人と結びつきません。

Android や iPad でも使える？

minulo は iPhone 専用で、Android 版と iPad 版はありません。パソコンでは Mac アプリを使えます（Chrome で使うときは Mac アプリから拡張機能を足します）。

ブロックしている間、公式アプリの通知は来る？

来ません。スクリーンタイムで公式アプリを止めている間は、そのアプリのプッシュ通知も届かないので、メッセージは minulo の中で確かめることになります。SocialLite は Instagram と Snapchat の通知を出せるので、通知を逃したくない人には向いています。
