リールとショートを消して、DMは残せるアプリの比較（2026年）

Instagram のリールや YouTube のショートを消しつつ、DM は使える iPhone アプリはいくつかあります。仕組みの多くは、アプリの中のブラウザで開くもの（SocialLite・UNDOOMED・Awhile・LoomWeb・minulo）か、Safari の拡張機能（ScrollGuard・Nope）です。SocialLite と minulo は、公式アプリをスクリーンタイムで止めて、リールの消えた画面へ案内することもできます。

インスタのリールだけ消して、DMを使えるアプリはどれ？

SocialLite・UNDOOMED・Awhile・LoomWeb・Nope・minulo は、どれもリールを隠したまま DM は使えると説明しています。Awhile は Instagram だけ、Nope は Instagram と YouTube、UNDOOMED・LoomWeb・minulo は複数のSNSに対応しています。minulo は TikTok と Snapchat を含む10のSNSに対応しています。

公式のInstagramアプリの中でリールを消せるアプリはある？

アプリの一部（リールやショート）を止められると説明しているのは WallHabit だけで、その仕組みは説明に書かれていません。ほかのアプリは、公式アプリを変えるのではなく、自前のブラウザか Safari で Instagram を表示します。minulo は別のやり方で、公式の Instagram アプリをスクリーンタイムで止め、開こうとするとリールが消えた minulo へ案内できます。

完全に無料で使えるのはどれ？

Nope は、サブスクもアプリ内課金もない完全無料だと説明しており、Safari で Instagram と YouTube に使えます。minulo は、10のSNSでリール・ショート・おすすめ投稿を消す機能が無料で、有料なのは予定・ロックモード・複数のリストだけです。

SocialLiteの代わりになるアプリは？

評価の数は SocialLite が群を抜いて多く、米国で7,912件です。ほかに DM を残してショート動画を消すアプリなら、対応SNSが多いのは UNDOOMED と minulo です。minulo は TikTok・Threads・Pinterest・LinkedIn にも対応し、Chrome の拡張機能もありますが、新しいアプリなので米国の評価はまだありません。

minuloでログインしても安全？

ログインは、minulo の中で開いた各SNSの公式ページで行います。minulo は ID もパスワードも受け取らず、保存もしません。minulo 自体のアカウントもありません。使われ方の記録は匿名で、個人と結びつきません。
